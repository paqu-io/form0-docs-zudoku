---
title: Troubleshooting
description: Resolve common form0-cli installation, project, preview, and connector problems.
---

Start by confirming the installed version with `form0 --version` and inspecting the relevant
command with `--help`. Run commands from the project directory containing `package.json` and
`form0.config.js`, and validate the schema before starting a preview.

For connector failures, confirm that the package is installed, configured, and reachable, then use
the connector test and status commands. For ordinary help, use the repository’s support channels.
