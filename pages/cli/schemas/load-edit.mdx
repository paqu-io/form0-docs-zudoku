---
title: Load and edit schemas
description: Load a schema into the interactive shell and edit it with your configured editor.
---

<PageBadges />

Use `load` to select a schema interactively, or `load <file>` to choose one directly. When a schema
is loaded, `schema edit` opens it with the editor configured through `EDITOR` or `VISUAL`.

The CLI validates saved changes before adopting them. Use the [Core schema documentation](/core/schema/form)
for field and form syntax.
