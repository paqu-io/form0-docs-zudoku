Per una nuova applicazione web, usa l'[avvio rapido della CLI](/it/getting-started/quickstart). Lo
starter mantenuto React e Vite include il binding, la configurazione e alcuni schemi di esempio.

Per aggiungere form0 a un'applicazione esistente:

```bash
npm install form0-react form0-core
```

L'applicazione host deve fornire anche dipendenze peer compatibili:

- Node.js 22 o versione successiva per l'installazione e gli strumenti di build
- React 18 o 19
- React DOM 18 o 19
- `@vanilla-extract/css` 1.17.4 o versione successiva

## Eseguire il rendering di uno schema

```jsx
import { FormRenderer } from "form0-react"
import "form0-react/index.css"
import schema from "./contact.form0.json"

export function ContactForm() {
  return (
    <FormRenderer
      schema={schema}
      onSubmit={(record, meta) => {
        console.log(record)
        console.log(meta.rawValues)
      }}
    />
  )
}
```

`schema` deve contenere un oggetto modulo `form0-core` valido. Inizia da
[Modifica il tuo primo schema](/it/getting-started/schema-edit) oppure consulta l'[Oggetto
modulo](/it/core/schema/form).

`onSubmit` riceve un record form0 strutturato. Il secondo argomento espone i valori grezzi, lo stato
delle sezioni ripetibili, i timestamp e il riepilogo della validazione. Vedi
[Valori, snapshot e invio](/it/bindings/react/values-snapshots-submission).

> [!NOTE]
> Per impostazione predefinita, `FormRenderer` esegue il motore sul thread principale. Le applicazioni
> Vite possono usare il module worker incluso nel pacchetto con `engineMode="worker"`.
