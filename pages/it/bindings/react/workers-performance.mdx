## Esecuzione del motore

Il valore predefinito, `engineMode="main-thread"`, valuta il motore del modulo sul thread
dell'interfaccia. Usa `engineMode="worker"` per spostare la valutazione del motore nel module worker
incluso nel pacchetto quando i Web Worker sono disponibili:

```jsx
<FormRenderer schema={schema} engineMode="worker" />
```

Vite supporta il pattern di module worker statico usato dal pacchetto e genera il worker durante la
build di produzione. Lo starter Vite mantenuto esclude `form0-react` dall'ottimizzazione delle
dipendenze, così questo worker resta disponibile.

L'API pubblica di `FormRenderer` non accetta un URL di worker personalizzato né una factory di
worker. Le applicazioni che usano un altro bundler devono verificare che supporti
`new Worker(new URL("./worker.js", import.meta.url), { type: "module" })`; in caso contrario, usa la
modalità predefinita sul thread principale.

Se il browser non supporta i Worker, il binding torna all'esecuzione sul thread principale.

## Modalità di archiviazione React

`engineStoreMode="snapshot"` clona lo snapshot del motore nello stato React ed è il valore
predefinito. `engineStoreMode="selector"` usa sottoscrizioni per campo per ridurre i rerender
estesi.

Considera la modalità selector come un'ottimizzazione: prima di adottarla, verifica
nell'applicazione di destinazione gli errori dei campi, i riepiloghi di navigazione, le sezioni
ripetibili e il comportamento dell'invio.
