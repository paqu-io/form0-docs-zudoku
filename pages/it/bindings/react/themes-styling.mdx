Importa il foglio di stile del pacchetto una sola volta nel punto di ingresso dell'applicazione:

```js
import "form0-react/index.css"
```

## Temi integrati

`theme` accetta `standard`, `modal`, `simplified` o `spotlight`. `colorMode` accetta `light`, `dark`
o `system`.

```jsx
<FormRenderer schema={schema} theme="standard" colorMode="system" />
```

Il nome del tema e la modalità colore selezionano la classe Vanilla Extract integrata
corrispondente. Il posizionamento non cambia automaticamente la proprietà `theme`, quindi ogni
applicazione può scegliere la propria combinazione.

## Temi personalizzati

L'esportazione `form0-react/theme.css.js` espone il contratto di tema `vars`:

```js
import { createTheme } from "@vanilla-extract/css"
import { vars } from "form0-react/theme.css.js"

export const appTheme = createTheme(vars, {
  // Provide every color, type, spacing, and radius token in the contract.
})
```

Passa la classe generata a `theme`:

```jsx
<FormRenderer schema={schema} theme={appTheme} colorMode="light" />
```

Usa `className` per gli stili a livello di modulo e normali elementi contenitore per il layout
dell'applicazione intorno al modulo. Il markup personalizzato di un campo va inserito in un
[renderer personalizzato](/it/bindings/react/custom-renderers).
