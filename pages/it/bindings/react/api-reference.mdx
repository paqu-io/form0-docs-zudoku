Tutte le esportazioni JavaScript supportate sono disponibili da `form0-react` a meno che non venga mostrato un altro percorso.

## Rendering

- `FormRenderer` — esegue il rendering e la gestione di un modulo basato su schema.
- `ThemeProvider`, `ThemeContext`, `useThemeClass` — forniscono o leggono la classe di tema attiva.

Vedere [FormRenderer](/it/bindings/react/form-renderer) e
[Temi e styling](/it/bindings/react/themes-styling).

## Registro dei campi

- `FieldRegistryProvider`, `FieldRegistryContext`, `useFieldRegistry`
- `createFieldRegistry`, `defaultFieldRegistry`
- `registerFieldComponent`, `unregisterFieldComponent`, `resetFieldComponents`
- `getFieldComponent`, `listRegisteredFieldTypes`, `getMissingFieldComponentTypes`
- `KNOWN_FIELD_TYPES`

Vedere [Campo personalizzato renderers](/it/bindings/react/custom-renderers).

## Utilità Schema

- `cloneDeep(value)` e `cloneSchema(schema)` creano copie staccate.
- `ensureSchemaKeys(elements)` aggiunge chiavi stabili dove richiesto e segnala se ha cambiato il
  ingresso.
- `prepareSchema(schema)` clona una schema e assicura le chiavi degli elementi sulla copia.

## Integrazione specializzata

- `useBuildingPlanController(options)` coordina la sezione UI del piano di costruzione di renderer con
  dati ripetibili. È specializzato piuttosto che un gancio forma-stato generale.

Il client interno `useFormEngine`, worker, i singoli componenti renderer predefiniti e
`FieldRenderer` non sono esportazioni di pacchetti. L'importazione di file interni non è supportata dal pacchetto
export map.

I token a tema vengono esportati separatamente da `form0-react/theme.css.js`. Il foglio di stile compilato è
Disponibile come `form0-react/index.css`.
