## Temi di colore

`colorMode` accetta `light` o `dark`. Fornisci un `customTheme` parziale per sostituire dei token; il
binding lo unisce in profondità con il tema integrato selezionato. Un'applicazione può ricavare la
preferenza del dispositivo con `useColorScheme` di React Native e passare la modalità risultante.

```jsx
<FormRenderer schema={schema} colorMode="dark" customTheme={{ color: { primary: "#7c3aed" } }} />
```

`lightTheme`, `darkTheme`, `mergeThemes` e `getThemeByName` sono esportati per comporre i temi a
livello di applicazione. `ThemeProvider` e `useTheme` permettono di mantenere l'interfaccia nativa
circostante coerente con il modulo.

## Font inclusi

Il pacchetto esporta i file del font Figtree tramite `form0Fonts`. Con Expo, caricali all'avvio
dell'applicazione, prima di eseguire il rendering del modulo:

```jsx
import { useFonts } from "expo-font"
import { form0Fonts, FormRenderer } from "form0-react-native"

const [fontsLoaded] = useFonts(form0Fonts)
if (!fontsLoaded) return null

return <FormRenderer schema={schema} />
```

## Immagini di supporto

Per impostazione predefinita, i percorsi HTTP e HTTPS remoti vengono risolti in `{ uri }`. React
Native richiede che le immagini locali incluse nel bundle siano individuabili staticamente, quindi
fornisci un `imageResolver` che associ i percorsi dello schema a sorgenti di immagine importate o
caricate con require:

```jsx
const images = {
  "safety/helmet.png": require("./assets/safety/helmet.png"),
}

<FormRenderer schema={schema} imageResolver={(path) => images[path] ?? null} />
```

Lo starter mantenuto Expo genera questa mappatura quando cambiano le immagini di supporto.
