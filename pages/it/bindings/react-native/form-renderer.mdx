---
title: FormRenderer
description: Configura il componente principale form0 per React Native.
---

`FormRenderer` valida e prepara lo schema, crea il motore, renderizza campi e sezioni native e
produce record strutturati o snapshot ripristinabili.

```jsx
<FormRenderer
  schema={schema}
  initialValues={{ name: "Ada" }}
  mode="edit"
  colorMode="light"
  labelPosition="top"
  onSubmit={saveRecord}
/>
```

## Proprietà essenziali

| Proprietà | Scopo |
| --- | --- |
| `schema` | Schema form0 contenente `form.elements`. |
| `initialValues` | Valori iniziali non ripetibili. |
| `initialSnapshot` | Ripristina insieme valori, ripetibili e timestamp. |
| `overrideValues` | Applica valori autorevoli sopra quelli iniziali. |
| `onSubmit` | Riceve un record validato e i metadati. |
| `onSave` | Riceve uno snapshot senza richiedere un modulo valido. |
| `onSnapshotChange` | Osserva inizializzazione e modifiche utente. |
| `mode` | Avvia in modalità `edit` o `readonly`. |

## Integrazione host

- `onRequestClose` abilita l’annullamento e la conferma quando ci sono modifiche.
- `headerAccessory` mostra contenuto sotto l’header; `showHeader` nasconde quello integrato.
- `primaryActionMode`, `primaryActionLabel` e `showPrimaryActionsInViewMode` configurano l’azione
  principale.
- `onSchemaReady` riceve lo schema preparato.
- `engineOptions` fornisce helper, sicurezza, avvisi, operazioni e osservazione del motore.
