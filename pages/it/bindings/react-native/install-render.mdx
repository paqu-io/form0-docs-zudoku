Per una nuova applicazione mobile, usa l'[avvio rapido della CLI](/it/getting-started/quickstart).
Lo starter mantenuto React Native ed Expo include il binding, il caricamento dei font, alcuni schemi
di esempio, immagini di supporto e la persistenza locale con SQLite.

Per aggiungere form0 a un'applicazione esistente, installa il binding e il core insieme:

```bash
npm install form0-react-native form0-core lucide-react-native
```

Installa le dipendenze peer native in versioni compatibili con la tua applicazione. Con Expo, usa
`npx expo install` per selezionare versioni compatibili con l'SDK del tuo progetto:

```bash
npx expo install react-native-svg react-native-safe-area-context expo-font
```

Il pacchetto richiede Node.js 22 o versione successiva per l'installazione e gli strumenti, React 18
o 19 e React Native 0.72 o versione successiva. `react-native-safe-area-context` è facoltativo, ma
permette all'intestazione integrata di rispettare l'area sicura del dispositivo. Se lo installi,
avvolgi la radice dell'applicazione nel suo `SafeAreaProvider`.

## Esegui il rendering di uno schema

```jsx
import { FormRenderer } from "form0-react-native"
import schema from "./contact.form0.json"

export function ContactForm() {
  return (
    <FormRenderer
      schema={schema}
      onSubmit={(record, meta) => {
        console.log(record)
        console.log(meta.rawValues)
      }}
    />
  )
}
```

`schema` deve contenere un oggetto modulo `form0-core` valido. Inizia da
[Modifica il tuo primo schema](/it/getting-started/schema-edit) oppure consulta
[Oggetto modulo](/it/core/schema/form).

Carica i font inclusi nel pacchetto prima di mostrare il modulo, per ottenere la tipografia
prevista. Vedi [Temi, font e immagini](/it/bindings/react-native/themes-assets).
