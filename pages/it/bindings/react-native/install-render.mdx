Per una nuova applicazione mobile, utilizzare [CLI quickstart](/it/getting-started/quickstart).
React Native e Expo starter include lo binding, caricamento dei caratteri, esempio schemas, supporto
immagini e persistenza SQLite locale.

Per aggiungere form0 a un'applicazione esistente:

```bash
npm install form0-react-native form0-core lucide-react-native
```

Installa dipendenze peer native con versioni compatibili con la tua applicazione. In Expo:

```bash
npx expo install react-native-svg react-native-safe-area-context expo-font
```

Il pacchetto richiede Node.js 22 o più recente per l'installazione e l'utensile, React 18 o 19 e React
Nativo 0.72 o più recente. `react-native-safe-area-context` è facoltativo ma lascia l'intestazione incorporata
rispettare l'area sicura del dispositivo. Quando è installato, avvolgere la radice dell'applicazione nel suo
`SafeAreaProvider`.

## Rendere un schema

```jsx
import { FormRenderer } from "form0-react-native"
import schema from "./contact.form0.json"

export function ContactForm() {
  return (
    <FormRenderer
      schema={schema}
      onSubmit={(record, meta) => {
        console.log(record)
        console.log(meta.rawValues)
      }}
    />
  )
}
```

`schema` deve contenere un oggetto modulo `form0-core` valido.
[Modificare il tuo primo schema](/it/getting-started/schema-edit) o rivedere il
[Form oggetto](/it/core/schema/form).

Caricare i font pacchettizzati prima di visualizzare il modulo per la tipografia desiderata. Vedi
[Temi, font e immagini](/it/bindings/react-native/themes-assets).
