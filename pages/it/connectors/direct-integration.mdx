---

La CLI è il percorso di integrazione abituale, ma entrambi i connettori ufficiali espongono lo stesso
ciclo di vita:

- `initialize(config, envVars)` apre l'archiviazione e crea le tabelle mancanti.
- `onFormSubmit(record)` salva un record strutturato canonico.
- `healthCheck()` indica se l'archiviazione inizializzata è raggiungibile.
- `getMetadata()` descrive il connettore installato e la configurazione attiva senza esporre segreti.
- `destroy()` rilascia la connessione al database o l'handle del file locale.

```javascript
import { Form0PostgreSQLConnector } from "form0-connector-pg"

const connector = new Form0PostgreSQLConnector()

await connector.initialize()
const health = await connector.healthCheck()

if (!health.healthy) {
  throw new Error(health.message)
}

const result = await connector.onFormSubmit(structuredRecord)
await connector.destroy()
```

I valori di configurazione espliciti hanno la precedenza su quelli ricavati dalle variabili
d'ambiente. Tieni le credenziali fuori dal controllo di versione e rilascia sempre il connettore
alla chiusura dell'applicazione.

La forma di record accettata è documentata in [Output e record del nucleo](/it/core/output-records).
I connettori aggiungono timestamp lato server prima del salvataggio e restituiscono un risultato che
descrive il record principale e i record annidati scritti.
