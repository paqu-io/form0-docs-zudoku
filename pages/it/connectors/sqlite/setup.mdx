---
title: Installazione e configurazione di SQLite
description: Installa e configura il connettore SQLite ufficiale per Node.js.
---

<PageBadges />

Installa e configura il connettore dalla CLI interattiva:

```text
form0> connector install form0-connector-sqlite
form0> connector configure form0-connector-sqlite
form0> connector test form0-connector-sqlite
```

Per l'uso diretto, installalo con `npm install form0-connector-sqlite`.

| Variabile d'ambiente                      | Scopo                                     | Valore predefinito           |
| ----------------------------------------- | ----------------------------------------- | ---------------------------- |
| `FORM0_CONNECTOR_SQLITE_PATH`             | Percorso relativo o assoluto del database | `./form0.db`                 |
| `FORM0_CONNECTOR_SQLITE_TABLE_NAME`       | Tabella principale                        | `form0_submissions`          |
| `FORM0_CONNECTOR_SQLITE_CHILD_TABLE_NAME` | Tabella dei record annidati               | `form0_submissions_children` |
| `FORM0_CONNECTOR_SQLITE_DEBUG`            | Logging dettagliato del connettore        | `false`                      |

I percorsi relativi del database vengono risolti a partire dalla directory di lavoro del processo.
Il connettore crea la directory padre e il file del database quando necessario, quindi il processo
deve avere permessi di scrittura adeguati.

Il pacchetto richiede Node.js 22 o versione successiva e una piattaforma supportata dalla sua
dipendenza nativa `better-sqlite3`. Non è pensato per React Native né per Expo; in quei casi usa
un'archiviazione mobile nativa della piattaforma, come `expo-sqlite`.

Non collocare un database di invii in una directory web pubblica e non aggiungerlo al controllo di
versione.
