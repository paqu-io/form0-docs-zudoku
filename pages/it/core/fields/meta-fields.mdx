## FormLinkField

```json
{
  "type": "FormLinkField",
  "key": "related_record",
  "data_name": "related_record",
  "label": "Related record",
  "display": "default",
  "description": null,
  "description_mode": null,
  "required": false,
  "required_conditions": null,
  "visible": true,
  "visible_conditions": null,
  "read_only": false,
  "read_only_conditions": null,
  "default_value": null,
  "allow_creating_records": true,
  "allow_existing_records": true,
  "allow_updating_records": false,
  "allow_multiple_records": false,
  "form_id": "target-form-id",
  "record_conditions": null,
  "record_defaults": null
}
```

Attributi aggiuntivi:

- `allow_creating_records`, `allow_existing_records`, `allow_updating_records`
- `allow_multiple_records`
- `form_id`: identificatore del modulo di destinazione
- `record_conditions`: filtri per i record collegati
- `record_defaults`: mappature predefinite dei campi quando si creano nuovi record

Le voci di `record_defaults` usano mappature come questa:

```json
{
  "source_field_id": "source_field_key",
  "destination_field_id": "target_field_key"
}
```

## StatusField

```json
{
  "type": "StatusField",
  "key": "@status",
  "data_name": "status",
  "label": "Status",
  "display": "default",
  "enabled": true,
  "visible": true,
  "visible_conditions": null,
  "read_only": false,
  "read_only_conditions": null,
  "default_value": "pending",
  "choices": [
    { "label": "Open", "value": "open" },
    { "label": "Closed", "value": "closed" }
  ]
}
```

StatusField è definito in `form.status_field` (non all'interno di `elements`).

## TitleField

```json
{
  "type": "TitleField",
  "key": "@title",
  "data_name": "title",
  "label": "Title",
  "display": "default",
  "enabled": true,
  "visible": true,
  "visible_conditions": null,
  "read_only": true,
  "read_only_conditions": null,
  "elements": ["first_name", "last_name"]
}
```

TitleField usa le chiavi dei campi ordinate (preferibile) o i valori `data_name`. I valori visualizzati non vuoti
vengono uniti con `", "`; i campi di scelta usano le etichette correnti dello schema, e il risultato è `null` quando
nessuna parte viene risolta.

Alla radice, TitleField è definito in `form.title_field` e può fare riferimento a campi radice all'interno di
sezioni ordinarie, ma mai a discendenti ripetibili. La stessa struttura completa può essere assegnata a
`RepeatableSection.title_field`, dove i riferimenti sono limitati ai dati di quel record figlio. Vedi
[RepeatableSection](/it/core/fields/containers#repeatablesection) per il salvataggio e l'etichetta di ripiego
mostrata nell'interfaccia.

<Callout type="info" title="Dettagli di reform">
  I campi FormLink, Status e Title hanno un comportamento più ampio in reform. Ulteriori dettagli
  saranno collegati in una revisione successiva su [docs.reformapp.io](https://docs.reformapp.io).
</Callout>
