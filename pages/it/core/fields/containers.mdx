## Section

```json
{
  "type": "Section",
  "key": "details",
  "data_name": "details",
  "label": "Details",
  "display": "inline",
  "description": null,
  "description_mode": null,
  "visible": true,
  "visible_conditions": null,
  "elements": []
}
```

Attributi aggiuntivi:

- `display`: `inline` o `drilldown`.
- `elements`: campi annidati.

## RepeatableSection

```json
{
  "type": "RepeatableSection",
  "key": "items",
  "data_name": "items",
  "label": "Items",
  "display": "drilldown",
  "description": null,
  "description_mode": null,
  "visible": true,
  "visible_conditions": null,
  "location_enabled": false,
  "location_required": false,
  "title_field": {
    "type": "TitleField",
    "key": "@title",
    "data_name": "title",
    "label": "Title",
    "display": "default",
    "enabled": true,
    "visible": true,
    "visible_conditions": null,
    "read_only": true,
    "read_only_conditions": null,
    "elements": ["item_name", "item_date"]
  },
  "elements": [
    {
      "type": "TextField",
      "key": "item_name",
      "data_name": "item_name",
      "label": "Item name"
    },
    {
      "type": "DateField",
      "key": "item_date",
      "data_name": "item_date",
      "label": "Item date"
    }
  ]
}
```

Attributi aggiuntivi:

- `location_enabled`: abilita i dati di posizione per gli elementi.
- `location_required`: rende obbligatori i dati di posizione per gli elementi.
- `title_field`: `TitleField` facoltativo usato per ricavare il titolo di ogni record figlio. Usa `null` se non
  è configurato alcun titolo della voce.

Le sezioni ripetibili producono un array di record figli nell'output. Il titolo della voce configurato viene
salvato come `@title` in ogni record figlio. Se tutte le parti del titolo sono vuote, `@title` è `null`; i renderer
possono mostrare un'etichetta posizionale come `Items 1`, ma questo valore di ripiego non viene salvato.

I riferimenti del titolo sono limitati ai dati dei record figli della sezione ripetibile stessa. Possono puntare a campi
all'interno di normali contenitori `Section` annidati, ma non a campi esterni alla sezione ripetibile o all'interno di una
`RepeatableSection` annidata. I tipi ammessi sono `TextField`, `NumericField`, `DateField`, `TimeField`,
`SingleChoiceField`, `MultiChoiceField`, `BooleanField` e `CalculatedField`. Sono preferibili le chiavi dei campi ordinate,
mentre negli schemi scritti a mano sono accettati anche i riferimenti tramite `data_name`.

## BuildingPlanSection

```json
{
  "type": "BuildingPlanSection",
  "key": "building_plan",
  "data_name": "building_plan",
  "label": "Building plan",
  "description": null,
  "description_mode": null,
  "visible": true,
  "visible_conditions": null,
  "read_only": false,
  "read_only_conditions": null,
  "building_plan": { "nodes": [], "edges": [] },
  "node_overrides": null,
  "elements": []
}
```

Attributi aggiuntivi:

- `building_plan`: struttura che descrive la topologia del piano.
- `node_overrides`: override per i nodi generati.
