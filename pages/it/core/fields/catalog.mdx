La tabella seguente elenca ogni tipo di campo supportato da form0-core.

| Tipo di campo         | Categoria                                  | Descrizione                                             |
| --------------------- | ------------------------------------------ | ------------------------------------------------------- |
| `TextField`           | <Badge variant="secondary">Input</Badge>   | Inserimento di testo su una sola riga.                  |
| `NumericField`        | <Badge variant="secondary">Input</Badge>   | Inserimento numerico con min/max e formato.             |
| `SingleChoiceField`   | <Badge variant="secondary">Input</Badge>   | Selezione a scelta singola.                             |
| `MultiChoiceField`    | <Badge variant="secondary">Input</Badge>   | Selezione a scelta multipla.                            |
| `BooleanField`        | <Badge variant="secondary">Input</Badge>   | Scelta booleana (sì/no o tri-stato).                    |
| `DateField`           | <Badge variant="secondary">Input</Badge>   | Inserimento di una data.                                |
| `TimeField`           | <Badge variant="secondary">Input</Badge>   | Inserimento di un orario.                               |
| `CalculatedField`     | <Badge variant="muted">Calcolato</Badge>   | Valore calcolato dalle espressioni.                     |
| `LabelField`          | <Badge variant="muted">Calcolato</Badge>   | Etichetta o nota non modificabile.                      |
| `Section`             | <Badge variant="outline">Struttura</Badge> | Contenitore per campi annidati.                         |
| `RepeatableSection`   | <Badge variant="outline">Struttura</Badge> | Contenitore ripetibile per i record.                    |
| `BuildingPlanSection` | <Badge variant="outline">Struttura</Badge> | Sezioni ripetibili generate da un piano di costruzione. |
| `SignatureField`      | <Badge variant="secondary">Media</Badge>   | Acquisizione della firma.                               |
| `PhotoField`          | <Badge variant="secondary">Media</Badge>   | Acquisizione o caricamento di foto.                     |
| `VideoField`          | <Badge variant="secondary">Media</Badge>   | Acquisizione o caricamento di video.                    |
| `FormLinkField`       | <Badge variant="outline">Meta</Badge>      | Collegamento ai record di un altro modulo.              |
| `StatusField`         | <Badge variant="outline">Meta</Badge>      | Selettore dello stato del modulo (livello superiore).   |
| `TitleField`          | <Badge variant="outline">Meta</Badge>      | Titolo composito (livello superiore).                   |
