Registra un gestore di eventi.

## Esempio

```js
ON("change", "city", function (event) {
  ALERT("City changed")
})
```

## Parametri

- eventType: stringa
- fieldKeyOrCallback: stringa|funzione
- callback: funzione (facoltativa)

## Valore restituito

Il descrittore dell’operazione (utilizzato dai client).
