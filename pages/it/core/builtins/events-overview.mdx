Gli eventi in diretta in `form.events.code` e sono valutati in runtime. Utilizza `ON` per registrare i gestori
e `SETVALUE` / `ALERT` per interagire con il modulo.

## Esempio rapido

```js
ON("change", "age", function (event) {
  if ($age >= 18) {
    SETVALUE("can_vote", "yes")
  }
})
```
