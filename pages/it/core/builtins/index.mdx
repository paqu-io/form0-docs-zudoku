I builtin sono funzioni disponibili nelle espressioni form0. Puoi usarli nei campi calcolati
e in `form.events.code` senza importare nulla.

## Dove si usano i builtin

- Espressioni di **CalculatedField** (`calculate`)
- **Codice degli eventi** (`form.events.code`)

## Categorie

| Categoria                                     | Esempi di builtin                |
| --------------------------------------------- | -------------------------------- |
| <Badge variant="secondary">Logica</Badge>     | `IF`, `AND`, `OR`                |
| <Badge variant="secondary">Matematica</Badge> | `ROUND`, `CEILING`               |
| <Badge variant="secondary">Testo</Badge>      | `UPPER`                          |
| <Badge variant="secondary">Scelta</Badge>     | `CHOICEVALUE`, `CHOICELABEL`     |
| <Badge variant="secondary">Schema</Badge>     | `DATANAMES`                      |
| <Badge variant="secondary">Controllo</Badge>  | `SETRESULT`, `EVAL`              |
| <Badge variant="secondary">Eventi</Badge>     | `ON`, `OFF`, `ALERT`, `SETVALUE` |
