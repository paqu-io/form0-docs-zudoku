Valuta un’espressione dinamica in un contesto limitato.

## Esempio

```js
EVAL("$" + fieldName)
```

## Parametri

- expression: stringa

## Valore restituito

Il risultato dell’espressione o null.

## Note

- EVAL applica regole di sicurezza aggiuntive; mantieni semplici le espressioni.
