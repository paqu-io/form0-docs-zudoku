Restituisce il valore selezionato di un campo a scelta singola.

## Esempio

```js
CHOICEVALUE($city)
```

## Parametri

- choiceField: valore di SingleChoiceField o BooleanField

## Valore restituito

Il valore selezionato o null.

## Note

- Mantiene i valori numerici quando possibile.
