Restituisce i nomi dati dei campi, con filtro facoltativo per tipo.

## Esempio

```js
DATANAMES("TextField")
```

## Parametri

- type: stringa facoltativa del tipo di campo

## Valore restituito

Un array di stringhe data_name.
