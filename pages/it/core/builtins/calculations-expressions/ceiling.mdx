Arrotonda un valore per eccesso al multiplo più vicino di un fattore.

## Esempio

```js
CEILING(12.3, 5)
```

## Parametri

- value: numero
- factor: numero (facoltativo, valore predefinito 1)

## Valore restituito

Il numero arrotondato.
