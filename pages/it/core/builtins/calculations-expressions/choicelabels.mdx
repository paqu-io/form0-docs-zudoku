Restituisce un array delle etichette selezionate di un campo a scelta multipla.

## Esempio

```js
CHOICELABELS($colors)
```

## Parametri

- multiChoiceField: valore di MultiChoiceField

## Valore restituito

Un array delle etichette selezionate.
