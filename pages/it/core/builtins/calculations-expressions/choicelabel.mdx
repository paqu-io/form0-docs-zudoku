Restituisce l’etichetta selezionata di un campo a scelta singola.

## Esempio

```js
CHOICELABEL($city)
```

## Parametri

- choiceField: valore di SingleChoiceField o BooleanField

## Valore restituito

L’etichetta selezionata o null.

## Note

- Mantiene le etichette numeriche quando possibile.
