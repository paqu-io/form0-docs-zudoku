Crea un array dagli argomenti oppure analizza una stringa.

## Esempio

```js
ARRAY($a, $b, $c)
```

## Parametri

- ...args: valori da includere
- string input: stringa facoltativa in formato array

## Valore restituito

Un array di valori.
