Sceglie tra due valori in base a una condizione.

## Esempio

```js
IF($age >= 18, "adult", "minor")
```

## Parametri

- condition: espressione booleana
- trueValue: restituito quando condition è truthy
- falseValue: restituito in caso contrario

## Valore restituito

`trueValue` o `falseValue`.
