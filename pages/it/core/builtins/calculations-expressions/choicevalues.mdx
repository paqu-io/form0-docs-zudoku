Restituisce un array dei valori selezionati di un campo a scelta multipla.

## Esempio

```js
CHOICEVALUES($colors)
```

## Parametri

- multiChoiceField: valore di MultiChoiceField

## Valore restituito

Un array dei valori selezionati.
