form0-core espone due output principali:

- Lo stato del motore (`values`, `errors`, `visible`, `required`, `read_only`)
- I record strutturati per la persistenza (`createStructuredRecord`)

## Stato del motore

Dopo `engine.eval()`, chiama `engine.getState()` per leggere lo stato più recente.

## Output dei record strutturati

`createStructuredRecord` trasforma lo stato del motore in un formato adatto all'invio:

- `form_values` usa per impostazione predefinita le chiavi dei campi
- Le sezioni ripetibili diventano array di record figli
- Le sezioni vengono omesse (sono solo contenitori)

### Modalità delle chiavi dei campi

Puoi usare invece le chiavi `data_name` tramite `fieldKeyMode`:

```js
const record = createStructuredRecord(state, fields, {
  fieldKeyMode: "data-name",
})
```

## Sezioni ripetibili

Le sezioni ripetibili creano record annidati. Usa `originalElements` per mantenere la corretta
struttura di annidamento quando crei i record.
