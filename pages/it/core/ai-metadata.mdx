form0-core supporta metadati IA facoltativi per guidare agenti esterni. Il motore ignora questi
metadati, che vengono usati solo se i tuoi strumenti li leggono.

## IA a livello di modulo

`form.ai` supporta le seguenti chiavi:

- `context`: array di tag di dominio.
- `instructions`: array di istruzioni per gli strumenti di IA.
- `namingPolicy`: oggetto che descrive le preferenze di denominazione.
- `tasks`: array delle attività da abilitare (ad esempio, `suggestFieldNames`).
- `requiresConsent`: booleano che indica se è richiesto il consenso dell'utente.
- `allowCloud`: booleano che indica se è consentita l'elaborazione nel cloud.

Esempio:

```json
{
  "ai": {
    "context": ["safety_inspections"],
    "instructions": ["Use snake_case"],
    "namingPolicy": { "language": "en", "case": "snake", "asciiOnly": true },
    "tasks": ["suggestFieldNames"],
    "requiresConsent": true
  }
}
```

## IA a livello di campo

`field.ai` supporta:

- `context`, `instructions`, `tasks` (come per il modulo)
- `examples`: valori di esempio
- `synonyms`: etichette alternative
- `inferrable`: booleano che indica se il valore può essere dedotto
- `fillStrategy`: `infer_from_previous`, `require_explicit` o `suggest_options`
- `priority`: numero che indica l'importanza
- `dependencies`: array di identificatori di campo
- `choicePolicy`: oggetto che descrive la strategia per i valori di scelta
- `providerHints`: indicazioni specifiche del provider
- `requiresConsent`, `allowCloud`

Esempio:

```json
{
  "ai": {
    "examples": ["John", "Jane"],
    "synonyms": ["First name"],
    "inferrable": true,
    "fillStrategy": "suggest_options",
    "priority": 0.7
  }
}
```
