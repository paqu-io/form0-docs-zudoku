Ogni schema inizia con un oggetto `form`, che definisce i metadati, i campi speciali e gli eventi.

## Attributi

<Callout type="info" title="Attributi a livello di applicazione">
  Gli attributi contrassegnati con ✓ nella colonna **Applicazione** sono metadati a livello di
  applicazione che il motore non elabora direttamente. Puoi usarli per l'integrazione con il
  prodotto SaaS [reform](https://reformapp.io) o per realizzare funzionalità simili nella tua
  applicazione.
</Callout>

| Attributo               |  Tipo   | Obbligatorio | Applicazione | Note                                                                                                                            |
| ----------------------- | :-----: | :----------: | :----------: | ------------------------------------------------------------------------------------------------------------------------------- |
| `name`                  | string  |      ✓       |              | Nome leggibile del modulo.                                                                                                      |
| `description`           | string  |              |              | Descrizione del modulo.                                                                                                         |
| `id`                    | string  |      ✓       |              | Identificatore univoco del modulo.                                                                                              |
| `record_count`          | number  |              |      ✓       | Contatore operativo gestito dalla piattaforma. Numero di record del modulo.                                                     |
| `record_last_change_at` | string  |              |      ✓       | Contatore operativo gestito dalla piattaforma. Data e ora dell'ultima modifica a un record (ISO 8601).                          |
| `form_created_at`       | string  |              |      ✓       | Data e ora di creazione del modulo (ISO 8601).                                                                                  |
| `form_updated_at`       | string  |              |      ✓       | Data e ora dell'ultimo aggiornamento del modulo (ISO 8601).                                                                     |
| `form_created_by`       | string  |              |      ✓       | Utente che ha creato il modulo.                                                                                                 |
| `form_updated_by`       | string  |              |      ✓       | Ultimo utente che ha aggiornato il modulo.                                                                                      |
| `status`                | string  |              |      ✓       | Stato del modulo, di solito `active` o `inactive`.                                                                              |
| `version`               | string  |              |      ✓       | Versione facoltativa dello schema gestita dalla piattaforma. form0-core non la incrementa.                                      |
| `main_org_id`           | string  |              |      ✓       | ID dell'organizzazione principale.                                                                                              |
| `main_org_metadata`     | object  |              |      ✓       | Campi di metadati dell'organizzazione principale.                                                                               |
| `sub_org_id`            | string  |              |      ✓       | ID della sotto-organizzazione.                                                                                                  |
| `sub_org_metadata`      | object  |              |      ✓       | Campi di metadati della sotto-organizzazione.                                                                                   |
| `project_id`            | string  |              |      ✓       | ID del progetto.                                                                                                                |
| `project_metadata`      | object  |              |      ✓       | Campi di metadati del progetto.                                                                                                 |
| `ai`                    | object  |              |              | Metadati IA con indicazioni a livello di modulo (vedi [Metadati IA](/it/core/ai-metadata)).                                     |
| `status_field`          | object  |      ✓       |              | Definizione del campo speciale di stato (vedi [Campi meta](/it/core/fields/meta-fields#statusfield)).                           |
| `title_field`           | object  |      ✓       |              | Definizione del campo speciale del titolo (vedi [Campi meta](/it/core/fields/meta-fields#titlefield)).                          |
| `bounding_box`          |  array  |              |      ✓       | `[min_lat, min_lng, max_lat, max_lng]` che contiene tutti i record.                                                             |
| `location_enabled`      | boolean |              |      ✓       | Abilita l'acquisizione della posizione.                                                                                         |
| `location_required`     | boolean |              |      ✓       | Rende obbligatori i dati di posizione quando è abilitato.                                                                       |
| `image`                 | string  |              |      ✓       | URL dell'icona del modulo (originale).                                                                                          |
| `image_thumbnail`       | string  |              |      ✓       | URL dell'icona in miniatura (160x160 px).                                                                                       |
| `image_small`           | string  |              |      ✓       | URL dell'icona piccola (320x320 px).                                                                                            |
| `image_large`           | string  |              |      ✓       | URL dell'icona grande (640x640 px).                                                                                             |
| `events`                | object  |              |              | Blocco di codice degli eventi (`events.code`).                                                                                  |
| `form_links`            | object  |              |              | Collegamenti da e verso altri moduli (usati con `FormLinkField`, vedi [Campi meta](/it/core/fields/meta-fields#formlinkfield)). |
| `elements`              |  array  |      ✓       |              | Campi e contenitori del modulo (vedi [Elementi](/it/core/schema/elements)).                                                     |

Per i dettagli su ogni attributo, compresi i valori predefiniti e le scelte possibili, vedi [Attributi del modulo](/it/core/schema/form-attributes).

## Campi speciali

`status_field` e `title_field` sono definiti al livello superiore, non in `elements`. Vengono
validati come i tipi di campo standard, ma hanno comportamenti fissi. Vedi [Campi meta](/it/core/fields/meta-fields) per i dettagli.

## Eventi

`events.code` contiene builtin ed espressioni JavaScript che registrano gestori di eventi con builtin come
`ON`, `OFF`, `ALERT`, `SETVALUE`, ecc. Vedi [Eventi](/it/core/builtins/events-overview) per i dettagli.

## Esempio

```json
{
  "form": {
    "name": "Inspection",
    "description": "Weekly inspection form",
    "id": "form_001",
    "status": "active",
    "version": "1",
    "location_enabled": true,
    "location_required": false,
    "status_field": { "type": "StatusField", "label": "Status", "choices": [] },
    "title_field": { "type": "TitleField", "label": "Title", "elements": [] },
    "events": { "code": "ON('load-record', function (e) { ALERT('Ready'); })" },
    "elements": []
  }
}
```
