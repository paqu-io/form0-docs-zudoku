`form0-core` è il motore guidato da schema che alimenta calcoli, visibilità, requisiti,
convalida ed eventi. È framework -agnostic ed è eseguito in qualsiasi JavaScript runtime (Node.js,
browser, React Native, ecc.).

## Cosa fa form0-core

- Convalida le definizioni di campo e schemas
- Valuta i campi e le espressioni calcolati
- Applica condizioni di visibilità, richieste e di sola lettura
- Esegue eventi definiti in `form.events.code`
- Esposizioni stato strutturato (`values`, `errors`, `visible`, `required`, `read_only`)
- Produce record strutturati per submission

## Cosa non fa form0-core

- rendering o layout dell'interfaccia utente
- Persistenza dei dati o networking
- Autenticazione o gestione degli utenti

<Callout type="info" title="Application-level attributes and field types">
  Alcuni attributi di schema sono metadati a livello di applicazione e alcuni tipi di campo
  richiedono l'interazione con altri moduli nell'applicazione. quindi non vengono elaborati
  direttamente dal motore. Questi attributi e tipi di campo sono ancora accettati dal motore.
  Possono essere utilizzati quando si integra con [reform](https://reformapp.io), il prodotto SaaS
  costruito da [paqu technologies](https://paqu.io) (il team dietro form0), o quando si creano
  funzionalità simili nella propria applicazione. <br /> Per ulteriori dettagli, vedere [attributi
  del form ](/it/core/schema/form) e [field types](/it/core/fields/catalog).
</Callout>
