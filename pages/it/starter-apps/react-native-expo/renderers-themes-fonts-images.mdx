## Tema e font

La radice dell'applicazione carica `form0Fonts` con `expo-font` prima del rendering e avvolge
l'interfaccia in `ThemeProvider`. Configura la modalità colore di base e gli override facoltativi
del tema in `form0.config.js`. Le schermate dello starter che circondano il modulo usano gli stessi
token di tema del modulo.

## Override dei renderer

Associa i tipi di campo dello schema a identificatori di renderer in `form0.config.js`, poi associa
questi identificatori ai componenti in `src/field-renderers/resolver.js`. Tenere i componenti fuori
dal file di configurazione mantiene una configurazione serializzabile e facile da gestire con gli
strumenti.

Per le proprietà dei renderer e il funzionamento della registrazione, consulta la
[documentazione dei renderer personalizzati](/it/bindings/react-native/custom-renderers).

## Immagini di supporto

React Native richiede che i riferimenti alle immagini incluse nel bundle siano individuabili
staticamente. Aggiungi i file in `assets/supporting-images`, poi rigenera la tabella di lookup:

```bash
npm run generate-images
```

Esegui il commit sia dell'asset sia di `src/supporting-images/index.js`. Gli script di avvio
rigenerano il file e la CI verifica che il registro committato sia aggiornato. I percorsi di
immagine HTTP e HTTPS remoti non hanno bisogno di voci nel registro.

Consulta [Temi, font e immagini](/it/bindings/react-native/themes-assets) per le API del binding.
