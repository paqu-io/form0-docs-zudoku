## Tema e font

La radice dell'applicazione carica `form0Fonts` con `expo-font` prima di eseguire il rendering e avvolge la sua UI in
`ThemeProvider`. Configurare la modalità colore di base e le sovrascrizioni opzionali del tema in `form0.config.js`.
Le schermate starter circostanti utilizzano gli stessi token del tema del modulo.

## Renderer overrides

Mappa i tipi di campo schema agli identificatori renderer in `form0.config.js`, quindi mappa quegli identificatori a
componenti in `src/field-renderers/resolver.js`. Mantenere i componenti fuori dal file di configurazione
preserva un limite di configurazione serializzabile e facile da usare.

Per gli oggetti di scena renderer e il comportamento di registrazione, utilizzare il
[documentazione personalizzata renderer](/it/bindings/react-native/custom-renderers).

## Immagini di supporto

React Native richiede che i riferimenti alle immagini in bundle siano staticamente rilevabili.
`assets/supporting-images`, quindi rigenerare la tabella di ricerca:

```bash
npm run generate-images
```

Commetti sia l'asset che `src/supporting-images/index.js`. Gli script di avvio rigenerano il file,
e CI verifica che il registro impegnato sia aggiornato. I percorsi di immagine HTTP e HTTPS remoti non
bisogno di voci di registro.

Vedere [Temi, font e immagini di](/it/bindings/react-native/themes-assets) per le API di livello binding.
