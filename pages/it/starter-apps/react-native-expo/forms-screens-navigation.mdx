## Registra i moduli

Gli schemi si trovano in `src/forms`. Aggiungi ogni modulo a `src/forms/registry.js` con un ID
stabile, metadati di visualizzazione e una funzione `loadSchema`. Gli import statici sono utili per
la prima schermata; quelli dinamici permettono di rimandare il caricamento degli altri moduli.

`useFormSchema` risolve la voce del registro selezionata ed espone il suo stato di caricamento, lo
schema e lo stato di errore. Valida gli schemi con [form0-cli](/it/cli/schemas/validate-preview)
prima di distribuirli.

## Comprendi il flusso delle schermate

Lo starter usa di proposito un piccolo flusso basato sullo stato:

```text
App → Home → FormPage → Form0Form
```

`Home` elenca i moduli registrati. `FormPage` carica lo schema e gestisce le azioni di invio e di
debug dell'archiviazione. `Form0Form` traduce la configurazione dell'applicazione nelle proprietà
del `FormRenderer` di React Native.

È un punto di partenza facile da capire, non un framework di routing. Sostituisci lo stato
`activeFormId` con il router o la libreria di navigazione della tua applicazione quando ti servono
deep link, schede, stack autenticati o il ripristino dello stato di navigazione.

Il renderer gestisce lo scorrimento, l'adattamento alla tastiera e le schermate drilldown all'interno
dell'area della schermata che gli è assegnata. Evita di inserirlo in un'altra vista a scorrimento
verticale. Consulta [Modalità e navigazione](/it/bindings/react-native/modes-navigation) per il
contratto del renderer.
