Lo starter React Native ed Expo è il modo più rapido per ottenere un'applicazione mobile form0.
Include schemi di esempio, renderer nativi, font, immagini di supporto e la persistenza locale con
SQLite.

## Crea l'applicazione

Installa [form0-cli](/it/cli/install-update), poi inizializza un progetto:

```bash
npm install --global form0-cli
form0 init my-mobile-form
```

Scegli **App mobile** e **React Native + Expo**. Entra nella directory generata e installa le
dipendenze se il gestore di pacchetti scelto non l'ha già fatto.

```bash
cd my-mobile-form
npm install
npm start
```

Il pulsante **Use this template** di GitHub è un'alternativa quando vuoi esplicitamente una copia
del repository. La CLI resta il percorso di creazione consigliato.

## Scegli un target di sviluppo

Usa una development build di Expo per il lavoro orientato alla produzione e ogni volta che
l'applicazione include codice nativo personalizzato. Expo Go resta utile per imparare e valutare
quando è disponibile una versione compatibile dell'SDK per la piattaforma di destinazione. Puoi
anche usare un emulatore Android, il simulatore iOS o il target web:

```bash
npm run android
npm run ios
npm run web
```

Il template richiede Node.js 22.13 o versione successiva. Le build native supportano Android 7 o
versione successiva e iOS 16.4 o versione successiva; le build iOS locali richiedono Xcode 26.4 o
versione successiva. La configurazione di emulatori e dispositivi nativi segue la
[guida all'ambiente di sviluppo di Expo](https://docs.expo.dev/get-started/set-up-your-environment/).

Prosegui con [Struttura e configurazione del progetto](./project-structure-configuration).
