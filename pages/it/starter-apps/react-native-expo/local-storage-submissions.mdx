## Archivio SQLite incluso

Lo starter salva i record strutturati inviati con `expo-sqlite`. Configuralo o disattivalo tramite
il blocco `storage` di `form0.config.js`:

```js
storage: {
  enabled: true,
  databaseName: "form0.db",
  tableName: "form0_submissions",
  debug: false,
}
```

Il database si trova nella sandbox dell'applicazione specifica di ogni piattaforma. Ogni invio viene
inserito con i metadati del record e il record strutturato completo in formato JSON. I controlli di
debug inclusi permettono di elencare o cancellare i record quando `debug` è attivo.

## Persistenza non significa sincronizzazione

Questo archivio offre solo la persistenza sul dispositivo. Non carica i record, non ritenta le
richieste, non risolve i conflitti, non cifra le esportazioni e non definisce criteri di
conservazione ed eliminazione. Le applicazioni devono progettare questi comportamenti in base ai
propri dati e al proprio modello di minaccia. Tratta i backup del database e i file esportati come
dati utente sensibili.

I pacchetti Node.js `form0-connector-pg` e `form0-connector-sqlite` non funzionano in React Native.
Invia i dati remoti tramite un'API autenticata dell'applicazione; non includere credenziali del
database in un'applicazione mobile.

Per il contratto di invio e di snapshot del renderer, consulta

generali in ambito mobile, consulta
[Integrazione mobile](/it/bindings/react-native/mobile-integration).
