## Incluso negozio SQLite

Lo starter salva i record inviati strutturati con `expo-sqlite`. Configurare o disabilitare
il blocco `storage` in `form0.config.js`:

```js
storage: {
  enabled: true,
  databaseName: "form0.db",
  tableName: "form0_submissions",
  debug: false,
}
```

Il database vive nella sandbox dell'applicazione specifica della piattaforma. Ogni submission è inserito con
record metadati e il record strutturato completo come JSON. I controlli di debug inclusi possono elencare
o cancellare i record quando `debug` è abilitato.

## La persistenza non è sincronizzazione

Questo negozio fornisce solo la persistenza sul dispositivo. Non carica record, riprova le richieste, risolvi
conflitti, crittografare le esportazioni o definire la politica di conservazione e cancellazione. Le applicazioni devono progettare quelle
comportamenti per i loro dati e il modello di minaccia. Trattare i backup del database e i file esportati come sensibili
dati utente.

I pacchetti Node.js `form0-connector-pg` e `form0-connector-sqlite` non vengono eseguiti in React Native.
Inviare submissions remoto tramite un'applicazione autenticata API; non incorporare credenziali di database
in un'applicazione mobile.

Per il contratto renderer submission e snapshot, vedere
[Valori, snapshots, e submission](/it/bindings/react-native/values-snapshots-submission). Per generale
frontiere mobili, vedere [Integrazione mobile](/it/bindings/react-native/mobile-integration).
