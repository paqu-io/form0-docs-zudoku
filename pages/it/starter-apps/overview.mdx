Le app starter sono basi applicative mantenute che combinano i pacchetti form0 con routing,
configurazione, stili e convenzioni per lo sviluppo locale. Sono utili quando vuoi partire da
un'applicazione funzionante da personalizzare, invece di aggiungere un binding a un progetto
esistente.

| Starter             | Ideale per                                                                               | Codice sorgente                                                          |
| ------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| React + Vite        | Applicazioni browser, moduli web personalizzati e hosting statico                        | [GitHub](https://github.com/paqu-io/form0-web-tmpl-react-vite)           |
| React Native + Expo | App iOS e Android, funzionalità del dispositivo e flussi di lavoro orientati all'offline | [GitHub](https://github.com/paqu-io/form0-mobile-tmpl-react-native-expo) |

## Percorso di creazione consigliato

Usa [form0-cli](/it/cli/overview) per creare uno starter. La CLI ti guida nella scelta del progetto
e del gestore di pacchetti e produce un normale repository applicativo di tua proprietà.

```bash
npm install --global form0-cli
form0 init my-form-app
```

Il pulsante **Use this template** di GitHub è disponibile anche quando vuoi creare esplicitamente un
repository a partire dallo starter sorgente. La CLI resta il percorso di onboarding di riferimento.

Le guide degli starter descrivono l'applicazione che circonda form0. Per le API dei pacchetti,
consulta la [documentazione dei binding React e React Native](/it/bindings/overview). Per il
comportamento degli schemi, consulta la [documentazione del nucleo](/it/core/overview).

Prosegui con la guida del tuo starter:

- [Creare ed eseguire lo starter React e Vite](/it/starter-apps/react-vite/create-run)
- [Creare ed eseguire lo starter React Native ed Expo](/it/starter-apps/react-native-expo/create-run)
