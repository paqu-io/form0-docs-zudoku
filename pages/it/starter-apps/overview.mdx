Le app Starter sono fondamenta di applicazioni mantenute che combinano i pacchetti form0 con il routing,
convenzioni di configurazione, styling e sviluppo locale. Sono utili quando si desidera un lavoro
applicazione per personalizzare piuttosto che aggiungere un binding a un progetto esistente.

| Starter             | Meglio per                                                                                   | Fonte                                                                    |
| ------------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| React + Vite        | Applicazioni del browser, moduli web personalizzati e hosting statico                        | [GitHub](https://github.com/paqu-io/form0-web-tmpl-react-vite)           |
| React Native + Expo | Applicazioni iOS e Android, funzionalità del dispositivo e flussi di lavoro offline-oriented | [GitHub](https://github.com/paqu-io/form0-mobile-tmpl-react-native-expo) |

## Percorso di creazione consigliato

Utilizzare [form0-cli](/it/cli/overview) per creare una starter. La CLI guida il progetto e il gestore dei pacchetti
seleziona e produce un normale repository di applicazioni che possiedi.

```bash
npm install --global form0-cli
form0 init my-form-app
```

Il pulsante \*\* di GitHub è disponibile anche quando si desidera creare un modello
repository dalla sorgente starter. CLI rimane il percorso canonico di onboarding.

Le guide di avvio spiegano l'applicazione intorno a form0. Per le API dei pacchetti, utilizzare il
[React e React Native binding documentazione](/it/bindings/overview). Per il comportamento schema, utilizzare il
[Documentazione core](/it/core/overview).
