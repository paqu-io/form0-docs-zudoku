Le app starter combinano i pacchetti form0 con routing, configurazione, stili e convenzioni per lo
sviluppo locale. Usale quando vuoi personalizzare un’applicazione funzionante invece di integrare un
binding in un progetto esistente.

| App                 | Ideale per                                                                | Codice sorgente                                                          |
| ------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| React + Vite        | Applicazioni web, moduli personalizzati e hosting statico                 | [GitHub](https://github.com/paqu-io/form0-web-tmpl-react-vite)           |
| React Native + Expo | Applicazioni iOS e Android, funzionalità del dispositivo e flussi offline | [GitHub](https://github.com/paqu-io/form0-mobile-tmpl-react-native-expo) |

## Percorso di creazione consigliato

Usa [form0-cli](/it/cli/overview). La CLI guida la scelta del progetto e del package manager e genera
una normale applicazione di tua proprietà.

```bash
npm install --global form0-cli
form0 init mia-app-form0
```

Il pulsante GitHub **Use this template** è disponibile quando vuoi creare direttamente un repository
dalla sorgente. La CLI rimane il percorso di onboarding canonico.

Queste guide descrivono l’applicazione attorno a form0. Consulta i [Bindings](/it/bindings/overview)
per le API e [Core](/it/core/overview) per il comportamento degli schemi.
