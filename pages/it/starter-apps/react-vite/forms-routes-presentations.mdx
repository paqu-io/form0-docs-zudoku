I file di schema si trovano in `src/forms`. Il registro in `src/forms/registry.js` assegna a ogni
modulo una route dell'applicazione, metadati di visualizzazione, un import dinamico dello schema e
valori iniziali facoltativi.

```js
const forms = [
  {
    id: "contact",
    title: "Contact us",
    description: "Send a message to the team.",
    loadSchema: () => import("./contact/schema.json"),
  },
]
```

Crea il file di schema corrispondente, poi aggiungi la voce al registro. Gli import dinamici
mantengono i file di schema in chunk di build separati.

## Route

Lo starter fornisce:

- `/` per l'elenco dei moduli e gli esempi di overlay;
- `/:formId` per la presentazione standard predefinita; e
- `/:formId/:variant` per le presentazioni in pagina `standard` o `simplified`.

`FormPage` valida l'identificatore del modulo e la presentazione prima di caricare lo schema. `Home`
gestisce gli esempi modale e spotlight.

## Presentazioni

Le quattro chiavi di presentazione incluse sono:

| Chiave       | Posizionamento                 |
| ------------ | ------------------------------ |
| `standard`   | Pagina con modulo completo     |
| `simplified` | Pagina passo passo             |
| `modal`      | Overlay in finestra di dialogo |
| `spotlight`  | Overlay in pannello laterale   |

I valori di layout predefiniti di ogni presentazione si trovano in `form0.config.js`. Il componente
wrapper dell'applicazione passa a `FormRenderer` il tema, il posizionamento, la modalità di
interazione e il dimensionamento risolti.

Consulta [Modifica il tuo primo schema](/it/getting-started/schema-edit) per la scrittura degli
schemi e [Modalità, posizionamento e navigazione](/it/bindings/react/modes-placement-navigation) per
il comportamento del binding React sottostante.
