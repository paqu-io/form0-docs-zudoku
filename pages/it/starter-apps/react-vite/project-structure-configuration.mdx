Lo starter è una normale applicazione Vite. I valori predefiniti specifici di form0 si trovano in
`form0.config.js`, mentre il codice dell'applicazione resta in `src`.

```text
.
├── form0.config.js
├── src/
│   ├── components/        # application form wrappers and UI primitives
│   ├── field-renderers/   # application-owned renderer overrides
│   ├── forms/             # schema files, registry, and loader
│   ├── pages/             # home and form routes
│   ├── styles/            # application-level form overrides
│   └── themes/            # optional Vanilla Extract themes
└── vite.config.js         # React plugins, aliases, and local API proxy
```

## Aree di configurazione

Modifica `form0.config.js` per controllare:

- `layout`: la larghezza predefinita, la posizione delle etichette e il layout di ogni presentazione;
- `engine`: la valutazione sul thread principale o in un worker e la strategia dello store React;
- `theme`: chiaro, scuro, di sistema o una classe di tema dell'applicazione;
- `interaction`: il comportamento iniziale in modifica o in sola lettura e l'invio negli overlay;
- `schemas.directory`: la directory degli schemi usata dagli strumenti;
- `devServer`: il comando dell'applicazione, l'opzione di invio ai connettori e l'URL di base dell'API;
- `fieldRenderers`: i tipi di campo sostituiti da renderer dell'applicazione; e
- `output.useKeys`: se i record strutturati preferiscono le chiavi dello schema o i nomi dei dati.

Le proprietà dei componenti possono sovrascrivere i valori predefiniti pertinenti per un singolo
modulo. Mantieni nella configurazione i valori predefiniti riutilizzabili dell'applicazione e nello
schema il comportamento del modulo.

> [!CAUTION]
> In questo starter lascia lo store del motore impostato su `snapshot`. La configurazione inclusa
> documenta una limitazione nota dei messaggi di validazione con la modalità `selector`.

## Proxy di sviluppo

Per impostazione predefinita, il server Vite inoltra `/api` a `http://localhost:3030`. Imposta
`FORM0_DEV_API_URL` nell'ambiente del processo o in un file `.env` locale di Vite per usare un altro
indirizzo del server della CLI. Il valore viene letto dalla configurazione di Vite e non è esposto al
codice del browser.

Non inserire credenziali in variabili lato client. Le credenziali del database appartengono
all'ambiente della CLI o del connettore lato server, descritto nella
[documentazione dei connettori](/it/connectors/overview).
