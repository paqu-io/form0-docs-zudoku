Il starter è un'applicazione normale Vite. I suoi predefiniti form0-specific vivono in `form0.config.js`,
mentre il codice dell'applicazione rimane sotto `src`.

```text
.
├── form0.config.js
├── src/
│   ├── components/        # application form wrappers and UI primitives
│   ├── field-renderers/   # application-owned renderer overrides
│   ├── forms/             # schema files, registry, and loader
│   ├── pages/             # home and form routes
│   ├── styles/            # application-level form overrides
│   └── themes/            # optional Vanilla Extract themes
└── vite.config.js         # React plugins, aliases, and local API proxy
```

## Aree di configurazione

Modificare `form0.config.js` per controllare:

- `layout`: larghezza predefinita, posizionamento delle etichette e layout di presentazione;
- `engine`: valutazione del filo principale o worker e strategia del negozio React;
- `theme`: luce, buio, sistema, o una classe di tema di applicazione;
- `interaction`: comportamento iniziale di modifica / sola lettura e comportamento di sovrapposizione submission;
- `schemas.directory`: la directory schema utilizzata dagli strumenti;
- `devServer`: il comando dell'app, lo switch submission del connettore e API base URL;
- `fieldRenderers`: tipi di campo sostituiti dall'applicazione renderers; e
- `output.useKeys`: se i record strutturati preferiscono chiavi schema o nomi di dati.

## Proxy di sviluppo

Il server Vite proxy `/api` a `http://localhost:3030` per impostazione predefinita.
`FORM0_DEV_API_URL` nell'ambiente di processo o in un file locale Vite `.env` per utilizzare un altro server CLI
indirizzo. Il valore viene consumato dalla configurazione di Vite e non è esposto al codice del browser.

Non inserire le credenziali nelle variabili lato client. Le credenziali del database appartengono alla CLI o
ambiente del connettore lato server descritto nella documentazione del connettore](/it/connectors/overview).
