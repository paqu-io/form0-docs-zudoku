Creare e visualizzare in anteprima una build di produzione localmente:

```bash
npm run build
npm run preview
```

Vite scrive l'output statico su `dist`. Distribuisci quella directory con un host statico o posizionala dietro
il tuo server di applicazioni.

## Requisiti di hosting

starter utilizza il routing del browser. Configurare l'host per servire `index.html` come fallback per
percorsi di applicazione come `/contact/standard`; altrimenti la navigazione diretta a tali URL può
restituisce la pagina 404 dell'host.

Il proxy del connettore predefinito esiste solo nel server di sviluppo. Produzione submission deve utilizzare

Il proxy `/api` sarà presente dopo la distribuzione.

## Prima della distribuzione

- Eseguire `npm run lint` e `npm run build`.
- Rivedere l'avviso di dimensione del bundle generato e introdurre la divisione del codice quando la crescita dell'applicazione
  rende il download iniziale inappropriato.
- Mantieni i file `.env` locali fuori dal controllo della versione.
- Confermare che nessun segreto è incorporato nelle risorse generate.
- Testa la navigazione diretta su ogni percorso di applicazione pubblica.
- Rivedere la [politica di sicurezza](https://github.com/paqu-io/form0-web-tmpl-react-vite/blob/main/SECURITY.md).

I valori di ambiente Vite destinati al codice del browser sono staticamente incorporati al momento della compilazione.
li come configurazione pubblica, anche quando hanno origine in un file di ambiente locale.
