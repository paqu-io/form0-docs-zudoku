## Requisiti

- Node.js 22 o più recente
- Un gestore di pacchetti supportato; la sorgente starter commette un lockfile npm
- Un browser moderno

## Creare l'applicazione

Installare CLI, quindi inizializzare un progetto web:

```bash
npm install --global form0-cli
form0 init my-form-app
```

Scegliere ** Web app ** e ** React + Vite ** quando richiesto.
dipendenze se il flusso selezionato non lo ha già fatto, e avviare l'applicazione:

```bash
cd my-form-app
npm install
npm run dev
```

Aprire la URL stampata da Vite, normalmente `http://localhost:5173`. La home page elenca i contenuti inclusi
moduli di esempio e la loro pagina e sovrapporre presentazioni.

## Eseguire con form0-cli

Dalla directory del progetto, `form0 serve --app` avvia il server dell'applicazione configurato a fianco
il server di sviluppo CLI. Usa questa modalità quando vuoi che il gestore starter predefinito di submission
raggiungere i connettori configurati localmente.

```bash
form0 serve --app
```

Vedere [Server di sviluppo app](/it/cli/local-development/app-development-servers) e
[Sottomissioni e connettori](/it/starter-apps/react-vite/submissions-connectors) per il confine
tra l'applicazione del browser, il server CLI e il connettore del database.
