## Requisiti

- Node.js 22 o versione successiva
- Un gestore di pacchetti supportato; lo starter sorgente include un lockfile npm
- Un browser moderno

## Crea l'applicazione

Installa la CLI, poi inizializza un progetto web:

```bash
npm install --global form0-cli
form0 init my-form-app
```

Scegli **App web** e **React + Vite** quando richiesto. Entra nella directory generata, installa le
dipendenze se il flusso scelto non l'ha già fatto e avvia l'applicazione:

```bash
cd my-form-app
npm install
npm run dev
```

Apri l'URL mostrato da Vite, di solito `http://localhost:5173`. La home page elenca i moduli di
esempio inclusi e le loro presentazioni in pagina e in overlay.

## Esegui con form0-cli

Dalla directory del progetto, `form0 serve --app` avvia il server dell'applicazione configurato
insieme al server di sviluppo della CLI. Usa questa modalità quando vuoi che il gestore di invio
predefinito dello starter raggiunga i connettori configurati in locale.

```bash
form0 serve --app
```

[Server di sviluppo delle applicazioni](/it/cli/local-development/app-development-servers) e
