## Una route indica che il modulo non è stato trovato

Verifica che l'identificatore nell'URL corrisponda esattamente a una voce di `src/forms/registry.js`.
Verifica anche che il suo import dinamico punti a un file di schema esistente.

## Uno schema non si carica

Apri la console del browser per leggere l'errore di import, poi valida lo schema con form0-cli. Gli
errori di sintassi JSON e i percorsi di import relativi errati sono le cause più comuni.

```bash
form0
```

Carica lo schema ed esegui `validate`. Vedi
[Validare e visualizzare l'anteprima](/it/cli/schemas/validate-preview).

## Un renderer personalizzato non viene usato

Controlla tutti e tre i nomi: il tipo di campo dello schema, la sua associazione in `form0.config.js`
e l'identificatore del resolver in `src/field-renderers/resolver.js`. Il resolver registra un
avviso per gli identificatori sconosciuti.

## Gli invii non raggiungono il server della CLI

Esegui `form0 serve --app` dalla directory del progetto. Se il server della CLI usa un indirizzo
diverso, imposta `FORM0_DEV_API_URL` prima di avviare Vite o nel file `.env` locale pertinente.
Verifica che `devServer.apiBaseUrl` corrisponda ancora al percorso del proxy di Vite.

## La valutazione nel worker non riesce

Imposta temporaneamente `engine.mode` su `main-thread` per distinguere il caricamento del worker dal
comportamento dello schema. Poi controlla la console del browser, i percorsi degli asset e il
content type servito dal deployment. Vedi
[Worker e prestazioni](/it/bindings/react/workers-performance).

## I link diretti restituiscono 404 dopo il deployment

Configura l'hosting statico in modo che usi `index.html` come fallback per i percorsi sconosciuti
dell'applicazione. È un problema di configurazione dell'hosting, non della definizione delle route
React.

Per gli errori di rendering a livello di pacchetto, prosegui con
[Risoluzione dei problemi di React](/it/bindings/react/troubleshooting). Per gli errori del database,
consulta [Risoluzione dei problemi dei connettori](/it/connectors/troubleshooting).
