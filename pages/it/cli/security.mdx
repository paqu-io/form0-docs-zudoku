<PageBadges />

`form0-cli` è uno strumento di sviluppo locale. Espressioni di schema e script di eventi eseguono JavaScript,
e i connettori configurati vengono eseguiti come moduli Node.js. Utilizzare schemas, progetti e pacchetti di connettori
da fonti attendibili.

Mantenere le credenziali nei file di ambiente locale ignorati. Il server di anteprima si lega a `localhost` tramite
default; esponerlo solo su reti attendibili. Segnalare vulnerabilità sospette privatamente attraverso
la [form0-cli politica di sicurezza](https://github.com/paqu-io/form0-cli/security/policy).
