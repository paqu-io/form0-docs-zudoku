title: Sicurezza
description: Confini di fiducia e pratiche sicure di sviluppo locale per form0-cli.

Le espressioni e gli eventi dello schema eseguono JavaScript e i connettori configurati vengono
eseguiti come moduli Node.js. Usa fonti affidabili, conserva le credenziali in file locali ignorati
ed esponi l’anteprima solo su reti fidate.
