---
title: Inizializzare un progetto
description: Crea un progetto form0 standard, web o mobile con la CLI.
---

<PageBadges />

Esegui `form0`, inserisci `init` e scegli **Progetto standard**, **Applicazione web** o
**Applicazione mobile**. Puoi anche usare direttamente `form0 init [dir]`.

Dopo la creazione, entra nella directory del progetto e segui il README generato.
