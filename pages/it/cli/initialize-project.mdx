---
title: Inizializzare un progetto
description: Crea un progetto form0 standard, web o mobile con la CLI.
---

<PageBadges />

Esegui `form0`, inserisci `init` e scegli il tipo di progetto adatto alla tua applicazione:

- **Progetto standard di schema form0** per schemi, validazione locale, test e anteprima.
- **App web** per lo starter mantenuto React e Vite.
- **App mobile** per lo starter mantenuto React Native ed Expo.

Puoi anche inizializzare direttamente una directory con `form0 init [dir]`. Dopo la creazione, entra
nella directory del progetto e segui il README generato.
