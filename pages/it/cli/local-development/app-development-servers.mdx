---
title: Server di sviluppo delle applicazioni
description: Avvia un'applicazione web o Expo configurata insieme al server di anteprima di form0.
---

<PageBadges />

Usa `form0 serve --app` quando il `form0.config.js` del progetto definisce un server di sviluppo per
l'applicazione. I template web e mobile mantenuti includono già una configurazione adatta.

I progetti Expo possono usare `--public-url` quando un dispositivo deve raggiungere il server di
sviluppo tramite un tunnel o un URL di sviluppo pubblico e stabile.
