---
title: Server di sviluppo delle applicazioni
description: Avvia un’applicazione web o Expo configurata insieme all’anteprima form0.
---

<PageBadges />

Usa `form0 serve --app` quando `form0.config.js` definisce un server di sviluppo dell’applicazione.
Nei progetti Expo, `--public-url` consente di indicare un URL pubblico o raggiungibile tramite
tunnel.
