---
title: Server di anteprima
description: Servi uno schema di modulo in locale con anteprima nel browser e aggiornamenti automatici.
---

<PageBadges />

Esegui `form0 serve [schema]` per avviare il server di anteprima locale. Per impostazione
predefinita usa la porta `3030` ed è in ascolto su `localhost`; `--port` e `--host` modificano
questi valori.

Il server di anteprima è uno strumento di sviluppo. Usa progetti e connettori affidabili, ed
esponilo solo su una rete affidabile.
