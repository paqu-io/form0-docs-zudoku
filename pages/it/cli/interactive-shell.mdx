Esegui `form0` senza argomenti per avviare la shell interattiva. Una sessione può mantenere uno schema
caricato durante convalida, anteprima, esecuzione, osservazione, modifica o servizio.

Usa `help` per elencare i comandi disponibili nella modalità corrente, `status` per ispezionare la
sessione e `exit` per uscire. Comandi come `load`, `schema edit` e `serve` aggiornano il prompt per
mostrare lo stato attivo.

## Sintassi per modalità

| Prompt              | Comportamento dell'input                                                                                  |
| ------------------- | --------------------------------------------------------------------------------------------------------- |
| `form0>`            | Inserisci i comandi della shell senza prefisso.                                                           |
| `form0(server)>`    | Usa i comandi sicuri mostrati da `help`, come `validate`, `preview`, `serve status`, `serve stop` o `ai`. |
| `form0(schema)>`    | Inserisci i comandi dell'editor dello schema senza prefisso.                                              |
| `form0(ai)>`        | Il testo senza prefisso va al modello; le azioni della CLI iniziano sempre con `/`.                       |
| `form0(server,ai)>` | Usa i comandi AI con barra, inclusi `/preview`, `/validate`, `/serve status` e `/serve stop`.             |

Le richieste in linguaggio naturale restano così non ambigue in modalità AI, mentre le altre modalità
mantengono la sintassi concisa.

L'installazione di un connettore è un comando del terminale, non un'azione della shell interattiva:

```bash
form0 connector install <name-or-path>
form0 connector --help
```

Nella shell, usa `connector help` per caricare, configurare, testare e controllare i connettori.
