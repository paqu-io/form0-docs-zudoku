## Catalogo dei provider

form0 usa il catalogo di provider e modelli di Pi senza rinominare i provider né modificarne le
capacità di autenticazione. Il catalogo può cambiare con la versione bloccata della dipendenza Pi;
consulta la versione installata invece di affidarti a un elenco statico.

```ansi
form0(ai)> /providers
form0(ai)> /models <provider>
```

La base dell'anteprima, verificata manualmente, comprende:

- OpenAI con una chiave API
- OpenAI Codex con OAuth dell'abbonamento
- Anthropic con una chiave API o con OAuth dell'abbonamento Claude
- Google Gemini con una chiave API
- OpenRouter con una chiave API o OAuth
- Modelli locali Ollama

Altri provider esposti da Pi possono funzionare, ma non fanno parte della base verificata
manualmente.

## Autenticazione

Usa il tipo di autenticazione indicato dal catalogo dei provider:

```ansi
form0(ai)> /login <provider> <api_key|oauth>
```

A seconda del provider, OAuth può offrire un flusso nel browser o tramite codice dispositivo. Le
chiavi API si inseriscono in un prompt nascosto. Le credenziali nelle variabili d'ambiente
riconosciute da Pi restano disponibili.

L'accesso all'API di OpenAI e un abbonamento ChatGPT/Codex sono percorsi di autenticazione distinti.
Usa il provider OpenAI per una chiave API e il provider OpenAI Codex per l'OAuth dell'abbonamento.

L'autenticazione non sceglie automaticamente un modello. Dopo l'accesso, elenca i modelli e
selezionane uno esplicitamente:

```ansi
form0(ai)> /models openai-codex
form0(ai)> /model openai-codex/gpt-5.6-luna
```

## Selezione e persistenza del modello

Il modello selezionato viene registrato nella conversazione Pi associata al percorso canonico dello
schema. Uscendo dalla modalità IA e tornando allo stesso schema, la selezione viene ripristinata.
Non viene salvata nello schema né nella configurazione del progetto.

Usa `/model` senza argomenti o `/status` per controllare la selezione corrente. `/new` e `/clear`
avviano una nuova conversazione mantenendo il modello attivo. Se il modello salvato non esiste più o
la sua autenticazione non è disponibile, la CLI mostra l'avviso di ripiego di Pi.

## Archiviazione locale

Credenziali, dati del catalogo dei modelli e conversazioni sono archiviati in `~/.form0-cli/ai/`. Le
directory sono accessibili solo all'utente corrente, e i file di credenziali e sessioni hanno
permessi riservati all'utente. Le conversazioni salvate possono contenere lo schema completo.

Nulla viene scritto in uno schema form0 finché non si applica una proposta approvata. Le credenziali
dei provider e i modelli scelti non vengono mai aggiunti alla configurazione del progetto.

## Modelli locali e cloud

Il rilevamento di Ollama interroga il servizio locale ed espone tramite Pi i modelli trovati. I
modelli locali restano disponibili quando la policy dello schema blocca i provider cloud. La
selezione di un modello cloud viene rifiutata se il modulo o un campo imposta `allowCloud: false`;
vedi [Privacy e sicurezza](/it/cli/ai-authoring/privacy-security).
