:::warning

La creazione con IA è in anteprima. Comandi, provider, prompt e protocollo di mutazione possono
cambiare prima di una versione stabile. Controlla calcoli e JavaScript degli eventi.

:::

La creazione con IA aggiunge a form0-cli una modalità conversazionale per modificare gli schemi.
Lavora con normali schemi form0: il file finale non contiene conversazioni, provider o mutazioni.

Avviala direttamente con uno schema oppure entra in modalità AI dalla shell interattiva:

```bash
form0 ai [schema]
```

```ansi
form0> serve
form0(server)> ai
form0(server,ai)> Add a calculated total from quantity and unit price
```

La modalità AI non avvia il server di anteprima. Se è già attivo, le bozze convalidate vengono
inviate al browser con l'indicazione **AI draft** senza essere scritte su disco.

## Come funziona la creazione

1. Il modello selezionato riceve il modulo completo e il catalogo del core installato.
2. L'agente propone un batch coerente di mutazioni semantiche invece di sostituire il file.
3. form0-core applica il batch a una copia e convalida l'intero risultato.
4. Una bozza valida può essere ispezionata, rivista, scartata o applicata esplicitamente.
5. L'applicazione ricontrolla la revisione su disco e scrive lo schema atomicamente.

Le proposte non valide non diventano mai bozze. Uscire o scartare ripristina nel browser lo schema
confermato. Il risultato resta un normale schema form0 senza metadati AI aggiunti automaticamente.
