:::warning

La creazione con IA è in anteprima. Comandi, provider disponibili, prompt e protocollo di mutazione
possono cambiare prima di una versione stabile. Controlla i calcoli e il JavaScript degli eventi
generati.

:::

La creazione con IA aggiunge a form0-cli una modalità conversazionale per creare schemi. Funziona
con normali schemi form0: il file finale non contiene la cronologia della conversazione, la
configurazione del provider né dati di mutazione.

Avviala direttamente con uno schema, oppure entra in modalità IA dalla shell interattiva:

```bash
form0 ai [schema]
```

```ansi
form0> serve
form0(server)> ai
form0(server,ai)> Add a calculated total from quantity and unit price
```

La modalità IA non avvia il server di anteprima. Se un server è già in esecuzione, le bozze validate
vengono inviate al browser con l'etichetta di origine **AI draft**, senza essere scritte su disco.

## Come funziona la creazione

1. Il modello selezionato riceve il modulo corrente completo e il catalogo di creazione del form0-core installato.
2. L'agente propone un batch coerente di mutazioni semantiche invece di sostituire il file dello schema.
3. form0-core applica il batch a una copia e valida l'intero risultato.
4. Una bozza valida può essere ispezionata, rivista, scartata o applicata esplicitamente.
5. L'applicazione ricontrolla la revisione su disco e scrive lo schema in modo atomico.

Le proposte non valide non diventano mai bozze. Uscendo o scartando, il browser torna a mostrare lo
schema salvato. Il risultato resta un normale schema form0, senza metadati IA aggiunti
automaticamente.
