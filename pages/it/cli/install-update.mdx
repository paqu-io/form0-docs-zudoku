---
title: Installare e aggiornare
description: Installa form0-cli globalmente o eseguilo temporaneamente con npx.
---

Installa la CLI con `npm install -g form0-cli`, oppure eseguila senza installazione globale con
`npx form0-cli`. Usa lo stesso comando npm per aggiornarla.

Le versioni precedenti alla 1.0 possono includere modifiche incompatibili. Fissa la versione negli
ambienti automatizzati e consulta GitHub Releases prima dell’aggiornamento.
