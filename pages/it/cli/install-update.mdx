---
title: Installare e aggiornare
description: Installa form0-cli globalmente oppure eseguilo temporaneamente con npx.
---

<PageBadges />

La CLI richiede Node.js 22.19.0 o una versione successiva.

Installa la CLI globalmente per rendere disponibile il comando `form0`:

```bash
npm install -g form0-cli
```

In alternativa, puoi eseguirla senza installarla globalmente:

```bash
npx form0-cli
```

Per aggiornare un'installazione globale, usa lo stesso comando npm. Le versioni precedenti alla 1.0
possono introdurre modifiche incompatibili: blocca le versioni negli ambienti automatizzati e
consulta le GitHub Releases prima di aggiornare.
