---
title: Installare e aggiornare
description: Installa form0-cli a livello globale o eseguilo temporaneamente con npx.
---

<PageBadges />

Installare il comando CLI a livello globale per rendere disponibile il comando `form0`:

```bash
npm install -g form0-cli
```

Puoi invece eseguirlo senza un'installazione globale:

```bash
npx form0-cli
```

Utilizzare lo stesso comando npm per aggiornare un'installazione globale.
modifiche, quindi pin versioni in ambienti automatizzati e revisione GitHub Releases prima dell'aggiornamento.
