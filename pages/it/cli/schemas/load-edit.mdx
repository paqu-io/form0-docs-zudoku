---
title: Caricare e modificare gli schemi
description: Carica uno schema nella shell interattiva e modificalo con l'editor configurato.
---

<PageBadges />

Usa `load` per scegliere uno schema in modo interattivo, oppure `load <file>` per indicarlo
direttamente. Con uno schema caricato, `schema edit` lo apre nell'editor configurato tramite
`EDITOR` o `VISUAL`.

La CLI valida le modifiche salvate prima di adottarle. Consulta la
[documentazione degli schemi del nucleo](/it/core/schema/form) per la sintassi di campi e moduli.
