---
title: Importazione ed esportazione CSV
description: Sposta le definizioni schema tra JSON e la rappresentazione CSV di CLI.
---

<PageBadges />

Utilizzare `form0 schema export` per creare una rappresentazione CSV di JSON schema e `form0 schema import`
per convertirlo in JSON.

Entrambi i comandi supportano percorsi di input o output espliciti e `--force` per la sostituzione intenzionale.
Convalidare e rivedere lo schema generato dopo averlo convertito.
