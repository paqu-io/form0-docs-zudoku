---
title: Importare ed esportare CSV
description: Converti le definizioni degli schemi dei moduli tra JSON e la rappresentazione CSV della CLI.
---

<PageBadges />

Usa `form0 schema export` per creare una rappresentazione CSV di uno schema JSON e
`form0 schema import` per riconvertirla in JSON.

Entrambi i comandi accettano percorsi di input o di output espliciti e `--force` per una
sostituzione intenzionale. Valida e revisiona lo schema generato dopo la conversione.
