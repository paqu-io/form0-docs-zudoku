Crea un progetto form0, avvia il server di sviluppo e apri un'anteprima live. Questo flusso utilizza solo la CLI e il template di schema incluso di default.

## Prerequisiti
- **Node.js** `20.0.0+` - [Scaricalo qui](https://nodejs.org/)
- Un terminale o prompt dei comandi
- Il tuo editor di codice preferito

## Pronto in 5 passaggi
Crea e visualizza il tuo primo schema form0 in pochi minuti.

<Stepper>

1. Installa la CLI:

   ```bash
   npm install -g @paqu-io/form0-cli@latest
   ```
   :::caution

   **form0 non è ancora pubblico.** Il pacchetto npm è privato, quindi dovrai:

   - Richiedere l'accesso inviando un'email a [hello@paqu.io](mailto:hello@paqu.io)
   - Una volta approvato, accedi a npm dal tuo terminale:
      ```bash
      npm login
      ```
   - Inserisci username, password ed email di npm quando richiesto.

   :::

   Oppure eseguila senza installarla globalmente:

   ```bash
   npx @paqu-io/form0-cli@latest
   ```
   :::info

   Il comando npx esegue la CLI senza bisogno di un'installazione globale.

   :::

1. Avvia la shell interattiva:

   ```bash
   form0
   ```

1. Inizializza un progetto standard:

   - Esegui `init`
   - Scegli **Standard project**
   - Lascia che la CLI carichi automaticamente il tuo schema

   :::info

   Se nella root del progetto c'è un solo file di schema, viene caricato automaticamente.

   :::

1. Avvia il server di sviluppo:

   ```ansi
   form0> serve
   ```

1. 🎉 **Fatto!** Ora la tua anteprima live di form0 è in esecuzione su `http://localhost:3030` nel tuo browser.

</Stepper>

## Cosa ottieni
I progetti standard sono basati su file e gestiti dalla CLI.

- `form.schema.json` con un form di esempio
- `form0.config.js` per le impostazioni della CLI
- `test.js` per verifiche locali del motore
- `supporting-images/` per le risorse grafiche dei campi
