## Expo informa de dependencias incompatibles

Usa los comandos de Expo que tienen en cuenta la compatibilidad en lugar de instalar versiones
arbitrarias de paquetes nativos:

```bash
npx expo install --check
npx expo-doctor@latest
```

Usa `npx expo install --fix` solo después de revisar los cambios propuestos. Trata cada
actualización del SDK de Expo como una migración y sigue la guía de actualización del SDK.

## Un dispositivo no puede abrir el proyecto

Comprueba que el dispositivo puede llegar al ordenador de desarrollo por la LAN. Revisa los
cortafuegos, las VPN, el aislamiento de clientes de la Wi-Fi, el puerto configurado y si el cliente
espera Expo Go o una development build. Si usas una URL pública, comprueba que no devuelva una
página intersticial antes de los endpoints de Expo. Expo Go admite una sola línea del SDK a la vez,
y la distribución compatible varía según la plataforma. Crea una nueva development build después de
cambiar el SDK de Expo o las dependencias nativas.

## Falta una imagen de apoyo

Comprueba que su ruta coincide con la del esquema, coloca los recursos empaquetados en
`assets/supporting-images` y ejecuta `npm run generate-images`. Haz commit del registro regenerado y
reinicia Metro cuando el grafo de módulos esté desactualizado.

## Las fuentes o los módulos nativos no se cargan

Espera a `useFonts(form0Fonts)` antes de renderizar. Instala los paquetes de Expo con
`npx expo install` y usa una development build para los módulos nativos que no están disponibles en
Expo Go.

## Fallan las escrituras en SQLite

Valida `databaseName` y `tableName`, revisa los logs del dispositivo y activa temporalmente la
salida de depuración del almacenamiento. Los nombres de tabla solo admiten letras, dígitos y guiones
bajos; los valores no válidos vuelven al valor predeterminado. Recuerda que borrar los datos de la
aplicación elimina la base de datos del sandbox.

Para los fallos específicos de los componentes, continúa con
[Solución de problemas de React Native](/es/bindings/react-native/troubleshooting).
