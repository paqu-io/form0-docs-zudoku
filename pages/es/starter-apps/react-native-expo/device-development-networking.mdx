El `form0.config.js` predeterminado inicia Expo en la red local. Un dispositivo físico debe poder
llegar al ordenador de desarrollo y al puerto 8081. Los cortafuegos del equipo, las redes Wi-Fi
aisladas, las VPN y las redes de contenedores pueden impedir esa conexión.

## Inicia con form0-cli

Usa la integración con el servidor de la aplicación cuando trabajes desde la CLI de form0:

```bash
form0 serve --app
```

La CLI lee el bloque `devServer` de `form0.config.js`. El comportamiento completo del comando se
describe en la
[referencia de los servidores de desarrollo de aplicaciones](/es/cli/local-development/app-development-servers).

## Anuncia una URL pública de desarrollo

Cuando no tengas acceso por LAN, establece la variable de entorno configurada en `.env.local`:

```text
FORM0_APP_PUBLIC_URL=https://your-development-domain.example
```

Inicia el túnel por separado y, después, ejecuta `form0 serve --app`. Para una sola ejecución, usa
`--public-url https://your-development-domain.example`.

La URL debe servir directamente el manifiesto de Expo, el bundle, los recursos y el tráfico
WebSocket. Las páginas intersticiales del navegador y las de verificación de acceso impiden que
funcionen los clientes de Expo. Nunca uses un túnel de desarrollo como despliegue de producción ni
incluyas credenciales con privilegios en el bundle móvil.

Usa una [development build](https://docs.expo.dev/develop/development-builds/introduction/) para el
trabajo orientado a producción o con código nativo personalizado. Expo Go es un cliente opcional
para aprender y evaluar cuando hay una versión compatible del SDK para la plataforma de destino.
