## Incluido Tienda SQLite

El starter guarda los registros enviados estructurados con `expo-sqlite`.
el bloque `storage` en `form0.config.js`:

```js
storage: {
  enabled: true,
  databaseName: "form0.db",
  tableName: "form0_submissions",
  debug: false,
}
```

La base de datos vive en el sandbox de aplicaciones específicas de la plataforma. Cada submission se inserta con
los metadatos del registro y el registro estructurado completo como JSON.
o borrar registros cuando `debug` está habilitado.

## Persistencia no es sincronización

Esta tienda solo proporciona persistencia en el dispositivo. No carga registros, reintenta solicitudes, resuelve
conflictos, cifrar las exportaciones, o definir la política de retención y eliminación.
Trate las copias de seguridad de la base de datos y los archivos exportados como confidenciales.
datos de usuario.

Los paquetes Node.js `form0-connector-pg` y `form0-connector-sqlite` no se ejecutan en React Native.
Enviar submissions remoto a través de una aplicación autenticada API; no incrustar credenciales de base de datos
en una aplicación móvil.

Para los contratos renderer y submission, véase
[Valores, snapshots, y submission](/es/bindings/react-native/values-snapshots-submission). Para general
límites móviles, véase [Integración móvil](/es/bindings/react-native/mobile-integration).
