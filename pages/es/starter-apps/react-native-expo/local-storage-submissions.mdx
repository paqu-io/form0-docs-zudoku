## Almacén SQLite incluido

El starter guarda los registros estructurados enviados con `expo-sqlite`. Configúralo o desactívalo
mediante el bloque `storage` de `form0.config.js`:

```js
storage: {
  enabled: true,
  databaseName: "form0.db",
  tableName: "form0_submissions",
  debug: false,
}
```

La base de datos se guarda en el sandbox de la aplicación propio de cada plataforma. Cada envío se
inserta con los metadatos del registro y el registro estructurado completo en formato JSON. Los
controles de depuración incluidos permiten listar o borrar registros cuando `debug` está activado.

## Persistencia no es sincronización

Este almacén solo ofrece persistencia en el dispositivo. No sube registros, no reintenta peticiones,
no resuelve conflictos, no cifra las exportaciones ni define políticas de conservación y
eliminación. Las aplicaciones deben diseñar esos comportamientos según sus datos y su modelo de
amenazas. Trata las copias de seguridad de la base de datos y los archivos exportados como datos de
usuario sensibles.

Los paquetes de Node.js `form0-connector-pg` y `form0-connector-sqlite` no se ejecutan en React
Native. Envía los datos remotos mediante una API autenticada de la aplicación; no incluyas
credenciales de bases de datos en una aplicación móvil.

Para el contrato de envío y de snapshots del renderer, consulta
[Valores, snapshots y envío](/es/bindings/react-native/values-snapshots-submission). Para los
límites generales en móvil, consulta [Integración móvil](/es/bindings/react-native/mobile-integration).
