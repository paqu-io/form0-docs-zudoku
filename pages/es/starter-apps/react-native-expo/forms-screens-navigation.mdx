## Formularios de registro

Esquemas en vivo bajo `src/forms`. Agregue cada formulario a `src/forms/registry.js` con un ID estable, pantalla
metadatos, y una función `loadSchema`. Las importaciones estáticas son útiles para la primera pantalla; dinámico
Las importaciones pueden diferir la carga de otros formularios.

`useFormSchema` resuelve la entrada del registro seleccionada y expone su carga, schema, y error
Valide schemas con [form0-cli](/es/cli/schemas/validate-preview) antes de enviarlos.

## Entender el flujo de la pantalla

El starter utiliza deliberadamente un pequeño flujo basado en estado:

```text
App → Home → FormPage → Form0Form
```

`Home` enumera los formularios registrados. `FormPage` carga el schema y posee submission y depurador de almacenamiento
`Form0Form` mapea la configuración de la aplicación en el React Native `FormRenderer`.

Este es un punto de partida comprensible, no un enrutamiento framework. Reemplazar el estado `activeFormId`
con el router o la biblioteca de navegación utilizada por su aplicación cuando necesita enlaces profundos, pestañas,
pilas autenticadas, o estado de navegación restaurado.

El renderer posee pantallas de desplazamiento, evitación de teclado y profundización dentro de su pantalla asignada
área. Evite envolverlo en otra vista de desplazamiento vertical. Ver
[Modos y navegación](/es/bindings/react-native/modes-navigation) para el contrato renderer.
