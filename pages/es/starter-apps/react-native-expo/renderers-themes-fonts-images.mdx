## Tema y fuentes

La raíz de la aplicación carga `form0Fonts` con `expo-font` antes de renderizar y envuelve su
interfaz en `ThemeProvider`. Configura el modo de color base y las sustituciones de tema opcionales
en `form0.config.js`. Las pantallas del starter que rodean al formulario usan los mismos tokens de
tema que el formulario.

## Sustitución de renderers

Asocia los tipos de campo del esquema con identificadores de renderer en `form0.config.js` y, después,
asocia esos identificadores con componentes en `src/field-renderers/resolver.js`. Mantener los
componentes fuera del archivo de configuración conserva una configuración serializable y fácil de
procesar con herramientas.

Para las propiedades de los renderers y el funcionamiento del registro, consulta la
[documentación de los renderers personalizados](/es/bindings/react-native/custom-renderers).

## Imágenes de apoyo

React Native exige que las referencias a imágenes empaquetadas se puedan detectar de forma
estática. Añade los archivos en `assets/supporting-images` y, después, vuelve a generar la tabla de
búsqueda:

```bash
npm run generate-images
```

Haz commit tanto del recurso como de `src/supporting-images/index.js`. Los scripts de inicio vuelven
a generar el archivo, y la CI verifica que el registro incluido en el repositorio está actualizado.
Las rutas de imagen HTTP y HTTPS remotas no necesitan entradas en el registro.

Consulta [Temas, fuentes e imágenes](/es/bindings/react-native/themes-assets) para las API del
binding.
