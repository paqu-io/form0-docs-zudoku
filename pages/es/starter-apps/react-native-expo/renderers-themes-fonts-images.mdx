## Tema y fuentes

La raíz de la aplicación carga `form0Fonts` con `expo-font` antes de renderizar y envuelve su interfaz de usuario en
`ThemeProvider` . Configure el modo de color base y el tema opcional se anula en `form0.config.js` .
Las pantallas circundantes de starter usan los mismos tokens de tema que el formulario.

## El renderizador anula

Asignar tipos de campo schema a identificadores renderer en `form0.config.js`, luego asignar esos identificadores a
componentes en `src/field-renderers/resolver.js`. Mantener los componentes fuera del archivo de configuración
preserva un límite de configuración fácil de serializar y fácil de usar.

Para los accesorios y el comportamiento de registro de renderer, utilice la
[custom renderer documentación](/es/bindings/react-native/custom-renderers).

## Imágenes de apoyo

React Native requiere referencias de imágenes agrupadas para poder ser descubiertas estáticamente.
`assets/supporting-images`, luego regenerar la tabla de búsqueda:

```bash
npm run generate-images
```

Comprometer tanto el activo como `src/supporting-images/index.js`. Los scripts de inicio regeneran el archivo,
y CI verifica que el registro comprometido esté actualizado. Las rutas de imagen HTTP y HTTPS remotas no
necesita entradas de registro.

Consulte [Temas, fuentes e imágenes](/es/bindings/react-native/themes-assets) para las API de nivel binding.
