El starter de React Native y Expo es la forma más rápida de tener una aplicación móvil con form0.
Incluye esquemas de ejemplo, renderers nativos, fuentes, imágenes de apoyo y persistencia local con
SQLite.

## Crea la aplicación

Instala [form0-cli](/es/cli/install-update) y, a continuación, inicializa un proyecto:

```bash
npm install --global form0-cli
form0 init my-mobile-form
```

Elige **Aplicación móvil** y **React Native + Expo**. Entra en el directorio generado e instala sus
dependencias si el gestor de paquetes elegido no lo ha hecho ya.

```bash
cd my-mobile-form
npm install
npm start
```

El botón **Use this template** de GitHub es una alternativa cuando quieres expresamente una copia
del repositorio. La CLI sigue siendo la vía de creación recomendada.

## Elige un destino de desarrollo

Usa una development build de Expo para el trabajo orientado a producción y siempre que la aplicación
incluya código nativo personalizado. Expo Go sigue siendo útil para aprender y evaluar cuando hay
una versión compatible del SDK para la plataforma de destino. También puedes usar un emulador de
Android, el simulador de iOS o el destino web:

```bash
npm run android
npm run ios
npm run web
```

La plantilla utiliza Expo SDK 58, React Native 0.88 y React 19.3. Usa una versión compatible de
Node.js 22 (22.13+) o 24 (24.3+). Las compilaciones nativas admiten Android 7 o posterior e iOS 16.4
o posterior; las compilaciones locales de iOS requieren Xcode 26.4 o posterior. Expo Go debe
coincidir con la versión del SDK del proyecto. La configuración de emuladores y dispositivos sigue la
[guía del entorno de desarrollo de Expo](https://docs.expo.dev/get-started/set-up-your-environment/).
