Las aplicaciones starter son bases de aplicación mantenidas que combinan los paquetes de form0 con
enrutamiento, configuración, estilos y convenciones de desarrollo local. Son útiles cuando quieres
partir de una aplicación que ya funciona y personalizarla, en lugar de añadir un binding a un
proyecto existente.

| Starter             | Ideal para                                                                                  | Código fuente                                                            |
| ------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| React + Vite        | Aplicaciones de navegador, formularios web personalizados y alojamiento estático            | [GitHub](https://github.com/paqu-io/form0-web-tmpl-react-vite)           |
| React Native + Expo | Aplicaciones para iOS y Android, funciones del dispositivo y flujos de trabajo sin conexión | [GitHub](https://github.com/paqu-io/form0-mobile-tmpl-react-native-expo) |

## Vía de creación recomendada

Usa [form0-cli](/es/cli/overview) para crear un starter. La CLI te guía en la elección del tipo de
proyecto y del gestor de paquetes, y genera un repositorio de aplicación normal que te pertenece.

```bash
npm install --global form0-cli
form0 init my-form-app
```

El botón **Use this template** de GitHub también está disponible cuando quieres crear expresamente
un repositorio a partir del starter de origen. La CLI sigue siendo la vía de incorporación
canónica.

Las guías de los starters explican la aplicación que rodea a form0. Para las API de los paquetes,
consulta la [documentación de los bindings de React y React Native](/es/bindings/overview). Para el
comportamiento de los esquemas, consulta la [documentación del núcleo](/es/core/overview).
