Las aplicaciones de inicio son bases de aplicaciones mantenidas que combinan paquetes form0 con enrutamiento,
configuración, estilo y convenciones de desarrollo local. Son útiles cuando se
aplicación para personalizar en lugar de agregar un binding a un proyecto existente.

| Arranque            | Mejor para                                                                                            | Fuente                                                                   |
| ------------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| React + Vite        | Aplicaciones de navegador, formularios web personalizados y alojamiento estático                      | [GitHub](https://github.com/paqu-io/form0-web-tmpl-react-vite)           |
| React Native + Expo | Aplicaciones iOS y Android, capacidades de dispositivos y flujos de trabajo orientados fuera de línea | [GitHub](https://github.com/paqu-io/form0-mobile-tmpl-react-native-expo) |

## Ruta de creación recomendada

Utilice [form0-cli](/es/cli/overview) para crear un starter. El CLI guía el proyecto y el administrador de paquetes
selección y produce un repositorio de aplicaciones normal que usted posee.

```bash
npm install --global form0-cli
form0 init my-form-app
```

** de GitHub Utilice esta plantilla El botón ** también está disponible cuando desee crear una
Repositorio desde la fuente starter . El CLI sigue siendo la ruta canónica de incorporación.

Las guías de inicio explican la aplicación en torno a form0. Para las API de paquetes, use la
[React y React Native binding documentación](/bindings/overview) . por schema comportamiento, utilice el
[Core documentación](/es/core/overview).
