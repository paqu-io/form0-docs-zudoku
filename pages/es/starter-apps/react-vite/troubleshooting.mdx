## Una ruta de formulario dice que el formulario no se encontró

Confirme que el identificador URL coincide exactamente con una entrada en `src/forms/registry.js`.
que su importación dinámica apunta a un archivo schema existente.

## Un schema no se carga

Abra la consola del navegador para el error de importación, a continuación, ejecute la validación schema a través de form0-cli.
Los errores de sintaxis y las rutas de importación relativas incorrectas son las causas más comunes.

```bash
form0
```

Cargue el schema y ejecute `validate`. Consulte [Validar y previsualizar](/es/cli/schemas/validate-preview).

## No se utiliza un renderer personalizado

Compruebe los tres nombres: el tipo de campo schema, su asignación en `form0.config.js` y el resolutor
identificador en `src/field-renderers/resolver.js`. El solucionador registra una advertencia para identificadores desconocidos.

## Las presentaciones no pueden llegar al servidor CLI

Ejecute `form0 serve --app` desde el directorio del proyecto. Si el servidor CLI utiliza una dirección diferente, establezca
`FORM0_DEV_API_URL` antes de iniciar Vite o en el archivo `.env` local correspondiente. Confirme que
`devServer.apiBaseUrl` todavía coincide con la ruta proxy Vite.

## La evaluación de los trabajadores falla

Ajusta temporalmente `engine.mode` a `main-thread` para aislar la carga de worker del comportamiento de schema.
verifique la consola del navegador, las rutas de los activos y el tipo de contenido de implementación. Ver
[Trabajadores y rendimiento](/es/bindings/react/workers-performance).

## Los enlaces directos devuelven 404 después de la implementación

Configure el host estático para que vuelva a `index.html` para las rutas de aplicación desconocidas.
problema de configuración, no un problema de definición de ruta React.

Para fallas de renderización a nivel de paquete, continúe con
[React solución de problemas](/es/bindings/react/troubleshooting). Para los fallos de la base de datos, utilizar
[Conector solución de problemas](/es/connectors/troubleshooting).
