`Form0Form` proporciona un controlador predeterminado de submission cuando el llamante no proporciona `onSubmit`.
El controlador crea o acepta un registro estructurado form0 y lo registra para su desarrollo.

Cuando `devServer.submitToConnector` es `true`, también llama a dos puntos finales locales:

1. `POST /api/create-record` cuando el renderer aún no ha producido un registro estructurado completo.
2. `POST /api/submit-record` para enviar ese registro a los conectores administrados por form0-cli.

El proxy Vite reenvía `/api` al servidor de desarrollo CLI. Inicie ambos procesos con:

```bash
form0 serve --app
```

## Comportamiento de la aplicación de suministro submission

Pase `onSubmit` a `Form0Form` para reemplazar el controlador predeterminado.
`useDefaultSubmitHandler={false}` si el formulario debe procesarse sin ninguna ruta submission.

Para obtener el registro de devolución de llamada completo y el contrato de metadatos, consulte
[Valores, snapshots y submission](/es/bindings/react/values-snapshots-submission).

> [!ADVERTENCIA]
> Los terminales CLI y el proxy Vite son ayudantes de desarrollo local, no un submission de producción.
> Una aplicación implementada necesita un límite de servidor de confianza con autenticación, autorización,
> validación, limitación de velocidad y controles de almacenamiento adecuados. Nunca envíe credenciales de base de datos a
> código del navegador.

Solo use schemas de autores de confianza. Las expresiones de esquema se ejecutan dentro del documento
[Límite de confianza form0-core](/es/core/security).
