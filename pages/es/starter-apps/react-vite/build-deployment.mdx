Crea y previsualiza una compilación de producción en local:

```bash
npm run build
npm run preview
```

Vite escribe la salida estática en `dist`. Despliega ese directorio en un alojamiento estático o
sírvelo detrás del servidor de tu aplicación.

## Requisitos del alojamiento

El starter usa enrutamiento en el navegador. Configura el alojamiento para que sirva `index.html`
como alternativa en las rutas de la aplicación, como `/contact/standard`; de lo contrario, al
acceder directamente a esas URL se puede obtener la página 404 del alojamiento.

El proxy de conectores predeterminado solo existe en el servidor de desarrollo. En producción, el
envío debe usar un endpoint de servidor propio de la aplicación. Configura ese endpoint de forma
explícita, en lugar de dar por hecho que el proxy `/api` de desarrollo seguirá existiendo tras el
despliegue.

## Antes del despliegue

- Ejecuta `npm run lint` y `npm run build`.
- Revisa el aviso de tamaño del bundle generado e introduce la división de código cuando el crecimiento de la aplicación haga que la descarga inicial sea excesiva.
- Mantén los archivos `.env` locales fuera del control de versiones.
- Comprueba que no haya secretos incrustados en los recursos generados.
- Prueba el acceso directo a cada ruta pública de la aplicación.
- Revisa la [política de seguridad](https://github.com/paqu-io/form0-web-tmpl-react-vite/blob/main/SECURITY.md).

Los valores de entorno de Vite destinados al código del navegador se incrustan de forma estática
durante la compilación. Trátalos como configuración pública, aunque procedan de un archivo de
entorno local.
