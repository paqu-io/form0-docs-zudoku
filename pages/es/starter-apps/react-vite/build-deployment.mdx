Crear y previsualizar una compilación de producción localmente:

```bash
npm run build
npm run preview
```

Vite escribe la salida estática en `dist`. Implemente ese directorio con un host estático o colóquelo detrás
su servidor de aplicaciones.

## Requisitos de alojamiento

El starter utiliza el enrutamiento del navegador. Configure el host para que sirva a `index.html` como alternativa para
rutas de aplicación como `/contact/standard`; de lo contrario, la navegación directa a esas URL puede
Devuelve la página 404 del host.

El proxy de conector predeterminado solo existe en el servidor de desarrollo. Producción submission debe usar
Configure ese punto final explícitamente en lugar de asumir el valor de la aplicación.
El proxy `/api` estará presente después de la implementación.

## Antes del despliegue

- Ejecute `npm run lint` y `npm run build`.
- Revise la advertencia de tamaño de paquete generada e introduzca la división de código cuando crezca la aplicación
  hace que la descarga inicial sea inapropiada.
- Mantenga los archivos locales `.env` fuera del control de versiones.
- Confirme que no hay secretos incrustados en los activos generados.
- Pruebe la navegación directa a cada ruta de aplicación pública.
- Revisar la [política de seguridad](https://github.com/paqu-io/form0-web-tmpl-react-vite/blob/main/SECURITY.md).

Los valores de entorno Vite destinados al código del navegador están incorporados estáticamente en el momento de la compilación.
como configuración pública, incluso cuando se originan en un archivo de entorno local.
