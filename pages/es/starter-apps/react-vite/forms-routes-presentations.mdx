Los archivos de esquema viven bajo `src/forms`. El registro en `src/forms/registry.js` da a cada forma un
ruta de la aplicación, mostrar metadatos, una importación dinámica de schema y valores iniciales opcionales.

```js
const forms = [
  {
    id: "contact",
    title: "Contact us",
    description: "Send a message to the team.",
    loadSchema: () => import("./contact/schema.json"),
  },
]
```

Cree el archivo schema correspondiente, luego agregue la entrada del registro. Las importaciones dinámicas mantienen los archivos schema en
Separar los fragmentos de compilación.

## Rutas

El starter proporciona:

- `/` para la lista de formularios y ejemplos de superposición;
- `/:formId` para la presentación estándar predeterminada; y
- `/:formId/:variant` para presentaciones de páginas `standard` o `simplified`.

`FormPage` valida el identificador de formulario y la presentación antes de cargar el schema . `Home` posee el
ejemplos modales y de focos.

## Presentaciones

Las cuatro claves de presentación incluidas son:

| Clave        | Colocación                    |
| ------------ | ----------------------------- |
| `standard`   | Página de formulario completo |
| `simplified` | Página paso a paso            |
| `modal`      | Superposición de diálogo      |
| `spotlight`  | Sobrecubierta de cajón        |

Los valores predeterminados de diseño para cada presentación están activos en `form0.config.js`.
