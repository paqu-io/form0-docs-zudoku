Los archivos de esquema están en `src/forms`. El registro de `src/forms/registry.js` asigna a cada
formulario una ruta de la aplicación, metadatos de visualización, una importación dinámica del
esquema y valores iniciales opcionales.

```js
const forms = [
  {
    id: "contact",
    title: "Contact us",
    description: "Send a message to the team.",
    loadSchema: () => import("./contact/schema.json"),
  },
]
```

Crea el archivo de esquema correspondiente y, después, añade la entrada al registro. Las
importaciones dinámicas mantienen los archivos de esquema en fragmentos de compilación separados.

## Rutas

El starter ofrece:

- `/` para la lista de formularios y los ejemplos de overlay;
- `/:formId` para la presentación estándar predeterminada; y
- `/:formId/:variant` para las presentaciones de página `standard` o `simplified`.

`FormPage` valida el identificador del formulario y la presentación antes de cargar el esquema.
`Home` se encarga de los ejemplos modal y spotlight.

## Presentaciones

Las cuatro claves de presentación incluidas son:

| Clave        | Ubicación                     |
| ------------ | ----------------------------- |
| `standard`   | Página de formulario completa |
| `simplified` | Página paso a paso            |
| `modal`      | Overlay de diálogo            |
| `spotlight`  | Overlay de panel lateral      |

Los valores predeterminados de diseño de cada presentación están en `form0.config.js`. El
componente envoltorio de la aplicación pasa a `FormRenderer` el tema, la ubicación, el modo de
interacción y el tamaño resueltos.

Consulta [Editar tu primer esquema](/es/getting-started/schema-edit) para crear esquemas y
[Modos, ubicación y navegación](/es/bindings/react/modes-placement-navigation) para el
comportamiento subyacente del binding de React.
