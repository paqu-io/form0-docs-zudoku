## Necesidades

- Node.js 22 o más reciente
- Un administrador de paquetes compatible; la fuente starter confirma un archivo de bloqueo npm
- Un navegador moderno

## Crear la aplicación

Instale el CLI, luego inicialice un proyecto web:

```bash
npm install --global form0-cli
form0 init my-form-app
```

Elija ** Aplicación web ** y ** React + Vite ** cuando se le solicite. Ingrese el directorio generado, instale su
dependencias si el flujo seleccionado aún no lo ha hecho, e iniciar la aplicación:

```bash
cd my-form-app
npm install
npm run dev
```

Abra el URL impreso por Vite, normalmente `http://localhost:5173`.
ejemplos de formularios y sus presentaciones de página y superposición.

## Ejecutar con form0-cli

Desde el directorio del proyecto, `form0 serve --app` inicia el servidor de aplicaciones configurado junto
Utilice este modo cuando desee que el controlador predeterminado de starter submission
llegar a conectores configurados localmente.

```bash
form0 serve --app
```

Ver [Servidores de desarrollo de aplicaciones](/es/cli/local-development/app-development-servers) y
[Envíos y conectores](/es/starter-apps/react-vite/submissions-connectors) para el límite
entre la aplicación del navegador, el servidor CLI y el conector de la base de datos.
