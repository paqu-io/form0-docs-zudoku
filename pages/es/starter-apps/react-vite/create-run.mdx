## Requisitos

- Node.js 22 o posterior
- Un gestor de paquetes compatible; el starter de origen incluye un archivo de bloqueo de npm
- Un navegador moderno

## Crea la aplicación

Instala la CLI y, a continuación, inicializa un proyecto web:

```bash
npm install --global form0-cli
form0 init my-form-app
```

Elige **Aplicación web** y **React + Vite** cuando se te pida. Entra en el directorio generado,
instala sus dependencias si el flujo elegido no lo ha hecho ya e inicia la aplicación:

```bash
cd my-form-app
npm install
npm run dev
```

Abre la URL que muestra Vite, normalmente `http://localhost:5173`. La página de inicio enumera los
formularios de ejemplo incluidos y sus presentaciones en página y en overlay.

## Ejecuta con form0-cli

Desde el directorio del proyecto, `form0 serve --app` inicia el servidor de la aplicación
configurado junto con el servidor de desarrollo de la CLI. Usa este modo cuando quieras que el
manejador de envío predeterminado del starter llegue a los conectores configurados en local.

```bash
form0 serve --app
```

Consulta [Servidores de desarrollo de aplicaciones](/es/cli/local-development/app-development-servers)
y [Envíos y conectores](/es/starter-apps/react-vite/submissions-connectors) para ver dónde termina la
aplicación de navegador y dónde empiezan el servidor de la CLI y el conector de base de datos.
