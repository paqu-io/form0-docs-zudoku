La plantilla es una aplicación Vite normal. Los valores predeterminados de form0 están en
`form0.config.js` y el código de la aplicación permanece en `src`.

```text
.
├── form0.config.js
├── src/
│   ├── components/        # wrappers y primitivas de interfaz
│   ├── field-renderers/   # renderizadores propios de la aplicación
│   ├── forms/             # esquemas, registro y cargador
│   ├── pages/             # páginas y rutas
│   ├── styles/            # estilos adicionales de form0
│   └── themes/            # temas opcionales de Vanilla Extract
└── vite.config.js         # plugins, alias y proxy local
```

## Áreas de configuración

`form0.config.js` controla el layout, el modo y almacenamiento del motor, el tema, la interacción,
el directorio de esquemas, el servidor de desarrollo, los renderizadores de campos y el formato de
salida. Las props de un componente pueden sustituir los valores pertinentes para un formulario.

> [!CAUTION]
> Mantén `engine.store` en `snapshot`. La configuración incluida documenta una limitación conocida
> de los mensajes de validación con el modo `selector`.

## Proxy de desarrollo

Vite reenvía `/api` a `http://localhost:3030` por defecto. Define `FORM0_DEV_API_URL` en el entorno
del proceso o en un archivo `.env` local de Vite para usar otra dirección. El valor solo se consume
en la configuración de Vite y no se expone al navegador.

No guardes credenciales en variables del cliente. Las credenciales de base de datos pertenecen al
entorno de la CLI o del servidor descrito en [Conectores](/es/connectors/overview).
