Crea un proyecto form0, inicia el servidor de desarrollo y abre una vista previa en vivo. Este flujo utiliza únicamente la CLI y la plantilla de esquema predeterminada que incluye.

## Requisitos previos

- **Node.js** `22.19.0+` - [Descárgalo aquí](https://nodejs.org/)
- Una terminal o símbolo del sistema
- Tu editor de código favorito

## Listo en 5 pasos

Crea y previsualiza tu primer esquema de form0 en pocos minutos.

<Stepper>

1. Instala la CLI:

   ```bash
   npm install -g form0-cli
   ```

   También puedes ejecutarla sin instalarla globalmente:

   ```bash
   npx form0-cli
   ```

   :::info

   El comando npx ejecuta la CLI sin necesidad de una instalación global.

   :::

1. Inicia la shell interactiva:

   ```bash
   form0
   ```

1. Inicializa un proyecto estándar:

   - Ejecuta `init`
   - Selecciona **Proyecto estándar de esquema form0**
   - Deja que la CLI cargue tu esquema automáticamente

   :::info

   Si solo hay un archivo de esquema en la raíz del proyecto, se carga automáticamente.

   :::

1. Inicia el servidor de desarrollo:

   ```ansi
   form0> serve
   ```

1. 🎉 **¡Listo!** La vista previa en vivo de form0 ya se está ejecutando en `http://localhost:3030` en tu navegador.

</Stepper>

## Qué obtienes

Los proyectos estándar se basan en archivos y se gestionan desde la CLI.

- `form.schema.json` con un formulario de ejemplo
- `form0.config.js` para la configuración de la CLI
- `test.js` para pruebas locales del motor
- `supporting-images/` para recursos gráficos de los campos
