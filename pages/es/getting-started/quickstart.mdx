Crea un proyecto form0, inicia el servidor de desarrollo y abre una vista previa en vivo. Este flujo utiliza únicamente la CLI y la plantilla de esquema que viene incluida.

## Requisitos previos

- **Node.js** `22.0.0+` - [Descárgalo aquí](https://nodejs.org/)
- Una terminal o símbolo del sistema
- Tu editor de código favorito

## Listo en 5 pasos

Crea y visualiza tu primer esquema form0 en minutos.

<Stepper>

1. Instala la CLI:

   ```bash
   npm install -g form0-cli
   ```

   También puedes ejecutarla sin instalarla globalmente:

   ```bash
   npx form0-cli
   ```

   :::info

   El comando npx ejecuta la CLI sin necesidad de una instalación global.

   :::

1. Inicia la shell interactiva:

   ```bash
   form0
   ```

1. Inicializa un proyecto estándar:

   - Ejecuta `init`
   - Selecciona **Standard project**
   - Deja que la CLI cargue tu esquema automáticamente

   :::info

   Si solo hay un archivo de esquema en la raíz del proyecto, se carga automáticamente.

   :::

1. Inicia el servidor de desarrollo:

   ```ansi
   form0> serve
   ```

1. 🎉 **¡Listo!** Ahora tu vista previa en vivo de form0 está corriendo en `http://localhost:3030` en tu navegador.

</Stepper>

## Qué obtienes

Los proyectos estándar están orientados a archivos y se gestionan desde la CLI.

- `form.schema.json` con un formulario de ejemplo
- `form0.config.js` para la configuración de la CLI
- `test.js` para pruebas locales del motor
- `supporting-images/` para recursos gráficos de los campos
