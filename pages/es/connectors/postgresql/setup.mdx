---
title: Instalación y configuración de PostgreSQL
description: Instala y configura el conector oficial para PostgreSQL.
---

<PageBadges />

Instala y configura el conector desde la CLI interactiva:

```text
form0> connector install form0-connector-pg
form0> connector configure form0-connector-pg
form0> connector test form0-connector-pg
```

Para usarlo directamente, instálalo con `npm install form0-connector-pg`.

Los ajustes obligatorios son el nombre de la base de datos, el usuario y la contraseña. El host
predeterminado es `localhost` y el puerto predeterminado es `5432`.

| Variable de entorno                          | Finalidad                                    | Valor predeterminado         |
| -------------------------------------------- | -------------------------------------------- | ---------------------------- |
| `FORM0_CONNECTOR_PG_HOST`                    | Host de PostgreSQL                           | `localhost`                  |
| `FORM0_CONNECTOR_PG_PORT`                    | Puerto de PostgreSQL                         | `5432`                       |
| `FORM0_CONNECTOR_PG_DATABASE`                | Nombre de la base de datos                   | Obligatorio                  |
| `FORM0_CONNECTOR_PG_USERNAME`                | Rol de la base de datos                      | Obligatorio                  |
| `FORM0_CONNECTOR_PG_PASSWORD`                | Contraseña de la base de datos               | Obligatorio                  |
| `FORM0_CONNECTOR_PG_SSL`                     | Activa TLS                                   | `false`                      |
| `FORM0_CONNECTOR_PG_SSL_REJECT_UNAUTHORIZED` | Verifica el certificado del servidor         | `true`                       |
| `FORM0_CONNECTOR_PG_MAX_CONNECTIONS`         | Tamaño máximo del pool                       | `10`                         |
| `FORM0_CONNECTOR_PG_IDLE_TIMEOUT`            | Tiempo de inactividad en milisegundos        | `30000`                      |
| `FORM0_CONNECTOR_PG_CONNECTION_TIMEOUT`      | Tiempo de espera de conexión en milisegundos | `5000`                       |
| `FORM0_CONNECTOR_PG_SCHEMA`                  | Esquema existente que contiene las tablas    | `public`                     |
| `FORM0_CONNECTOR_PG_TABLE_NAME`              | Tabla principal                              | `form0_submissions`          |
| `FORM0_CONNECTOR_PG_CHILD_TABLE_NAME`        | Tabla de registros anidados                  | `form0_submissions_children` |
| `FORM0_CONNECTOR_PG_DEBUG`                   | Registro detallado del conector              | `false`                      |

Los nombres de esquema y de tabla deben ser identificadores de PostgreSQL válidos sin comillas. El
esquema debe existir previamente, y el rol configurado necesita permisos para conectarse, crear las
tablas que falten, crear índices y triggers, y leer y escribir en esas tablas.

Usa TLS para las conexiones remotas y un rol dedicado con privilegios mínimos. Guarda la
configuración en un archivo `.env.local` excluido del control de versiones o en el gestor de
secretos de la aplicación host.
