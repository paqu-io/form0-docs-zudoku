---
title: Instalación y configuración de SQLite
description: Instala y configura el conector oficial de SQLite para Node.js.
---

<PageBadges />

Instala y configura el conector desde la CLI interactiva:

```text
form0> connector install form0-connector-sqlite
form0> connector configure form0-connector-sqlite
form0> connector test form0-connector-sqlite
```

Para usarlo directamente, instálalo con `npm install form0-connector-sqlite`.

| Variable de entorno                       | Finalidad                                    | Valor predeterminado         |
| ----------------------------------------- | -------------------------------------------- | ---------------------------- |
| `FORM0_CONNECTOR_SQLITE_PATH`             | Ruta relativa o absoluta de la base de datos | `./form0.db`                 |
| `FORM0_CONNECTOR_SQLITE_TABLE_NAME`       | Tabla principal                              | `form0_submissions`          |
| `FORM0_CONNECTOR_SQLITE_CHILD_TABLE_NAME` | Tabla de registros anidados                  | `form0_submissions_children` |
| `FORM0_CONNECTOR_SQLITE_DEBUG`            | Registro detallado del conector              | `false`                      |

Las rutas relativas de la base de datos se resuelven a partir del directorio de trabajo del proceso.
El conector crea el directorio padre y el archivo de la base de datos cuando hace falta, así que el
proceso necesita los permisos de escritura adecuados.

El paquete requiere Node.js 22 o posterior y una plataforma compatible con su dependencia nativa
`better-sqlite3`. No está pensado para React Native ni para Expo; en esos casos, usa un
almacenamiento móvil nativo de la plataforma, como `expo-sqlite`.

No coloques una base de datos de envíos dentro de un directorio web público ni la incluyas en el
control de versiones.
