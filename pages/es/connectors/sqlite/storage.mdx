La inicialización activa la comprobación de claves foráneas y crea las tablas principal y de
registros hijos, cuyos nombres son configurables. Los metadatos comunes se proyectan en columnas de
SQLite, mientras que el registro estructurado completo se codifica como texto JSON en
`form_values`.

Los registros de las secciones repetibles anidadas conservan el identificador del registro principal
y el del padre inmediato. Los índices cubren las columnas comunes de estado, formulario, marca de
tiempo, borrador, versión, conjunto de cambios y relaciones.

`onFormSubmit()` escribe el registro principal y después escribe de forma recursiva los registros
anidados. Cuando SQLite notifica un error de bloqueo de archivo o de E/S que admite reintento, el
conector se vuelve a conectar y reintenta el envío una vez. Los fallos persistentes se devuelven al
código que hizo la llamada.

El conector es un punto de escritura y no ofrece una API pública de consulta ni de sincronización.
Las aplicaciones que lean la base de datos deben usar una capa de acceso a datos independiente y
coordinar el acceso con el proceso que escribe.

La aplicación host se encarga de los permisos de archivo, la planificación de la concurrencia, las
copias de seguridad, las pruebas de restauración, la conservación de datos, las exportaciones
seguras y la eliminación de los registros sensibles.
