---
title: Shell interactivo
description: Trabaja con un esquema cargado en una sesión persistente de form0-cli.
---

Ejecuta `form0` sin argumentos para iniciar el shell interactivo. La sesión mantiene un esquema
cargado mientras lo validas, previsualizas, ejecutas, observas, editas o sirves.

Usa `help` para ver los comandos disponibles, `status` para inspeccionar la sesión y `exit` para
salir.
