## Antes de empezar

Instala form0-cli en Node.js 22.19.0 o posterior. Necesitas una credencial de un proveedor
compatible o un modelo local de Ollama accesible. El esquema es opcional: sin él, la creación con IA
parte del formulario vacío canónico.

Consulta [Instalar y actualizar](/es/cli/install-update) para la instalación de la CLI y los
requisitos del entorno de ejecución.

## Entra en el modo IA

Abre directamente un esquema conocido:

```bash
form0 ai form.schema.json
```

O combina la creación con IA con el servidor de vista previa interactivo:

```ansi
form0> load form.schema.json
form0> serve
form0(server)> ai
form0(server,ai)>
```

Iniciar el modo IA no inicia automáticamente un servidor. Un servidor que ya esté en ejecución sigue
activo y muestra los borradores validados al instante.

También puedes iniciar ambos desde el modo IA, incluso si el formulario todavía no se ha guardado:

```ansi
form0> ai
form0(ai)> /serve --app
form0(server,ai)>
```

El servidor recibe el esquema de trabajo actual, incluida una propuesta validada sin aplicar. En el
modo IA, el texto sin prefijo siempre es una petición al modelo; usa comandos con barra como
`/serve`, `/validate` y `/preview` para las acciones de la CLI.

## Autentícate y selecciona un modelo

Lista el catálogo de proveedores, autentícate, consulta los identificadores de modelo y selecciona
uno:

```ansi
form0(ai)> /providers
form0(ai)> /login openai-codex oauth
form0(ai)> /models openai-codex
form0(ai)> /model openai-codex/gpt-5.6-luna
form0(ai)> /status
```

Los identificadores de proveedor y de autenticación proceden directamente de Pi. Con la
autenticación por clave de API, la CLI pide el secreto sin añadirlo al proyecto ni al esquema.
Consulta [Proveedores y modelos](/es/cli/ai-authoring/providers-models) para conocer la base
compatible y cómo se almacenan los datos.

## Haz y revisa un primer cambio

Describe el comportamiento que quieres para el formulario, no ediciones de JSON en bruto:

```ansi
form0(ai)> Add quantity and unit price fields, then a calculated total rounded to two decimals.
```

El agente puede hacer preguntas o devolver diagnósticos mientras construye un lote de mutaciones
válido. Cuando la propuesta esté lista:

```ansi
form0(ai)> /preview
form0(ai)> /diff
form0(ai)> /apply
```

No se escribe nada hasta que confirmas la aplicación. Consulta la guía del flujo para entender
[la revisión de borradores, las revisiones, el deshacer y los conflictos](/es/cli/ai-authoring/authoring-workflow).

## Empieza sin esquema

Ejecuta el comando sin ruta para empezar con un formulario vacío:

```bash
form0 ai
```

La primera aplicación pide una ruta para el esquema y, si el archivo ya existe, usa la confirmación
de sobrescritura habitual. Después de guardarlo, la identidad temporal de la conversación se
reasigna a la ruta canónica del esquema.
