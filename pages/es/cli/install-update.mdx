---
title: Instalar y actualizar
description: Instale form0-cli globalmente o ejecútelo temporalmente con npx.
---

<PageBadges />

La CLI requiere Node.js 22.19.0 o posterior.

Instale el CLI globalmente para que el comando `form0` esté disponible:

```bash
npm install -g form0-cli
```

En su lugar, puede ejecutarlo sin una instalación global:

```bash
npx form0-cli
```

Utilice el mismo comando npm para actualizar una instalación global. Las versiones anteriores a 1.0 pueden contener interrupción
cambios, por lo que fija las versiones en entornos automatizados y revisa GitHub Releases antes de actualizar.
