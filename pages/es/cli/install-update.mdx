---
title: Instalar y actualizar
description: Instala form0-cli de forma global o ejecútalo de forma temporal con npx.
---

<PageBadges />

La CLI requiere Node.js 22.19.0 o posterior.

Instala la CLI de forma global para tener disponible el comando `form0`:

```bash
npm install -g form0-cli
```

También puedes ejecutarla sin instalarla globalmente:

```bash
npx form0-cli
```

Para actualizar una instalación global, usa el mismo comando de npm. Las versiones anteriores a la 1.0
pueden incluir cambios incompatibles, así que fija las versiones en entornos automatizados y revisa
las GitHub Releases antes de actualizar.
