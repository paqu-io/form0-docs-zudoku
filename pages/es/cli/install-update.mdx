---
title: Instalar y actualizar
description: Instala form0-cli globalmente o ejecútalo temporalmente con npx.
---

Instala la CLI globalmente con `npm install -g form0-cli`, o ejecútala sin una instalación global
con `npx form0-cli`. Usa el mismo comando de npm para actualizarla.

Las versiones anteriores a 1.0 pueden incluir cambios incompatibles. Fija la versión en entornos
automatizados y revisa GitHub Releases antes de actualizar.
