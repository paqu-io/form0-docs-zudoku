---
title: Ver y probar
description: Revalide schemas a medida que cambian y ejecutan el script de prueba form0 de un proyecto.
---

<PageBadges />

Utilice `form0 watch [schema]` durante el desarrollo de schema. Agregue `--auto-validate` o `--auto-run` para repetir
esas operaciones después de los cambios guardados; `--values` proporciona valores iniciales para ejecuciones automáticas.

Utilice `form0 test [dir]` para ejecutar el proyecto `test.js`. Mantenga las pruebas deterministas y centradas en el
schema comportamiento que importa al proyecto.
