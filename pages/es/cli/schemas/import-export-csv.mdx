---
title: Importación y exportación CSV
description: Mueva las definiciones de schema entre JSON y la representación CSV de CLI.
---

<PageBadges />

Utilice `form0 schema export` para crear una representación CSV de un JSON schema y `form0 schema import`
para convertirlo de nuevo a JSON.

Ambos comandos admiten rutas explícitas de entrada o salida y `--force` para reemplazo intencional.
Valide y revise el schema generado después de convertirlo.
