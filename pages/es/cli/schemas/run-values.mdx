---
title: Ejecutar con valores
description: Evalúa un esquema con valores iniciales en JSON o YAML.
---

<PageBadges />

Usa `form0 run <schema> --values <input>`. La entrada puede ser JSON en línea o un archivo JSON,
YAML o YML. El comando muestra el estado evaluado del motor y avisa de los campos de entrada
desconocidos.
