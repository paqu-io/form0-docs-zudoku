---
title: Inicializar un proyecto
description: Crea un proyecto estándar, web o móvil de form0 con la CLI.
---

Ejecuta `form0`, introduce `init` y elige **Proyecto estándar**, **Aplicación web** o
**Aplicación móvil**. También puedes usar `form0 init [dir]` directamente.

Después de crear el proyecto, entra en su directorio y sigue el README generado.
