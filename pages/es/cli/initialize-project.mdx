---
title: Inicializar un proyecto
description: Crea un proyecto form0 estándar, web o móvil con la CLI.
---

<PageBadges />

Ejecuta `form0`, introduce `init` y elige el tipo de proyecto que corresponda a tu aplicación:

- **Proyecto estándar de esquema form0** para esquemas, validación local, pruebas y vistas previas.
- **Aplicación web** para el starter mantenido de React y Vite.
- **Aplicación móvil** para el starter mantenido de React Native y Expo.

También puedes inicializar un directorio directamente con `form0 init [dir]`. Después de crear el
proyecto, entra en su directorio y sigue el README generado.
