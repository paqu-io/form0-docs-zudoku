<PageBadges />

Ejecute `form0 --help` para la lista de comandos autorizada de la versión instalada, y
`form0 <command> --help` para opciones específicas de comando.

- `init` crea un proyecto.
- `validate`, `preview`, `run`, `watch`, `serve` y `test` operan en schemas y proyectos.
- `schema` crea, importa, exporta y convierte schemas.
- `ai [schema]` abre la [creación con IA](/es/cli/ai-authoring) para revisar y validar cambios.
- `connector` administra conectores de datos.
- `reform` gestiona la autenticación, el alcance y la sincronización opcionales con reform.
- `theme` y `locale` administran las preferencias de CLI.
- `interactive` o `shell` inicia una sesión interactiva.

La ejecución de `form0` sin un comando también inicia el shell interactivo, cuya salida `help` refleja
el modo de sesión actual.
