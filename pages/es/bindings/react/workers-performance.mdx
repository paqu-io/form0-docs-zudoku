## Ejecución del motor

El valor predeterminado `engineMode="main-thread"` evalúa el motor de formulario en el subproceso de la interfaz de usuario.
`engineMode="worker"` para mover la evaluación del motor al módulo empaquetado worker cuando Web Workers
están disponibles:

```jsx
<FormRenderer schema={schema} engineMode="worker" />
```

Si el navegador no tiene soporte para Worker, el binding vuelve a la ejecución del subproceso principal.

## Modo de almacenamiento React

`engineStoreMode="snapshot"` clona el motor snapshot en el estado React y es el predeterminado.
`engineStoreMode="selector"` utiliza suscripciones de campo para reducir los rerenders amplios.

Tratar el modo selector como una optimización: verificar errores de campo, resúmenes de navegación, repetibles
secciones y el comportamiento de submission en la aplicación de destino antes de adoptarla.
