---
title: Solución de problemas de React
description: Diagnostica problemas comunes de instalación, renderizado, estilos y workers.
---

## El formulario no tiene estilos

Importa `form0-react/index.css` una vez y confirma que el bundler permite CSS de dependencias.

## Un campo aparece como no compatible

Comprueba el [catálogo de campos](/es/core/fields/catalog). Si el tipo es conocido, verifica que el
componente esté registrado en el mismo subárbol `FieldRegistryProvider` que `FormRenderer`.

## El esquema falla al renderizar

`FormRenderer` exige `schema.form.elements`. Ejecuta
[`form0 validate`](/es/cli/schemas/validate-preview) antes de cargarlo.

## El modo worker no carga

Vuelve primero a `engineMode="main-thread"`. En Vite, conserva el constructor estático y excluye
`form0-react` de la optimización como hace el proyecto inicial. Otros bundlers deben admitir workers
ESM basados en `new URL(..., import.meta.url)`. `workerUrl` y `createWorker` no forman parte de la
API pública de `FormRenderer`.

## Los cambios locales del paquete no aparecen

Reconstruye `form0-react`, reinicia el servidor y limpia únicamente la caché de dependencias del
bundler si es necesario.

## El envío no se ejecuta

Comprueba que `onSubmit` sea una función, el formulario esté en edición, `submitBlockedReason` esté
vacío y no haya errores de validación.
