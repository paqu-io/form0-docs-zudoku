Importa una vez la hoja de estilos en el punto de entrada:

```js
import "form0-react/index.css"
```

## Temas incluidos

`theme` acepta `standard`, `modal`, `simplified` o `spotlight`. `colorMode` acepta `light`, `dark` o
`system`.

```jsx
<FormRenderer schema={schema} theme="standard" colorMode="system" />
```

La ubicación no cambia automáticamente `theme`, por lo que la aplicación puede elegir la
combinación.

## Temas personalizados

La exportación `form0-react/theme.css.js` expone el contrato `vars`. Crea una clase completa con
`createTheme` de `@vanilla-extract/css` y pásala a `theme`.

Usa `className` para estilos del formulario y wrappers normales para el diseño de la aplicación. El
markup personalizado de campos pertenece a un
[renderer personalizado](/es/bindings/react/custom-renderers).
