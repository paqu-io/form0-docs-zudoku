Importa la hoja de estilos del paquete una sola vez en el punto de entrada de la aplicación:

```js
import "form0-react/index.css"
```

## Temas integrados

`theme` acepta `standard`, `modal`, `simplified` o `spotlight`. `colorMode` acepta `light`, `dark` o
`system`.

```jsx
<FormRenderer schema={schema} theme="standard" colorMode="system" />
```

El nombre del tema y el modo de color seleccionan la clase de Vanilla Extract integrada
correspondiente. La ubicación no cambia automáticamente la propiedad `theme`, así que cada
aplicación puede elegir su propia combinación.

## Temas personalizados

La exportación `form0-react/theme.css.js` expone el contrato de tema `vars`:

```js
import { createTheme } from "@vanilla-extract/css"
import { vars } from "form0-react/theme.css.js"

export const appTheme = createTheme(vars, {
  // Provide every color, type, spacing, and radius token in the contract.
})
```

Pasa la clase generada a `theme`:

```jsx
<FormRenderer schema={schema} theme={appTheme} colorMode="light" />
```

Usa `className` para los estilos a nivel de formulario y elementos contenedores normales para el
diseño de la aplicación que rodea al formulario. El marcado personalizado de un campo corresponde a
un [renderer personalizado](/es/bindings/react/custom-renderers).
