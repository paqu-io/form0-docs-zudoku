---
title: Referencia de la API React
description: Componentes, hooks, registros y utilidades públicas de form0-react.
---

Todas las exportaciones JavaScript compatibles están disponibles desde `form0-react`, salvo que se
indique otra ruta.

## Renderizado y temas

- `FormRenderer`
- `ThemeProvider`, `ThemeContext`, `useThemeClass`

## Registro de campos

- `FieldRegistryProvider`, `FieldRegistryContext`, `useFieldRegistry`
- `createFieldRegistry`, `defaultFieldRegistry`
- `registerFieldComponent`, `unregisterFieldComponent`, `resetFieldComponents`
- `getFieldComponent`, `listRegisteredFieldTypes`, `getMissingFieldComponentTypes`
- `KNOWN_FIELD_TYPES`

## Utilidades de esquema

- `cloneDeep(value)` y `cloneSchema(schema)` crean copias independientes.
- `ensureSchemaKeys(elements)` añade claves estables e indica si modificó la entrada.
- `prepareSchema(schema)` clona un esquema y asegura las claves en la copia.

## Integración especializada

- `useBuildingPlanController(options)` coordina la interfaz de planos con datos repetibles; no es un
  hook general de estado del formulario.

`useFormEngine`, el cliente worker, `FieldRenderer` y los renderizadores individuales son internos
y no están en el mapa de exportaciones. Los tokens de tema se exportan desde
`form0-react/theme.css.js` y el CSS compilado desde `form0-react/index.css`.
