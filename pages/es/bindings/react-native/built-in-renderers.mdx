---
title: Renderizadores de campo integrados
description: Tipos de campo renderizados por form0-react-native sin personalizaciones.
---

`form0-react-native` proporciona componentes nativos para la mayoría de tipos públicos definidos
por `form0-core`. El [catálogo de campos](/es/core/fields/catalog) sigue definiendo el contrato.

| Grupo | Tipos renderizados |
| --- | --- |
| Texto y números | `TextField`, `NumericField`, `CalculatedField` |
| Opciones | `SingleChoiceField`, `MultiChoiceField`, `BooleanField` |
| Fecha y hora | `DateField`, `TimeField` |
| Presentación y metadatos | `LabelField`, `TitleField`, `StatusField` |
| Firma | `SignatureField` |

`Section` y `RepeatableSection` son nodos estructurales gestionados por `FormRenderer`.

`PhotoField`, `VideoField` y `FormLinkField` usan actualmente componentes provisionales. Proporciona
renderizadores de aplicación antes de usarlos en producción. La captura, permisos, almacenamiento,
subida y retención de medios son responsabilidad de la aplicación.

Usa `KNOWN_FIELD_TYPES` y `getMissingFieldComponentTypes()` para inspeccionar la cobertura.
