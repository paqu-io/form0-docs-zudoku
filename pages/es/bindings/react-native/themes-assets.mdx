## Temas de color

`colorMode` acepta `light` o `dark`. Proporciona un `customTheme` parcial para sustituir tokens; el
binding lo fusiona en profundidad con el tema integrado seleccionado. Una aplicación puede obtener
la preferencia del dispositivo con `useColorScheme` de React Native y pasar el modo resultante.

```jsx
<FormRenderer schema={schema} colorMode="dark" customTheme={{ color: { primary: "#7c3aed" } }} />
```

`lightTheme`, `darkTheme`, `mergeThemes` y `getThemeByName` se exportan para componer temas a nivel
de aplicación. `ThemeProvider` y `useTheme` permiten mantener la interfaz nativa que rodea al
formulario coherente con él.

## Fuentes incluidas

El paquete exporta sus recursos de Figtree mediante `form0Fonts`. En Expo, cárgalos al iniciar la
aplicación, antes de renderizar el formulario:

```jsx
import { useFonts } from "expo-font"
import { form0Fonts, FormRenderer } from "form0-react-native"

const [fontsLoaded] = useFonts(form0Fonts)
if (!fontsLoaded) return null

return <FormRenderer schema={schema} />
```

## Imágenes de apoyo

Las rutas HTTP y HTTPS remotas se resuelven como `{ uri }` de forma predeterminada. React Native
exige que las imágenes locales empaquetadas se puedan detectar de forma estática, así que
proporciona un `imageResolver` que asocie las rutas del esquema con fuentes de imagen importadas o
cargadas con require:

```jsx
const images = {
  "safety/helmet.png": require("./assets/safety/helmet.png"),
}

<FormRenderer schema={schema} imageResolver={(path) => images[path] ?? null} />
```

El starter mantenido de Expo genera esta asociación cuando cambian los recursos de las imágenes de
apoyo.
