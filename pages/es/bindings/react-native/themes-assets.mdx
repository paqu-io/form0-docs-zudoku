## Temas de color

`colorMode` acepta `light` o `dark`. Proporcione un `customTheme` parcial para anular tokens; el
binding lo fusiona profundamente con el tema incorporado seleccionado. Una aplicación puede resolver el dispositivo
preferencia con React Native 's `useColorScheme` y pasar el modo resultante.

```jsx
<FormRenderer schema={schema} colorMode="dark" customTheme={{ color: { primary: "#7c3aed" } }} />
```

`lightTheme`, `darkTheme`, `mergeThemes` y `getThemeByName` se exportan para el nivel de aplicación
`ThemeProvider` y `useTheme` pueden mantener la interfaz de usuario nativa circundante alineada con la
forma.

## Fuentes empaquetadas

El paquete exporta sus activos Figtree a través de `form0Fonts`. En Expo, cárguelos en la aplicación
inicio antes de renderizar el formulario:

```jsx
import { useFonts } from "expo-font"
import { form0Fonts, FormRenderer } from "form0-react-native"

const [fontsLoaded] = useFonts(form0Fonts)
if (!fontsLoaded) return null

return <FormRenderer schema={schema} />
```

## Imágenes de apoyo

Las rutas HTTP y HTTPS remotas se resuelven a `{ uri }` de forma predeterminada.
imágenes para que se puedan descubrir estáticamente, así que proporcione un `imageResolver` que asigne rutas schema
fuentes de imagen importadas o requeridas:

```jsx
const images = {
  "safety/helmet.png": require("./assets/safety/helmet.png"),
}

<FormRenderer schema={schema} imageResolver={(path) => images[path] ?? null} />
```

El mantenimiento de Expo starter genera esta asignación al cambiar los activos de imagen de soporte.
