---
title: Solución de problemas React Native
description: Diagnosticar problemas comunes de instalación, renderización, fuente, activo y persistencia de form0-react-native.
---

<PageBadges />

## Metro no puede resolver una dependencia entre pares

Instale las versiones compatibles `lucide-react-native` y `react-native-svg`. En Expo, use
`npx expo install react-native-svg react-native-safe-area-context expo-font` para que el nativo instalado
los paquetes coinciden con el SDK activo, luego reinicie Metro.

## El texto utiliza una fuente de reserva

Cargar `form0Fonts` con `expo-font` antes de renderizar el formulario. Si la aplicación suministra un personalizado
mantenga sus tokens de familia de fuentes alineados con los nombres cargados en el registro de fuentes nativo.

## Falta una imagen de apoyo local

Los activos locales no se pueden resolver de forma arbitraria. runtime cadenas. Proporcione `imageResolver` con un
ruta estática al mapa de origen, regenerar el mapa si el starter lo posee, y reiniciar Metro después de agregar
nuevos activos.

## Un campo dice que no es compatible o provisional

Compruebe [Campo incorporado renderers](/es/bindings/react-native/built-in-renderers). `PhotoField`,
`VideoField`, y `FormLinkField` necesitan anulaciones de aplicaciones para el comportamiento de producción.
override se pasa al mismo `FormRenderer` o proveedor de registro que procesa el formulario.

## La sumisión no se ejecuta

`onSubmit` está activado por validación. Confirme que el formulario está en modo de edición, proporcione un controlador de envío y use
la hoja de navegación de validación para inspeccionar errores. Para la validación-tolerante drafts, proporcione `onSave`
y establecer `primaryActionMode="save"`.

## Los borradores desaparecen después de reiniciarse

Las instantáneas son emitidas pero nunca almacenadas por el binding. Persistirlas a través de `onSnapshotChange` o
`onSave`, y restaurar el objeto completo con `initialSnapshot`. No lo reemplace con solo el
valores de campo raw cuando importan entradas o marcas de tiempo repetibles.
