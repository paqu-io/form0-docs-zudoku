title: Solución de problemas de React Native
description: Diagnostica problemas habituales de form0-react-native con la instalación, el renderizado, las fuentes, los recursos y la persistencia.
---

## Metro no puede resolver una dependencia peer

Instala versiones compatibles de `lucide-react-native` y `react-native-svg`. En Expo, usa
`npx expo install react-native-svg react-native-safe-area-context expo-font` para que los paquetes
nativos instalados coincidan con el SDK activo y, después, reinicia Metro.

## El texto usa una fuente alternativa

Carga `form0Fonts` con `expo-font` antes de renderizar el formulario. Si la aplicación proporciona
un tema personalizado, mantén sus tokens de familia tipográfica alineados con los nombres cargados
en el registro nativo de fuentes.

## Falta una imagen de apoyo local

Los recursos locales no se pueden resolver a partir de cadenas arbitrarias en tiempo de ejecución.
Proporciona a `imageResolver` un mapa estático de rutas a fuentes, vuelve a generar el mapa si lo
gestiona el starter y reinicia Metro después de añadir recursos nuevos.

## Un campo indica que no es compatible o que es provisional

Consulta [Renderers de campo integrados](/es/bindings/react-native/built-in-renderers).
`PhotoField`, `VideoField` y `FormLinkField` necesitan renderers propios de la aplicación para
funcionar en producción. Asegúrate de pasar la sustitución al mismo `FormRenderer` o proveedor de
registro que renderiza el formulario.

## El envío no se ejecuta

`onSubmit` solo se ejecuta si el formulario supera la validación. Comprueba que el formulario esté
en modo de edición, proporciona un manejador de envío y usa el panel de navegación de validación
para revisar los errores. Para guardar borradores aunque no superen la validación, proporciona
`onSave` y establece `primaryActionMode="save"`.

## Los borradores desaparecen tras reiniciar

El binding emite snapshots, pero nunca los almacena. Guárdalos mediante `onSnapshotChange` u
`onSave` y restaura el objeto completo con `initialSnapshot`. No lo sustituyas solo por los valores
sin procesar de los campos cuando importen las entradas repetibles o las marcas de tiempo.
