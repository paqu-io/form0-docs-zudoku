Para una aplicación móvil nueva, usa el [inicio rápido de la CLI](/es/getting-started/quickstart).
El starter mantenido de React Native y Expo incluye el binding, la carga de fuentes, esquemas de
ejemplo, imágenes de apoyo y persistencia local con SQLite.

Para añadir form0 a una aplicación existente:

```bash
npm install form0-react-native form0-core lucide-react-native
```

Instala las dependencias peer nativas en versiones compatibles con tu aplicación. En Expo:

```bash
npx expo install react-native-svg react-native-safe-area-context expo-font
```

El paquete requiere Node.js 22 o posterior para la instalación y las herramientas, React 18 o 19 y
React Native 0.72 o posterior. `react-native-safe-area-context` es opcional, pero permite que el
encabezado integrado respete el área segura del dispositivo. Si lo instalas, envuelve la raíz de la
aplicación en su `SafeAreaProvider`.

## Renderiza un esquema

```jsx
import { FormRenderer } from "form0-react-native"
import schema from "./contact.form0.json"

export function ContactForm() {
  return (
    <FormRenderer
      schema={schema}
      onSubmit={(record, meta) => {
        console.log(record)
        console.log(meta.rawValues)
      }}
    />
  )
}
```

`schema` debe contener un objeto de formulario válido de `form0-core`. Empieza por
[Editar tu primer esquema](/es/getting-started/schema-edit) o consulta el
[Objeto formulario](/es/core/schema/form).

Carga las fuentes incluidas en el paquete antes de mostrar el formulario para obtener la tipografía
prevista. Consulta [Temas, fuentes e imágenes](/es/bindings/react-native/themes-assets).
