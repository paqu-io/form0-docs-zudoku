Para una nueva aplicación móvil, utilice el comando [CLI quickstart](/es/getting-started/quickstart).
React Native y Expo starter incluye el binding, carga de fuentes, ejemplo schemas, soporte
imágenes y persistencia local SQLite.

Para agregar form0 a una aplicación existente:

```bash
npm install form0-react-native form0-core lucide-react-native
```

Instale dependencias de pares nativas con versiones compatibles con su aplicación. En Expo:

```bash
npx expo install react-native-svg react-native-safe-area-context expo-font
```

El paquete requiere Node.js 22 o más reciente para instalación y herramientas, React 18 o 19, y React
Nativo 0.72 o más reciente. `react-native-safe-area-context` es opcional, pero permite el encabezado incorporado
Cuando esté instalado, envuelva la raíz de la aplicación en su
`SafeAreaProvider`.

## Renderizar un schema

```jsx
import { FormRenderer } from "form0-react-native"
import schema from "./contact.form0.json"

export function ContactForm() {
  return (
    <FormRenderer
      schema={schema}
      onSubmit={(record, meta) => {
        console.log(record)
        console.log(meta.rawValues)
      }}
    />
  )
}
```

`schema` debe contener un objeto de formulario `form0-core` válido. Comenzar con
[Edite su primer schema](/es/getting-started/schema-edit) o revise el
[Formulario objeto](/es/core/schema/form).

Cargue las fuentes empaquetadas antes de mostrar el formulario para la tipografía deseada. Ver
[Temas, fuentes e imágenes](/es/bindings/react-native/themes-assets).
