`FormRenderer` valida y prepara un schema, crea el motor de formularios, renderiza campos nativos y
secciones y produce registros estructurados o snapshots restaurable.

```jsx
<FormRenderer
  schema={schema}
  initialValues={{ name: "Ada" }}
  mode="edit"
  colorMode="light"
  labelPosition="top"
  onSubmit={saveRecord}
/>
```

## Propiedades esenciales

| Propiedad          | Finalidad                                                                   |
| ------------------ | --------------------------------------------------------------------------- |
| `schema`           | form0 schema que contiene `form.elements`.                                  |
| `initialValues`    | Valores de campo iniciales no repetibles.                                   |
| `initialSnapshot`  | Restaurar valores sin procesar, estado repetible y marcas de tiempo juntos. |
| `overrideValues`   | Aplicar valores autoritativos sobre valores iniciales.                      |
| `onSubmit`         | Recibir un registro estructurado de validación y metadatos.                 |
| `onSave`           | Recibir un snapshot sin necesidad de que el formulario sea válido.          |
| `onSnapshotChange` | Observe la semilla y el cambio de usuario snapshots.                        |
| `mode`             | Comience en el modo `edit` o `readonly`.                                    |

## Integración de host

- `onRequestClose` habilita la acción de cancelación raíz y recibe `{ reason: "cancel" }` después de cualquier
  Requiere confirmación de descarte.
- `headerAccessory` muestra el contenido de la aplicación inmediatamente debajo del encabezado incorporado.
- `showHeader` oculta el encabezado incorporado cuando el host posee la navegación y las acciones circundantes.
- `primaryActionMode`, `primaryActionLabel`, y `showPrimaryActionsInViewMode` personalizar el
  Incorporación de la acción primaria.
- `onSchemaReady` recibe el schema preparado después de que se hayan asegurado las claves estables.
- `engineOptions` suministra ayudantes de núcleo, configuración de seguridad, advertencias, manejo de operación y
  Actualización de la observación.
