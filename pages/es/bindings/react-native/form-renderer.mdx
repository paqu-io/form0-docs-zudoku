`FormRenderer` valida y prepara un esquema, crea el motor del formulario, renderiza los campos y las
secciones nativos y genera registros estructurados o snapshots restaurables.

```jsx
<FormRenderer
  schema={schema}
  initialValues={{ name: "Ada" }}
  mode="edit"
  colorMode="light"
  labelPosition="top"
  onSubmit={saveRecord}
/>
```

## Propiedades esenciales

| Propiedad          | Finalidad                                                                                                 |
| ------------------ | --------------------------------------------------------------------------------------------------------- |
| `schema`           | Un esquema form0 que contiene `form.elements`.                                                            |
| `initialValues`    | Valores iniciales de los campos no repetibles.                                                            |
| `initialSnapshot`  | Restaura a la vez los valores sin procesar, el estado de las secciones repetibles y las marcas de tiempo. |
| `overrideValues`   | Aplica valores prioritarios sobre los valores iniciales.                                                  |
| `onSubmit`         | Recibe el registro estructurado y sus metadatos, solo si el formulario supera la validación.              |
| `onSave`           | Recibe un snapshot sin exigir que el formulario sea válido.                                               |
| `onSnapshotChange` | Observa los snapshots iniciales y los de cambios del usuario.                                             |
| `mode`             | Empieza en modo `edit` o `readonly`.                                                                      |

## Integración con la aplicación host

- `onRequestClose` activa la acción de cancelar de la raíz y recibe `{ reason: "cancel" }` después
  de la confirmación de descarte, si hace falta.
- `headerAccessory` renderiza contenido de la aplicación justo debajo del encabezado integrado.
- `showHeader` oculta el encabezado integrado cuando la aplicación host gestiona la navegación y las
  acciones que lo rodean.
- `primaryActionMode`, `primaryActionLabel` y `showPrimaryActionsInViewMode` personalizan la acción
  principal integrada.
- `onSchemaReady` recibe el esquema preparado una vez garantizadas las claves estables.
- `engineOptions` proporciona los helpers del núcleo, la configuración de seguridad, los avisos, la
  gestión de operaciones y la observación de actualizaciones.

Los manejadores de eventos del esquema se ejecutan en Hermes si están escritos como funciones o
funciones flecha en `form.events.code`. Consulta
[Cómo se ejecuta el código de los manejadores](/es/core/engine/events-operations#cómo-se-ejecuta-el-código-de-los-manejadores).
