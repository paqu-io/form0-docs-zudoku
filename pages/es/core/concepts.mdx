## Primero el esquema

Un esquema de form0 es un documento JSON con un objeto `form` de nivel superior. El esquema define
la estructura, las reglas y el comportamiento de un formulario sin código de interfaz.

## Campos y valores

- Cada campo tiene un `data_name` (identificador legible) y una `key` (identificador interno,
  normalmente derivado de `data_name`).
- El motor guarda los valores por `data_name` y las expresiones los leen como `$data_name`.
- Las condiciones hacen referencia a los campos mediante `field_id`, que acepta tanto la `key` como
  el `data_name`. Consulta [Condiciones y operadores](/es/core/schema/conditions-operators).

## Estado del motor

El motor evalúa el esquema y produce un objeto de estado con:

- `values`: los valores actuales de los campos
- `errors`: los errores de validación de valor y de formato
- `visible`: la visibilidad de cada campo
- `required`: la obligatoriedad de cada campo
- `read_only`: el estado de solo lectura de cada campo

El motor indica si un campo es obligatorio, pero un campo obligatorio vacío no se añade a `errors`.
Las reglas de envío las aplica el renderer o la aplicación host. Consulta
[Validación de esquemas](/es/core/schema/validation).
