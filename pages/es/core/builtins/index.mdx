Los builtins son funciones disponibles en las expresiones de form0. Puedes usarlos en campos calculados
y en `form.events.code` sin importar nada.

## Dónde se usan los builtins

- Expresiones de **CalculatedField** (`calculate`)
- **Código de eventos** (`form.events.code`)

## Categorías

| Categoría                                      | Ejemplos de builtins             |
| ---------------------------------------------- | -------------------------------- |
| <Badge variant="secondary">Lógica</Badge>      | `IF`, `AND`, `OR`                |
| <Badge variant="secondary">Matemáticas</Badge> | `ROUND`, `CEILING`               |
| <Badge variant="secondary">Texto</Badge>       | `UPPER`                          |
| <Badge variant="secondary">Selección</Badge>   | `CHOICEVALUE`, `CHOICELABEL`     |
| <Badge variant="secondary">Esquema</Badge>     | `DATANAMES`                      |
| <Badge variant="secondary">Control</Badge>     | `SETRESULT`, `EVAL`              |
| <Badge variant="secondary">Eventos</Badge>     | `ON`, `OFF`, `ALERT`, `SETVALUE` |
