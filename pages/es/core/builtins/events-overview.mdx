Eventos en vivo `form.events.code` y son evaluados en runtime . Uso `ON` para registrar los controladores
y `SETVALUE` / `ALERT` para interactuar con el formulario.

## Ejemplo rápido

```js
ON("change", "age", function (event) {
  if ($age >= 18) {
    SETVALUE("can_vote", "yes")
  }
})
```
