Devuelve la etiqueta seleccionada de un campo de selección única.

## Ejemplo

```js
CHOICELABEL($city)
```

## Parámetros

- choiceField: valor de SingleChoiceField o BooleanField

## Devuelve

La etiqueta seleccionada o null.

## Notas

- Conserva las etiquetas numéricas cuando es posible.
