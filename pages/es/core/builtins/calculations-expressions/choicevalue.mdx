Devuelve el valor seleccionado de un campo de selección única.

## Ejemplo

```js
CHOICEVALUE($city)
```

## Parámetros

- choiceField: valor de SingleChoiceField o BooleanField

## Devuelve

El valor seleccionado o null.

## Notas

- Conserva los valores numéricos cuando es posible.
