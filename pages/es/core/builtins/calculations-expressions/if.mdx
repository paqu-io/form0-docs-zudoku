Elige entre dos valores según una condición.

## Ejemplo

```js
IF($age >= 18, "adult", "minor")
```

## Parámetros

- condition: expresión booleana
- trueValue: se devuelve cuando condition es verdadera
- falseValue: se devuelve en caso contrario

## Devuelve

`trueValue` o `falseValue`.
