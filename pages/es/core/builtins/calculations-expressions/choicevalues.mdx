Devuelve un array con los valores seleccionados de un campo de selección múltiple.

## Ejemplo

```js
CHOICEVALUES($colors)
```

## Parámetros

- multiChoiceField: valor de MultiChoiceField

## Devuelve

Un array con los valores seleccionados.
