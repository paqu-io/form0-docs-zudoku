Crea un array a partir de argumentos o analiza una cadena.

## Ejemplo

```js
ARRAY($a, $b, $c)
```

## Parámetros

- ...args: valores que se incluirán
- string input: cadena opcional con formato de array

## Devuelve

Un array de valores.
