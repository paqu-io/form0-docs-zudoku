Devuelve un array con las etiquetas seleccionadas de un campo de selección múltiple.

## Ejemplo

```js
CHOICELABELS($colors)
```

## Parámetros

- multiChoiceField: valor de MultiChoiceField

## Devuelve

Un array con las etiquetas seleccionadas.
