Devuelve los nombres de datos de los campos, con filtrado opcional por tipo.

## Ejemplo

```js
DATANAMES("TextField")
```

## Parámetros

- type: cadena opcional con el tipo de campo

## Devuelve

Un array de cadenas data_name.
