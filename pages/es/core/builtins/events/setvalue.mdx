Establece el valor de un campo durante un evento.

## Ejemplo

```js
SETVALUE("age", 18)
```

El valor debe coincidir con el campo. Usa un número para un `NumericField` y un texto para un
`TextField`. Un `SingleChoiceField` o `BooleanField` acepta un identificador de texto, y un
`MultiChoiceField` acepta una lista de identificadores de texto:

```js
SETVALUE("rating", "1")
SETVALUE("tags", ["red", "blue"])
```

Si se rechaza una llamada de un manejador, no se aplica ninguna operación de ese evento. Aplicar un
`SETVALUE()` recalcula el formulario, pero no despacha `change`. Consulta
[Actualización y normalización de valores](/es/core/engine/value-updates).

## Parámetros

- fieldDataName: cadena
- valueToSet: cualquier valor

## Devuelve

El descriptor de la operación (utilizado por los clientes).

## Pruébalo

Necesitas [form0-cli](/es/cli/install-update). Todas las páginas de builtins de eventos usan el
mismo formulario de prueba.

1. Descarga el formulario e inicia la vista previa:

   ```bash
   curl -o event-builtins.json https://docs.form0.dev/examples/event-builtins.form0.json
   form0 serve event-builtins.json
   ```

1. Abre `http://localhost:3030`.

1. Escribe `7` en **Amount**. **Note** muestra **Amount is 7**.
