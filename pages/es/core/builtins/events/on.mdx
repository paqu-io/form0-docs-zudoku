Registra un controlador de eventos.

## Ejemplo

```js
ON("change", "city", function (event) {
  ALERT("City changed")
})
```

## Parámetros

- eventType: cadena
- fieldKeyOrCallback: cadena|función
- callback: función (opcional)

## Devuelve

El descriptor de la operación (utilizado por los clientes).
