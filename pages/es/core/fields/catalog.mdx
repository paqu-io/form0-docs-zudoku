La siguiente tabla muestra todos los tipos de campo admitidos por form0-core.

| Tipo de campo         | Categoría                                     | Descripción                                                         |
| --------------------- | --------------------------------------------- | ------------------------------------------------------------------- |
| `TextField`           | <Badge variant="secondary">Entrada</Badge>    | Entrada de texto de una sola línea.                                 |
| `NumericField`        | <Badge variant="secondary">Entrada</Badge>    | Entrada numérica con min/max y formato.                             |
| `SingleChoiceField`   | <Badge variant="secondary">Entrada</Badge>    | Selección de opción única.                                          |
| `MultiChoiceField`    | <Badge variant="secondary">Entrada</Badge>    | Selección de opciones múltiples.                                    |
| `BooleanField`        | <Badge variant="secondary">Entrada</Badge>    | Opción booleana (sí/no o de tres estados).                          |
| `DateField`           | <Badge variant="secondary">Entrada</Badge>    | Entrada de fecha.                                                   |
| `TimeField`           | <Badge variant="secondary">Entrada</Badge>    | Entrada de hora.                                                    |
| `CalculatedField`     | <Badge variant="muted">Calculado</Badge>      | Valor calculado a partir de expresiones.                            |
| `LabelField`          | <Badge variant="muted">Calculado</Badge>      | Etiqueta o nota no editable.                                        |
| `Section`             | <Badge variant="outline">Estructura</Badge>   | Contenedor para campos anidados.                                    |
| `RepeatableSection`   | <Badge variant="outline">Estructura</Badge>   | Contenedor repetible para registros.                                |
| `BuildingPlanSection` | <Badge variant="outline">Estructura</Badge>   | Secciones repetibles generadas a partir de un plan de construcción. |
| `SignatureField`      | <Badge variant="secondary">Multimedia</Badge> | Captura de firma.                                                   |
| `PhotoField`          | <Badge variant="secondary">Multimedia</Badge> | Captura o subida de fotos.                                          |
| `VideoField`          | <Badge variant="secondary">Multimedia</Badge> | Captura o subida de vídeos.                                         |
| `FormLinkField`       | <Badge variant="outline">Meta</Badge>         | Enlace a registros de otro formulario.                              |
| `StatusField`         | <Badge variant="outline">Meta</Badge>         | Selector del estado del formulario (nivel superior).                |
| `TitleField`          | <Badge variant="outline">Meta</Badge>         | Título compuesto (nivel superior).                                  |
