## FormLinkField

```json
{
  "type": "FormLinkField",
  "key": "related_record",
  "data_name": "related_record",
  "label": "Related record",
  "display": "default",
  "description": null,
  "description_mode": null,
  "required": false,
  "required_conditions": null,
  "visible": true,
  "visible_conditions": null,
  "read_only": false,
  "read_only_conditions": null,
  "default_value": null,
  "allow_creating_records": true,
  "allow_existing_records": true,
  "allow_updating_records": false,
  "allow_multiple_records": false,
  "form_id": "target-form-id",
  "record_conditions": null,
  "record_defaults": null
}
```

Atributos adicionales:

- `allow_creating_records`, `allow_existing_records`, `allow_updating_records`
- `allow_multiple_records`
- `form_id`: identificador del formulario de destino
- `record_conditions`: filtros para los registros vinculados
- `record_defaults`: correspondencias de campos predeterminadas al crear registros nuevos

Las entradas de `record_defaults` usan correspondencias como estas:

```json
{
  "source_field_id": "source_field_key",
  "destination_field_id": "target_field_key"
}
```

## StatusField

```json
{
  "type": "StatusField",
  "key": "@status",
  "data_name": "status",
  "label": "Status",
  "display": "default",
  "enabled": true,
  "visible": true,
  "visible_conditions": null,
  "read_only": false,
  "read_only_conditions": null,
  "default_value": "pending",
  "choices": [
    { "label": "Open", "value": "open" },
    { "label": "Closed", "value": "closed" }
  ]
}
```

StatusField se define en `form.status_field` (no dentro de `elements`).

## TitleField

```json
{
  "type": "TitleField",
  "key": "@title",
  "data_name": "title",
  "label": "Title",
  "display": "default",
  "enabled": true,
  "visible": true,
  "visible_conditions": null,
  "read_only": true,
  "read_only_conditions": null,
  "elements": ["first_name", "last_name"]
}
```

TitleField usa claves de campo ordenadas (preferible) o valores `data_name`. Los valores visibles que no están vacíos se
unen con `", "`; los campos de selección usan sus etiquetas actuales del esquema, y el resultado es `null` cuando no se
resuelve ninguna parte.

En la raíz, TitleField se define en `form.title_field` y puede hacer referencia a campos raíz dentro de
secciones normales, pero nunca a descendientes repetibles. La misma estructura completa se puede asignar a
`RepeatableSection.title_field`, donde las referencias se limitan a los datos de ese registro hijo. Consulta
[RepeatableSection](/es/core/fields/containers#repeatablesection) para ver cómo se guarda y qué muestra la interfaz
como alternativa.

<Callout type="info" title="Detalles de reform">
  Los campos FormLink, Status y Title tienen un comportamiento más amplio en reform. Más adelante
  añadiremos enlaces a más detalles en [docs.reformapp.io](https://docs.reformapp.io).
</Callout>
