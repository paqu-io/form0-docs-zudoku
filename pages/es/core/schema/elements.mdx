`form.elements` es un array ordenado de campos y contenedores. Los contenedores pueden anidar otros
campos mediante su propio array `elements`.

## Claves y nombres de datos

- `data_name`: identificador legible que se usa como clave del valor en el estado del motor (único; solo minúsculas a-z, 0-9 y guion bajo; máximo 42 caracteres)
- `key`: identificador interno, normalmente derivado de `data_name` (único, hexadecimal, 8 caracteres)

Para hacer referencia a campos en condiciones o en `title_field.elements`, puedes usar `key` o `data_name`. Al escribir esquemas a mano, `data_name` suele ser más práctico porque es más fácil de recordar.

## Contenedores

Los siguientes tipos de campos pueden contener elementos anidados:

- `Section` – agrupa campos visualmente
- `RepeatableSection` – permite múltiples instancias de sus hijos

`BuildingPlanSection` también admite elementos anidados, pero tiene un comportamiento específico para generar formularios dinámicos. Consulta [BuildingPlanSection](/es/core/fields/containers#buildingplansection) para más detalles.

```json
  "description_mode": null,
  "visible": true,
  "visible_conditions": null,
  "elements": [
    {
      "type": "TextField",
      "key": "first_name",
      "data_name": "first_name",
      "label": "First name",
      "display": "default",
      "description": null,
      "description_mode": null,
      "required": true,
      "required_conditions": null,
      "visible": true,
      "visible_conditions": null,
      "read_only": false,
      "read_only_conditions": null,
      "default_value": null,
      "pattern": null,
      "pattern_description": null,
      "supporting_image": false,
      "supporting_image_path": null,
      "supporting_image_display": null
    }
  ]
}
```
