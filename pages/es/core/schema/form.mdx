Todo esquema empieza con un objeto `form`, que define los metadatos, los campos especiales y los eventos.

## Atributos

<Callout type="info" title="Atributos de nivel de aplicación">
  Los atributos marcados con ✓ en la columna **Nivel de aplicación** son metadatos de la aplicación
  que el motor no procesa directamente. Puedes usarlos al integrar el producto SaaS
  [reform](https://reformapp.io) o al crear funcionalidades similares en tu propia aplicación.
</Callout>

| Atributo                |  Tipo   | Obligatorio | Nivel de aplicación | Notas                                                                                                                                     |
| ----------------------- | :-----: | :---------: | :-----------------: | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `name`                  | string  |      ✓      |                     | Nombre legible del formulario.                                                                                                            |
| `description`           | string  |             |                     | Descripción del formulario.                                                                                                               |
| `id`                    | string  |      ✓      |                     | Identificador único del formulario.                                                                                                       |
| `record_count`          | number  |             |          ✓          | Contador operativo gestionado por la plataforma. Número de registros del formulario.                                                      |
| `record_last_change_at` | string  |             |          ✓          | Contador operativo gestionado por la plataforma. Fecha y hora del último cambio en un registro (ISO 8601).                                |
| `form_created_at`       | string  |             |          ✓          | Fecha y hora de creación del formulario (ISO 8601).                                                                                       |
| `form_updated_at`       | string  |             |          ✓          | Fecha y hora de la última actualización del formulario (ISO 8601).                                                                        |
| `form_created_by`       | string  |             |          ✓          | Usuario que creó el formulario.                                                                                                           |
| `form_updated_by`       | string  |             |          ✓          | Usuario que actualizó el formulario por última vez.                                                                                       |
| `status`                | string  |             |          ✓          | Estado del formulario, normalmente `active` o `inactive`.                                                                                 |
| `version`               | string  |             |          ✓          | Versión opcional del esquema gestionada por la plataforma. form0-core no la incrementa.                                                   |
| `main_org_id`           | string  |             |          ✓          | ID de la organización principal.                                                                                                          |
| `main_org_metadata`     | object  |             |          ✓          | Campos de metadatos de la organización principal.                                                                                         |
| `sub_org_id`            | string  |             |          ✓          | ID de la suborganización.                                                                                                                 |
| `sub_org_metadata`      | object  |             |          ✓          | Campos de metadatos de la suborganización.                                                                                                |
| `project_id`            | string  |             |          ✓          | ID del proyecto.                                                                                                                          |
| `project_metadata`      | object  |             |          ✓          | Campos de metadatos del proyecto.                                                                                                         |
| `ai`                    | object  |             |                     | Metadatos de IA con indicaciones a nivel de formulario (consulta [Metadatos de IA](/es/core/ai-metadata)).                                |
| `status_field`          | object  |      ✓      |                     | Definición del campo especial de estado (consulta [Campos meta](/es/core/fields/meta-fields#statusfield)).                                |
| `title_field`           | object  |      ✓      |                     | Definición del campo especial de título (consulta [Campos meta](/es/core/fields/meta-fields#titlefield)).                                 |
| `bounding_box`          |  array  |             |          ✓          | `[min_lat, min_lng, max_lat, max_lng]` que contiene todos los registros.                                                                  |
| `location_enabled`      | boolean |             |          ✓          | Habilita la captura de la ubicación.                                                                                                      |
| `location_required`     | boolean |             |          ✓          | Exige datos de ubicación cuando está habilitado.                                                                                          |
| `image`                 | string  |             |          ✓          | URL del icono del formulario (original).                                                                                                  |
| `image_thumbnail`       | string  |             |          ✓          | URL del icono en miniatura (160x160 px).                                                                                                  |
| `image_small`           | string  |             |          ✓          | URL del icono pequeño (320x320 px).                                                                                                       |
| `image_large`           | string  |             |          ✓          | URL del icono grande (640x640 px).                                                                                                        |
| `events`                | object  |             |                     | Bloque de código de eventos (`events.code`).                                                                                              |
| `form_links`            | object  |             |                     | Enlaces hacia y desde otros formularios (se usan con `FormLinkField`; consulta [Campos meta](/es/core/fields/meta-fields#formlinkfield)). |
| `elements`              |  array  |      ✓      |                     | Campos y contenedores del formulario (consulta [Elementos](/es/core/schema/elements)).                                                    |

Para ver en detalle cada atributo, incluidos sus valores predeterminados y opciones, consulta [Atributos del formulario](/es/core/schema/form-attributes).

## Campos especiales

`status_field` y `title_field` se definen en el nivel superior, no en `elements`. Se
validan como los tipos de campo estándar, pero tienen comportamientos fijos. Consulta [Campos meta](/es/core/fields/meta-fields) para más detalles.

## Eventos

`events.code` contiene builtins y expresiones JavaScript que registran manejadores de eventos con builtins como
`ON`, `OFF`, `ALERT`, `SETVALUE`, etc. Consulta [Eventos](/es/core/builtins/events-overview) para más detalles.

## Ejemplo

```json
{
  "form": {
    "name": "Inspection",
    "description": "Weekly inspection form",
    "id": "form_001",
    "status": "active",
    "version": "1",
    "location_enabled": true,
    "location_required": false,
    "status_field": { "type": "StatusField", "label": "Status", "choices": [] },
    "title_field": { "type": "TitleField", "label": "Title", "elements": [] },
    "events": { "code": "ON('load-record', function (e) { ALERT('Ready'); })" },
    "elements": []
  }
}
```
