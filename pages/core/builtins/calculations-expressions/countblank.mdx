# COUNTBLANK

<Badge variant="secondary">Logical</Badge>

Counts blank values in an array (null, undefined, empty string).

## Example

```js
COUNTBLANK(ARRAY(null, "", $note))
```

## Parameters

- values: array

## Returns

Number of blank items.
