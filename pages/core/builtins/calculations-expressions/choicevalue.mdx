Returns the selected value from a single-choice field.

## Example

```js
CHOICEVALUE($city)
```

## Parameters

- choiceField: SingleChoiceField or BooleanField value

## Returns

Selected choice value or null.

## Notes

- Preserves numeric values when possible.
