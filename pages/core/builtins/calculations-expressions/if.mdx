Choose between two values based on a condition.

## Example

```js
IF($age >= 18, "adult", "minor")
```

## Parameters

- condition: boolean expression
- trueValue: returned when condition is truthy
- falseValue: returned otherwise

## Returns

Either `trueValue` or `falseValue`.
