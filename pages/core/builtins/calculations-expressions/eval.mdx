# EVAL

<Badge variant="secondary">Control</Badge>

Evaluates a dynamic expression in a restricted context.

## Example

```js
EVAL("$" + fieldName)
```

## Parameters

- expression: string

## Returns

Result of the expression or null.

## Notes

- EVAL applies extra security rules; keep expressions simple.
