# CEILING

<Badge variant="secondary">Math</Badge>

Rounds a value up to the nearest multiple of a factor.

## Example

```js
CEILING(12.3, 5)
```

## Parameters

- value: number
- factor: number (optional, default 1)

## Returns

Rounded number.
