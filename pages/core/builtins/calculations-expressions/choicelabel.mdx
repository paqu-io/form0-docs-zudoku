Returns the selected label from a single-choice field.

## Example

```js
CHOICELABEL($city)
```

## Parameters

- choiceField: SingleChoiceField or BooleanField value

## Returns

Selected choice label or null.

## Notes

- Preserves numeric labels when possible.
