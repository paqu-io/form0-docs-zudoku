Registers an event handler.

## Example

```js
ON("change", "city", function (event) {
  ALERT("City changed")
})
```

## Parameters

- eventType: string
- fieldKeyOrCallback: string|function
- callback: function (optional)

## Returns

Operation descriptor (used by clients).
