Sets a field value during an event.

## Example

```js
SETVALUE("age", 18)
```

<Callout type="caution" title="Use live value shapes for choice fields">
  Primitive choice values are not currently normalized consistently by every official binding. For
  portable event code, set a `SingleChoiceField` or `BooleanField` with
  `{ "choice": [{ "value": "it", "label": "Italy" }], "other": [] }`. Set a
  `MultiChoiceField` with `{ "choices": [...], "other": [] }`. Text, numeric, and other scalar
  fields continue to accept their normal scalar values.
</Callout>

## Parameters

- fieldDataName: string
- valueToSet: any

## Returns

Operation descriptor (used by clients).
