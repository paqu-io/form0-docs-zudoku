Sets a field value during an event.

## Example

```js
SETVALUE("age", 18)
```

Official consumers apply string SingleChoice/Boolean IDs, arrays of MultiChoice IDs, or the matching full live objects through shared normalization. Dispatch collects operations; application evaluates affected calculations without implicitly dispatching change. [See the value-update contract](/core/engine/value-updates).

## Parameters

- fieldDataName: string
- valueToSet: any

## Returns

Operation descriptor (used by clients).
