---
title: INVALID
description: Reject a submission with your own validation message.
---

<PageBadges />

`INVALID(message)` stops a record from being submitted and shows your message to the user. Use it
for rules that a field setting cannot express, such as a minimum amount or a check that compares two
fields.

## Example

```js
ON("validate-record", function () {
  if ($amount < 4) INVALID("Amount must be at least four.")
})

ON("validate-repeatable", "rows", function () {
  if ($row_amount <= 0) INVALID("Enter a positive row amount.")
})
```

`validate-record` runs when the user submits the form. `validate-repeatable` runs when the user
saves a [row](/core/fields/containers#repeatablesection) of the named repeatable section, here
`rows`.

## Parameters

- message: nonempty string

## Returns

Operation descriptor (used by clients).

## Notes

- Call `INVALID()` inside a `validate-record` or `validate-repeatable` handler. Anywhere else, it is
  rejected.
- The message belongs to the whole record or row, not to one field, so it appears in the form's
  validation list.
- Validation handlers can only check values. They cannot change values, show alerts, or return
  promises.
- `INVALID()` does not add to `state.errors`, calculation diagnostics, or the saved record.

With `form0-core` alone, dispatch the event yourself and read `validationIssues`:

```js
const { validationIssues } = engine.triggerDetailed("validate-record")
// [{ message: "Amount must be at least four.", instancePath: [] }]
```

Each call returns fresh findings. A finding does not count as an execution failure, so it does not
appear in `issues`. Your application decides what to do with it, for example whether to allow a
draft.

See [Events and operations](/core/engine/events-operations) and the
[maintained contract](https://github.com/paqu-io/form0-core/blob/development/EVENT_CONTRACT.md).

## Try it

You need [form0-cli](/cli/install-update). All event builtin pages use the same test form.

1. Download the form and start the preview:

   ```bash
   curl -o event-builtins.json https://docs.form0.dev/examples/event-builtins.form0.json
   form0 serve event-builtins.json
   ```

1. Open `http://localhost:3030`.

1. Enter `2` in **Amount** and click **Submit Record**. The form shows
   **Amount must be at least four.** and does not submit.

1. Change **Amount** to `10` and click **Submit Record**. The message disappears, and the browser
   console shows `[STRUCTURED RECORD] Record prepared`.
