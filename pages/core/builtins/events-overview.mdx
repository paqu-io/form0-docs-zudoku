# Events

Events live in `form.events.code` and are evaluated at runtime. Use `ON` to register handlers
and `SETVALUE`/`ALERT` to interact with the form.

## Quick example

```js
ON('change', 'age', function (event) {
  if ($age >= 18) {
    SETVALUE('can_vote', 'yes');
  }
});
```
