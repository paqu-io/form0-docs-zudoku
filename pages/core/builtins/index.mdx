Builtins are functions available inside form0 expressions. You can use them in calculated fields
and in `form.events.code` without importing anything.

## Where builtins are used

- **CalculatedField** expressions (`calculate`)
- **Event code** (`form.events.code`)

## Categories

| Category | Example builtins |
| --- | --- |
| <Badge variant="secondary">Logical</Badge> | `IF`, `AND`, `OR` |
| <Badge variant="secondary">Math</Badge> | `ROUND`, `CEILING` |
| <Badge variant="secondary">String</Badge> | `UPPER` |
| <Badge variant="secondary">Choice</Badge> | `CHOICEVALUE`, `CHOICELABEL` |
| <Badge variant="secondary">Schema</Badge> | `DATANAMES` |
| <Badge variant="secondary">Control</Badge> | `SETRESULT`, `EVAL` |
| <Badge variant="secondary">Events</Badge> | `ON`, `OFF`, `ALERT`, `SETVALUE` |
