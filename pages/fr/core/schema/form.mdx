Tout schéma commence par un objet `form`, qui définit les métadonnées, les champs spéciaux et les événements.

## Attributs

<Callout type="info" title="Attributs propres à l'application">
  Les attributs marqués d'un ✓ dans la colonne **Application** sont des métadonnées propres à
  l'application, que le moteur ne traite pas directement. Vous pouvez les utiliser pour une
  intégration avec le produit SaaS [reform](https://reformapp.io) ou pour créer des fonctionnalités
  similaires dans votre propre application.
</Callout>

| Attribut                |  Type   | Obligatoire | Application | Remarques                                                                                                                                 |
| ----------------------- | :-----: | :---------: | :---------: | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `name`                  | string  |      ✓      |             | Nom lisible du formulaire.                                                                                                                |
| `description`           | string  |             |             | Description du formulaire.                                                                                                                |
| `id`                    | string  |      ✓      |             | Identifiant unique du formulaire.                                                                                                         |
| `record_count`          | number  |             |      ✓      | Compteur opérationnel géré par la plateforme. Nombre d'enregistrements du formulaire.                                                     |
| `record_last_change_at` | string  |             |      ✓      | Compteur opérationnel géré par la plateforme. Date et heure de la dernière modification d'un enregistrement (ISO 8601).                   |
| `form_created_at`       | string  |             |      ✓      | Date et heure de création du formulaire (ISO 8601).                                                                                       |
| `form_updated_at`       | string  |             |      ✓      | Date et heure de la dernière mise à jour du formulaire (ISO 8601).                                                                        |
| `form_created_by`       | string  |             |      ✓      | Utilisateur qui a créé le formulaire.                                                                                                     |
| `form_updated_by`       | string  |             |      ✓      | Dernier utilisateur à avoir mis à jour le formulaire.                                                                                     |
| `status`                | string  |             |      ✓      | Statut du formulaire, généralement `active` ou `inactive`.                                                                                |
| `version`               | string  |             |      ✓      | Version facultative du schéma gérée par la plateforme. form0-core ne l'incrémente pas.                                                    |
| `main_org_id`           | string  |             |      ✓      | ID de l'organisation principale.                                                                                                          |
| `main_org_metadata`     | object  |             |      ✓      | Champs de métadonnées de l'organisation principale.                                                                                       |
| `sub_org_id`            | string  |             |      ✓      | ID de la sous-organisation.                                                                                                               |
| `sub_org_metadata`      | object  |             |      ✓      | Champs de métadonnées de la sous-organisation.                                                                                            |
| `project_id`            | string  |             |      ✓      | ID du projet.                                                                                                                             |
| `project_metadata`      | object  |             |      ✓      | Champs de métadonnées du projet.                                                                                                          |
| `ai`                    | object  |             |             | Métadonnées d'IA pour guider au niveau du formulaire (voir [Métadonnées d'IA](/fr/core/ai-metadata)).                                     |
| `status_field`          | object  |      ✓      |             | Définition du champ spécial de statut (voir [Champs méta](/fr/core/fields/meta-fields#statusfield)).                                      |
| `title_field`           | object  |      ✓      |             | Définition du champ spécial de titre (voir [Champs méta](/fr/core/fields/meta-fields#titlefield)).                                        |
| `bounding_box`          |  array  |             |      ✓      | `[min_lat, min_lng, max_lat, max_lng]` englobant tous les enregistrements.                                                                |
| `location_enabled`      | boolean |             |      ✓      | Active la capture de la position.                                                                                                         |
| `location_required`     | boolean |             |      ✓      | Exige des données de localisation lorsque l'option est activée.                                                                           |
| `image`                 | string  |             |      ✓      | URL de l'icône du formulaire (originale).                                                                                                 |
| `image_thumbnail`       | string  |             |      ✓      | URL de l'icône miniature (160x160 px).                                                                                                    |
| `image_small`           | string  |             |      ✓      | URL de la petite icône (320x320 px).                                                                                                      |
| `image_large`           | string  |             |      ✓      | URL de la grande icône (640x640 px).                                                                                                      |
| `events`                | object  |             |             | Bloc de code des événements (`events.code`).                                                                                              |
| `form_links`            | object  |             |             | Liens vers et depuis d'autres formulaires (utilisés avec `FormLinkField`, voir [Champs méta](/fr/core/fields/meta-fields#formlinkfield)). |
| `elements`              |  array  |      ✓      |             | Champs et conteneurs du formulaire (voir [Éléments](/fr/core/schema/elements)).                                                           |

Pour le détail de chaque attribut, y compris les valeurs par défaut et les choix possibles, voir [Attributs du formulaire](/fr/core/schema/form-attributes).

## Champs spéciaux

`status_field` et `title_field` sont définis au premier niveau, et non dans `elements`. Ils sont
validés comme les types de champs standard, mais leur comportement est fixe. Voir [Champs méta](/fr/core/fields/meta-fields) pour plus de détails.

## Événements

`events.code` contient des builtins et des expressions JavaScript qui enregistrent des gestionnaires d'événements avec des builtins comme
`ON`, `OFF`, `ALERT`, `SETVALUE`, etc. Voir [Événements](/fr/core/builtins/events-overview) pour plus de détails.

## Exemple

```json
{
  "form": {
    "name": "Inspection",
    "description": "Weekly inspection form",
    "id": "form_001",
    "status": "active",
    "version": "1",
    "location_enabled": true,
    "location_required": false,
    "status_field": { "type": "StatusField", "label": "Status", "choices": [] },
    "title_field": { "type": "TitleField", "label": "Title", "elements": [] },
    "events": { "code": "ON('load-record', function (e) { ALERT('Ready'); })" },
    "elements": []
  }
}
```
