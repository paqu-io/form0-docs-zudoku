Cette page documente tous les attributs disponibles sur l'objet `form`, y compris les métadonnées propres à l'application.

<Callout type="note" title="Attributs propres à l'application">
  Les attributs marqués **Application** sont des métadonnées que le moteur ne traite pas
  directement. Vous pouvez les utiliser pour une intégration avec le produit SaaS
  [reform](https://reformapp.io) ou pour créer des fonctionnalités similaires dans votre propre
  application.
</Callout>
