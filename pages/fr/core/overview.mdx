`form0-core` est le moteur piloté par schéma qui gère les calculs, la visibilité, le caractère
obligatoire, la validation et les événements. Il est indépendant de tout framework et s'exécute dans
n'importe quel environnement d'exécution JavaScript (Node.js, navigateurs, React Native, etc.).

## ⚙️ Ce que fait form0-core

- Valide les schémas de formulaire et les définitions de champs
- Évalue les champs calculés et les expressions
- Applique les conditions de visibilité, de caractère obligatoire et de lecture seule
- Exécute les événements définis dans `form.events.code`
- Expose un état structuré (`values`, `errors`, `visible`, `required`, `read_only`)
- Produit des enregistrements structurés prêts pour la soumission

## 🚫 Ce que form0-core ne fait pas

- Le rendu ou la mise en page de l'interface
- La persistance des données ou les communications réseau
- L'authentification ou la gestion des utilisateurs

<Callout type="info" title="Attributs et types de champs propres à l'application">
  Certains attributs du schéma sont des métadonnées propres à l'application, et certains types de
  champs doivent interagir avec d'autres formulaires de votre application : le moteur ne les traite
  donc pas directement. Il les accepte néanmoins. Vous pouvez les utiliser pour une intégration avec
  [reform](https://reformapp.io), le produit SaaS développé par [paqu technologies](https://paqu.io)
  (l'équipe derrière form0), ou pour créer des fonctionnalités similaires dans votre propre
  application.
  <br />
  Pour en savoir plus, consultez les [attributs du formulaire](/fr/core/schema/form) et les [types
  de champs](/fr/core/fields/catalog).
</Callout>
