## Le schéma d'abord

Un schéma form0 est un document JSON avec un objet `form` de premier niveau. Le schéma définit la
structure, les règles et le comportement d'un formulaire sans aucun code d'interface.

## Champs et valeurs

- Chaque champ possède un `data_name` (identifiant lisible) et une `key` (identifiant interne,
  généralement dérivé de `data_name`).
- Le moteur stocke les valeurs par `data_name`, et les expressions les lisent sous la forme
  `$data_name`.
- Les conditions référencent les champs avec `field_id`, qui accepte la `key` ou le `data_name`.
  Voir [Conditions et opérateurs](/fr/core/schema/conditions-operators).

## État du moteur

Le moteur évalue le schéma et produit un objet d'état contenant :

- `values` : les valeurs actuelles des champs
- `errors` : les erreurs de validation de valeur et de format
- `visible` : la visibilité de chaque champ
- `required` : le caractère obligatoire de chaque champ
- `read_only` : la lecture seule de chaque champ

Le moteur indique si un champ est obligatoire, mais un champ obligatoire vide n'est pas ajouté à
`errors`. Les règles de soumission sont appliquées par le renderer ou l'application host. Voir
[Validation du schéma](/fr/core/schema/validation).
