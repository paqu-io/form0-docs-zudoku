## CalculatedField

```json
{
  "type": "CalculatedField",
  "key": "total",
  "data_name": "total",
  "label": "Total",
  "display": { "style": "numeric" },
  "description": null,
  "description_mode": null,
  "required": false,
  "visible": true,
  "visible_conditions": null,
  "read_only": true,
  "calculate": "$quantity * 2",
  "supporting_image": false,
  "supporting_image_path": null,
  "supporting_image_display": null
}
```

Attributs supplémentaires :

- `calculate` : expression, sous forme de chaîne, évaluée par le moteur.
- `display.style` : `text`, `numeric`, `date` ou `currency`.

Remarques :

- `required` est toujours `false`.
- `read_only` est toujours `true`.

## LabelField

```json
{
  "type": "LabelField",
  "key": "label_note",
  "data_name": "label_note",
  "label": "Note",
  "display": "default",
  "description": "Static label text",
  "description_mode": "subtext",
  "required": false,
  "visible": true,
  "visible_conditions": null,
  "read_only": true,
  "default_value": null,
  "supporting_image": false,
  "supporting_image_path": null,
  "supporting_image_display": null
}
```

LabelField est un champ non modifiable, utile pour du texte en ligne et pour regrouper des éléments dans l'interface.

<Callout type="info" title="Expressions">
  Utilisez les builtins (par exemple, `IF`, `ROUND`, `CHOICEVALUE`) dans `calculate`. Voir les pages
  Builtins pour la liste complète.
</Callout>
