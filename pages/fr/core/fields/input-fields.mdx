Cette page présente les types de champs de saisie et les attributs qu'ils ajoutent aux attributs communs.

## TextField

```json
{
  "type": "TextField",
  "key": "first_name",
  "data_name": "first_name",
  "label": "First name",
  "display": "default",
  "description": null,
  "description_mode": null,
  "required": false,
  "required_conditions": null,
  "visible": true,
  "visible_conditions": null,
  "read_only": false,
  "read_only_conditions": null,
  "default_value": null,
  "pattern": null,
  "pattern_description": null,
  "supporting_image": false,
  "supporting_image_path": null,
  "supporting_image_display": null
}
```

Attributs supplémentaires :

- `pattern` : expression régulière pour valider la saisie.
- `pattern_description` : explication facultative du motif.

```json
{
  "type": "NumericField",
  "key": "age",
  "data_name": "age",
  "label": "Age",
  "display": "default",
  "description": null,
  "description_mode": null,
  "required": true,
  "required_conditions": null,
  "visible": true,
  "visible_conditions": null,
  "read_only": false,
  "read_only_conditions": null,
  "default_value": null,
  "min": 0,
  "max": 120,
  "format": "integer",
  "supporting_image": false,
  "supporting_image_path": null,
  "supporting_image_display": null
}
```

Attributs supplémentaires :

- `min` : valeur minimale autorisée.
- `max` : valeur maximale autorisée.
- `format`: `integer` ou `float`.

## SingleChoiceField

```json
{
  "type": "SingleChoiceField",
  "key": "city",
  "data_name": "city",
  "label": "City",
  "display": "default",
  "description": null,
  "description_mode": null,
  "required": true,
  "required_conditions": null,
  "visible": true,
  "visible_conditions": null,
  "read_only": false,
  "read_only_conditions": null,
  "default_value": null,
  "allow_other": false,
  "choices": [
    { "label": "Paris", "value": "paris" },
    { "label": "Rome", "value": "rome" }
  ],
  "supporting_image": false,
  "supporting_image_path": null,
  "supporting_image_display": null,
  "is_searchable": false,
  "is_searchable_mode": null
}
```

Attributs supplémentaires :

- `choices` : tableau d'objets `{ label, value }`.
- `allow_other` : active une option de texte libre.
- `is_searchable` : active la recherche dans les longues listes.
- `is_searchable_mode` : pour l'instant, `default` ou `null`.

## MultiChoiceField

```json
{
  "type": "MultiChoiceField",
  "key": "foods",
  "data_name": "foods",
  "label": "Favorite foods",
  "display": "checkbox",
  "description": null,
  "description_mode": null,
  "required": false,
  "required_conditions": null,
  "visible": true,
  "visible_conditions": null,
  "read_only": false,
  "read_only_conditions": null,
  "default_value": ["pasta"],
  "allow_other": false,
  "choices": [
    { "label": "Pasta", "value": "pasta" },
    { "label": "Pizza", "value": "pizza" }
  ],
  "supporting_image": false,
  "supporting_image_path": null,
  "supporting_image_display": null,
  "is_searchable": false,
  "is_searchable_mode": null
}
```

Attributs supplémentaires :

- `choices` : tableau d'objets `{ label, value }`.
- `allow_other` : active les éléments en texte libre.
- `display`: `default` ou `checkbox`.

## BooleanField

```json
{
  "type": "BooleanField",
  "key": "newsletter",
  "data_name": "newsletter",
  "label": "Subscribe?",
  "display": "default",
  "description": null,
  "description_mode": null,
  "required": false,
  "required_conditions": null,
  "visible": true,
  "visible_conditions": null,
  "read_only": false,
  "read_only_conditions": null,
  "default_value": null,
  "choices": [
    { "label": "Yes", "value": "yes" },
    { "label": "No", "value": "no" }
  ],
  "third_option_enabled": false,
  "supporting_image": false,
  "supporting_image_path": null,
  "supporting_image_display": null
}
```

Attributs supplémentaires :

- `choices` : généralement deux options (oui/non).
- `third_option_enabled` : active une troisième option neutre.

<Callout type="info" title="Choice values">
  Les valeurs de choix doivent respecter `^[a-z0-9_]+$`. Si un choix ne définit pas de `value`,
  form0-core en génère une à partir du libellé.
</Callout>
