## FormLinkField

```json
{
  "type": "FormLinkField",
  "key": "related_record",
  "data_name": "related_record",
  "label": "Related record",
  "display": "default",
  "description": null,
  "description_mode": null,
  "required": false,
  "required_conditions": null,
  "visible": true,
  "visible_conditions": null,
  "read_only": false,
  "read_only_conditions": null,
  "default_value": null,
  "allow_creating_records": true,
  "allow_existing_records": true,
  "allow_updating_records": false,
  "allow_multiple_records": false,
  "form_id": "target-form-id",
  "record_conditions": null,
  "record_defaults": null
}
```

Attributs supplémentaires :

- `allow_creating_records`, `allow_existing_records`, `allow_updating_records`
- `allow_multiple_records`
- `form_id` : identifiant du formulaire cible
- `record_conditions` : filtres appliqués aux enregistrements liés
- `record_defaults` : correspondances de champs par défaut lors de la création d'enregistrements

Les entrées de `record_defaults` utilisent des correspondances comme celles-ci :

```json
{
  "source_field_id": "source_field_key",
  "destination_field_id": "target_field_key"
}
```

## StatusField

```json
{
  "type": "StatusField",
  "key": "@status",
  "data_name": "status",
  "label": "Status",
  "display": "default",
  "enabled": true,
  "visible": true,
  "visible_conditions": null,
  "read_only": false,
  "read_only_conditions": null,
  "default_value": "pending",
  "choices": [
    { "label": "Open", "value": "open" },
    { "label": "Closed", "value": "closed" }
  ]
}
```

StatusField est défini dans `form.status_field` (et non dans `elements`).

## TitleField

```json
{
  "type": "TitleField",
  "key": "@title",
  "data_name": "title",
  "label": "Title",
  "display": "default",
  "enabled": true,
  "visible": true,
  "visible_conditions": null,
  "read_only": true,
  "read_only_conditions": null,
  "elements": ["first_name", "last_name"]
}
```

TitleField utilise des clés de champ ordonnées (de préférence) ou des valeurs `data_name`. Les valeurs affichées non vides
sont jointes avec `", "` ; les champs de choix utilisent leurs libellés actuels du schéma, et le résultat vaut `null`
si aucune partie n'est résolue.

À la racine, TitleField est défini dans `form.title_field` et peut référencer des champs racine situés dans
des sections ordinaires, mais jamais des descendants répétables. La même structure complète peut être affectée à
`RepeatableSection.title_field`, où les références sont limitées aux données de cet enregistrement enfant. Voir
[RepeatableSection](/fr/core/fields/containers#repeatablesection) pour l'enregistrement et le libellé de repli
affiché dans l'interface.

<Callout type="info" title="Détails de reform">
  Les champs FormLink, Status et Title ont un comportement plus étendu dans reform. Des détails
  supplémentaires seront ajoutés ultérieurement sur [docs.reformapp.io](https://docs.reformapp.io).
</Callout>
