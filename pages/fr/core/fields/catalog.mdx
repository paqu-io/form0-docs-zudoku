Le tableau ci-dessous répertorie tous les types de champs pris en charge par form0-core.

| Type de champ         | Catégorie                                  | Description                                                      |
| --------------------- | ------------------------------------------ | ---------------------------------------------------------------- |
| `TextField`           | <Badge variant="secondary">Saisie</Badge>  | Saisie de texte sur une ligne.                                   |
| `NumericField`        | <Badge variant="secondary">Saisie</Badge>  | Saisie numérique avec min/max et format.                         |
| `SingleChoiceField`   | <Badge variant="secondary">Saisie</Badge>  | Sélection à choix unique.                                        |
| `MultiChoiceField`    | <Badge variant="secondary">Saisie</Badge>  | Sélection à choix multiples.                                     |
| `BooleanField`        | <Badge variant="secondary">Saisie</Badge>  | Choix booléen (oui/non ou tri-état).                             |
| `DateField`           | <Badge variant="secondary">Saisie</Badge>  | Saisie de date.                                                  |
| `TimeField`           | <Badge variant="secondary">Saisie</Badge>  | Saisie d'heure.                                                  |
| `CalculatedField`     | <Badge variant="muted">Calculé</Badge>     | Valeur calculée à partir des expressions.                        |
| `LabelField`          | <Badge variant="muted">Calculé</Badge>     | Étiquette ou note non modifiable.                                |
| `Section`             | <Badge variant="outline">Structure</Badge> | Conteneur pour champs imbriqués.                                 |
| `RepeatableSection`   | <Badge variant="outline">Structure</Badge> | Conteneur répétable pour les enregistrements.                    |
| `BuildingPlanSection` | <Badge variant="outline">Structure</Badge> | Sections répétables générées à partir d'un plan de construction. |
| `SignatureField`      | <Badge variant="secondary">Média</Badge>   | Capture de signature.                                            |
| `PhotoField`          | <Badge variant="secondary">Média</Badge>   | Prise ou envoi de photos.                                        |
| `VideoField`          | <Badge variant="secondary">Média</Badge>   | Prise ou envoi de vidéos.                                        |
| `FormLinkField`       | <Badge variant="outline">Méta</Badge>      | Lien vers des enregistrements d'un autre formulaire.             |
| `StatusField`         | <Badge variant="outline">Méta</Badge>      | Sélecteur du statut du formulaire (niveau supérieur).            |
| `TitleField`          | <Badge variant="outline">Méta</Badge>      | Titre composite (niveau supérieur).                              |
