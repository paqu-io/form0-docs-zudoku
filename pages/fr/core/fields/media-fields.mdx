## SignatureField

```json
{
  "type": "SignatureField",
  "key": "signature",
  "data_name": "signature",
  "label": "Signature",
  "display": "default",
  "description": null,
  "description_mode": null,
  "required": true,
  "required_conditions": null,
  "visible": true,
  "visible_conditions": null,
  "read_only": false,
  "read_only_conditions": null,
  "default_value": null,
  "agreement_text": "I confirm the information is accurate."
}
```

Attributs supplémentaires:

- `agreement_text`: Texte de consentement facultatif affiché près de la signature.
