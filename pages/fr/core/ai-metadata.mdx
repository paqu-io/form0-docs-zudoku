form0-core prend en charge des métadonnées d'IA facultatives pour guider des agents externes. Le
moteur ignore ces métadonnées ; seuls vos outils les exploitent s'ils les lisent.

## IA au niveau du formulaire

`form.ai` accepte les clés suivantes :

- `context` : tableau d'étiquettes de domaine.
- `instructions` : tableau d'instructions destinées aux outils d'IA.
- `namingPolicy` : objet décrivant les préférences de nommage.
- `tasks` : tableau des tâches à activer (par exemple, `suggestFieldNames`).
- `requiresConsent` : booléen indiquant si le consentement de l'utilisateur est requis.
- `allowCloud` : booléen indiquant si le traitement dans le cloud est autorisé.

Exemple :

```json
{
  "ai": {
    "context": ["safety_inspections"],
    "instructions": ["Use snake_case"],
    "namingPolicy": { "language": "en", "case": "snake", "asciiOnly": true },
    "tasks": ["suggestFieldNames"],
    "requiresConsent": true
  }
}
```

## IA au niveau du champ

`field.ai` accepte :

- `context`, `instructions`, `tasks` (comme pour le formulaire)
- `examples` : exemples de valeurs
- `synonyms` : libellés alternatifs
- `inferrable` : booléen indiquant si la valeur peut être déduite
- `fillStrategy` : `infer_from_previous`, `require_explicit` ou `suggest_options`
- `priority` : nombre indiquant l'importance
- `dependencies` : tableau d'identifiants de champs
- `choicePolicy` : objet décrivant la stratégie pour les valeurs de choix
- `providerHints` : indications propres à chaque fournisseur
- `requiresConsent`, `allowCloud`

Exemple :

```json
{
  "ai": {
    "examples": ["John", "Jane"],
    "synonyms": ["First name"],
    "inferrable": true,
    "fillStrategy": "suggest_options",
    "priority": 0.7
  }
}
```
