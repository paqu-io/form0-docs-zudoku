Affiche une alerte avec un titre et un message facultatif.

## Exemple

```js
ALERT("Warning", "Check the form")
```

## Paramètres

- title : chaîne
- message : chaîne (facultatif)

## Valeur renvoyée

Le descripteur de l’opération (utilisé par les clients).
