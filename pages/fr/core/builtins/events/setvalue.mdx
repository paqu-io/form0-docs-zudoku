Définit la valeur d’un champ pendant un événement.

## Exemple

```js
SETVALUE("age", 18)
```

## Paramètres

- fieldDataName : chaîne
- valueToSet : toute valeur

## Valeur renvoyée

Le descripteur de l’opération (utilisé par les clients).
