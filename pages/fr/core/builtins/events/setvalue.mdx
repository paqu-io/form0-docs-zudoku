Définit la valeur d’un champ pendant un événement.

## Exemple

```js
SETVALUE("age", 18)
```

Les consommateurs officiels appliquent les identifiants textuels SingleChoice/Boolean, les tableaux MultiChoice ou leurs objets actifs complets par normalisation partagée. Le déclenchement collecte les opérations ; leur application évalue les calculs concernés sans déclencher change implicitement. [Voir le contrat de mise à jour des valeurs](/fr/core/engine/value-updates).

## Paramètres

- fieldDataName : chaîne
- valueToSet : toute valeur

## Valeur renvoyée

Le descripteur de l’opération (utilisé par les clients).
