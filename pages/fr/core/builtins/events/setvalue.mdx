Définit la valeur d’un champ pendant un événement.

## Exemple

```js
SETVALUE("age", 18)
```

<Callout type="caution" title="Utilisez les formes de valeur d'exécution pour les champs à choix">
  Les valeurs primitives des champs à choix ne sont pas encore normalisées de la même façon par tous
  les bindings officiels. Pour un code d'événement portable, définissez un `SingleChoiceField` ou un
  `BooleanField` avec `{ "choice": [{ "value": "it", "label": "Italy" }], "other": [] }`. Définissez
  un `MultiChoiceField` avec `{ "choices": [...], "other": [] }`. Les champs texte, numériques et les
  autres champs scalaires acceptent toujours leurs valeurs scalaires habituelles.
</Callout>

## Paramètres

- fieldDataName : chaîne
- valueToSet : toute valeur

## Valeur renvoyée

Le descripteur de l’opération (utilisé par les clients).
