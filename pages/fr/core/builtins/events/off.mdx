Supprime des gestionnaires d’événements.

## Exemple

```js
OFF("change", "city")
```

## Paramètres

- eventType : chaîne
- fieldKeyOrCallback : chaîne|fonction (facultatif)
- callback : fonction (facultative)

## Valeur renvoyée

Le descripteur de l’opération (utilisé par les clients).
