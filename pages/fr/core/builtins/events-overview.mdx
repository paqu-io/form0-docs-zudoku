Les événements vivent dans `form.events.code` et sont évalués en runtime Utilisation `ON` pour enregistrer les gestionnaires
et `SETVALUE` / `ALERT` pour interagir avec le formulaire.

## Exemple rapide

```js
ON("change", "age", function (event) {
  if ($age >= 18) {
    SETVALUE("can_vote", "yes")
  }
})
```
