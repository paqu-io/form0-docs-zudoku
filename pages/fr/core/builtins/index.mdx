Les builtins sont des fonctions disponibles dans les expressions form0. Vous pouvez les utiliser dans les champs calculés
et dans `form.events.code` sans rien importer.

## Où utiliser les builtins

- Expressions de **CalculatedField** (`calculate`)
- **Code des événements** (`form.events.code`)

## Catégories

| Catégorie                                        | Exemples de builtins             |
| ------------------------------------------------ | -------------------------------- |
| <Badge variant="secondary">Logique</Badge>       | `IF`, `AND`, `OR`                |
| <Badge variant="secondary">Mathématiques</Badge> | `ROUND`, `CEILING`               |
| <Badge variant="secondary">Texte</Badge>         | `UPPER`                          |
| <Badge variant="secondary">Choix</Badge>         | `CHOICEVALUE`, `CHOICELABEL`     |
| <Badge variant="secondary">Schéma</Badge>        | `DATANAMES`                      |
| <Badge variant="secondary">Contrôle</Badge>      | `SETRESULT`, `EVAL`              |
| <Badge variant="secondary">Événements</Badge>    | `ON`, `OFF`, `ALERT`, `SETVALUE` |
