Choisit entre deux valeurs selon une condition.

## Exemple

```js
IF($age >= 18, "adult", "minor")
```

## Paramètres

- condition : expression booléenne
- trueValue : renvoyée lorsque condition est truthy
- falseValue : renvoyée dans le cas contraire

## Valeur renvoyée

`trueValue` ou `falseValue`.
