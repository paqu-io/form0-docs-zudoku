Évalue une expression dynamique dans un contexte restreint.

## Exemple

```js
EVAL("$" + fieldName)
```

## Paramètres

- expression : chaîne

## Valeur renvoyée

Le résultat de l’expression ou null.

## Remarques

- EVAL applique des règles de sécurité supplémentaires ; gardez les expressions simples.
