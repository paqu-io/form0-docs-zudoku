Renvoie le libellé sélectionné d’un champ à choix unique.

## Exemple

```js
CHOICELABEL($city)
```

## Paramètres

- choiceField : valeur de SingleChoiceField ou BooleanField

## Valeur renvoyée

Le libellé sélectionné ou null.

## Remarques

- Conserve les libellés numériques lorsque c’est possible.
