Arrondit une valeur au multiple supérieur le plus proche d’un facteur.

## Exemple

```js
CEILING(12.3, 5)
```

## Paramètres

- value : nombre
- factor : nombre (facultatif, 1 par défaut)

## Valeur renvoyée

Le nombre arrondi.
