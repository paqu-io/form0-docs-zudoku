Arrondit un nombre au nombre de décimales indiqué.

## Exemple

```js
ROUND(12.345, 2)
```

## Paramètres

- value : nombre
- places : nombre de décimales (peut être négatif)

## Valeur renvoyée

Le nombre arrondi.
