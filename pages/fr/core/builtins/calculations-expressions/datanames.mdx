Renvoie les noms de données des champs, avec un filtre facultatif par type.

## Exemple

```js
DATANAMES("TextField")
```

## Paramètres

- type : chaîne facultative du type de champ

## Valeur renvoyée

Un tableau de chaînes data_name.
