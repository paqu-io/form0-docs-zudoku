Compte les valeurs vides d’un tableau (null, undefined ou chaîne vide).

## Exemple

```js
COUNTBLANK(ARRAY(null, "", $note))
```

## Paramètres

- values : tableau

## Valeur renvoyée

Le nombre d’éléments vides.
