Renvoie true si une valeur « autre » a été saisie.

## Exemple

```js
HASOTHER($city)
```

## Paramètres

- choiceField : valeur de SingleChoiceField ou MultiChoiceField

## Valeur renvoyée

Le résultat booléen.
