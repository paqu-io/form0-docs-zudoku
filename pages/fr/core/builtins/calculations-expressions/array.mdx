Crée un tableau à partir d’arguments ou analyse une chaîne.

## Exemple

```js
ARRAY($a, $b, $c)
```

## Paramètres

- ...args : valeurs à inclure
- string input : chaîne facultative au format tableau

## Valeur renvoyée

Un tableau de valeurs.
