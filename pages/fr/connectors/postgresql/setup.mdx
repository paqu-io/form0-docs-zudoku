---
title: Installation et configuration de PostgreSQL
description: Installez et configurez le connecteur PostgreSQL officiel.
---

<PageBadges />

Installez et configurez le connecteur depuis la CLI interactive :

```text
form0> connector install form0-connector-pg
form0> connector configure form0-connector-pg
form0> connector test form0-connector-pg
```

Pour une utilisation directe, installez-le avec `npm install form0-connector-pg`.

Les paramètres obligatoires sont le nom de la base de données, le nom d’utilisateur et le mot de
passe. L’hôte par défaut est `localhost` et le port par défaut est `5432`.

| Variable d’environnement                     | Rôle                                               | Valeur par défaut            |
| -------------------------------------------- | -------------------------------------------------- | ---------------------------- |
| `FORM0_CONNECTOR_PG_HOST`                    | Hôte PostgreSQL                                    | `localhost`                  |
| `FORM0_CONNECTOR_PG_PORT`                    | Port PostgreSQL                                    | `5432`                       |
| `FORM0_CONNECTOR_PG_DATABASE`                | Nom de la base de données                          | Obligatoire                  |
| `FORM0_CONNECTOR_PG_USERNAME`                | Rôle de base de données                            | Obligatoire                  |
| `FORM0_CONNECTOR_PG_PASSWORD`                | Mot de passe de la base de données                 | Obligatoire                  |
| `FORM0_CONNECTOR_PG_SSL`                     | Active TLS                                         | `false`                      |
| `FORM0_CONNECTOR_PG_SSL_REJECT_UNAUTHORIZED` | Vérifie le certificat du serveur                   | `true`                       |
| `FORM0_CONNECTOR_PG_MAX_CONNECTIONS`         | Taille maximale du pool                            | `10`                         |
| `FORM0_CONNECTOR_PG_IDLE_TIMEOUT`            | Délai d’inactivité en millisecondes                | `30000`                      |
| `FORM0_CONNECTOR_PG_CONNECTION_TIMEOUT`      | Délai de connexion en millisecondes                | `5000`                       |
| `FORM0_CONNECTOR_PG_SCHEMA`                  | Schéma existant contenant les tables du connecteur | `public`                     |
| `FORM0_CONNECTOR_PG_TABLE_NAME`              | Table principale                                   | `form0_submissions`          |
| `FORM0_CONNECTOR_PG_CHILD_TABLE_NAME`        | Table des enregistrements imbriqués                | `form0_submissions_children` |
| `FORM0_CONNECTOR_PG_DEBUG`                   | Journalisation détaillée du connecteur             | `false`                      |

Les noms de schéma et de table doivent être des identifiants PostgreSQL valides sans guillemets. Le
schéma doit déjà exister, et le rôle configuré doit avoir l’autorisation de se connecter, de créer
les tables manquantes, de créer des index et des triggers, et de lire et d’écrire dans ces tables.

Utilisez TLS pour les connexions distantes et un rôle dédié disposant du minimum de privilèges.
Conservez la configuration dans un fichier `.env.local` exclu du contrôle de version ou dans le
gestionnaire de secrets de l’application host.
