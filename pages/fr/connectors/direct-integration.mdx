title: Intégration directe
description: Gérez directement le cycle de vie d’un connecteur form0 dans une application Node.js.
---

<PageBadges />

La CLI est la voie d’intégration habituelle, mais les deux connecteurs officiels exposent le même
cycle de vie :

- `initialize(config, envVars)` ouvre le stockage et crée les tables manquantes.
- `onFormSubmit(record)` stocke un enregistrement structuré canonique.
- `healthCheck()` indique si le stockage initialisé est joignable.
- `getMetadata()` décrit le connecteur installé et la configuration active sans exposer de secrets.
- `destroy()` libère la connexion à la base de données ou le descripteur du fichier local.

```javascript
import { Form0PostgreSQLConnector } from "form0-connector-pg"

const connector = new Form0PostgreSQLConnector()

await connector.initialize()
const health = await connector.healthCheck()

if (!health.healthy) {
  throw new Error(health.message)
}

const result = await connector.onFormSubmit(structuredRecord)
await connector.destroy()
```

Les valeurs de configuration explicites l’emportent sur celles issues des variables
d’environnement. Gardez les identifiants hors du contrôle de version et libérez toujours le
connecteur à l’arrêt de l’application.

La forme d’enregistrement acceptée est documentée dans
[Sortie et enregistrements du noyau](/fr/core/output-records). Les connecteurs ajoutent des
horodatages côté serveur avant le stockage et renvoient un résultat décrivant l’enregistrement
principal et les enregistrements imbriqués qui ont été écrits.
