<PageBadges />

L’initialisation active les clés étrangères et crée les tables principale et enfant configurées.
Les métadonnées courantes sont projetées dans des colonnes SQLite et l’enregistrement complet est
encodé en texte JSON dans `form_values`.

Les enregistrements de sections répétables conservent les identifiants de l’enregistrement principal
et du parent immédiat. Les index couvrent l’état, le formulaire, les horodatages, le brouillon, la
version, le changeset et les relations.

`onFormSubmit()` écrit l’enregistrement principal puis les enregistrements imbriqués. Si SQLite
signale un verrou ou une erreur d’E/S réessayable, le connecteur se reconnecte et réessaie une fois.
Les échecs persistants sont renvoyés à l’appelant.

Le connecteur est une frontière d’écriture et ne fournit aucune API publique de requête ou de
synchronisation. Utilisez une couche d’accès distincte et coordonnez-la avec le processus d’écriture.

L’application hôte gère les droits, la concurrence, les sauvegardes, tests de restauration, la
rétention, les exports sécurisés et la suppression des données sensibles.
