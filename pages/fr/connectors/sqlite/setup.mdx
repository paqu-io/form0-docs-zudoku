---
title: Installation et configuration de SQLite
description: Installez et configurez le connecteur SQLite officiel pour Node.js.
---

<PageBadges />

Installez et configurez le connecteur avec la CLI interactive :

```text
form0> connector install form0-connector-sqlite
form0> connector configure form0-connector-sqlite
form0> connector test form0-connector-sqlite
```

Pour un usage direct, exécutez `npm install form0-connector-sqlite`.

| Variable d’environnement                  | Rôle                                | Valeur par défaut            |
| ----------------------------------------- | ----------------------------------- | ---------------------------- |
| `FORM0_CONNECTOR_SQLITE_PATH`             | Chemin relatif ou absolu            | `./form0.db`                 |
| `FORM0_CONNECTOR_SQLITE_TABLE_NAME`       | Table principale                    | `form0_submissions`          |
| `FORM0_CONNECTOR_SQLITE_CHILD_TABLE_NAME` | Table des enregistrements imbriqués | `form0_submissions_children` |
| `FORM0_CONNECTOR_SQLITE_DEBUG`            | Journalisation détaillée            | `false`                      |

Les chemins relatifs sont résolus depuis le répertoire de travail du processus. Le connecteur crée
le répertoire parent et le fichier si nécessaire ; le processus doit donc pouvoir y écrire.

Le paquet requiert Node.js 22 ou ultérieur et une plateforme compatible avec sa dépendance native
`better-sqlite3`. Il n’est pas destiné à React Native ou Expo ; utilisez un stockage mobile natif
comme `expo-sqlite` dans ces environnements.

Ne placez pas la base de soumissions dans un répertoire web public et ne la versionnez pas.
