---
title: Installation et configuration de SQLite
description: Installez et configurez le connecteur SQLite officiel pour Node.js.
---

<PageBadges />

Installez et configurez le connecteur depuis la CLI interactive :

```text
form0> connector install form0-connector-sqlite
form0> connector configure form0-connector-sqlite
form0> connector test form0-connector-sqlite
```

Pour une utilisation directe, installez-le avec `npm install form0-connector-sqlite`.

| Variable d’environnement                  | Rôle                                           | Valeur par défaut            |
| ----------------------------------------- | ---------------------------------------------- | ---------------------------- |
| `FORM0_CONNECTOR_SQLITE_PATH`             | Chemin relatif ou absolu de la base de données | `./form0.db`                 |
| `FORM0_CONNECTOR_SQLITE_TABLE_NAME`       | Table principale                               | `form0_submissions`          |
| `FORM0_CONNECTOR_SQLITE_CHILD_TABLE_NAME` | Table des enregistrements imbriqués            | `form0_submissions_children` |
| `FORM0_CONNECTOR_SQLITE_DEBUG`            | Journalisation détaillée du connecteur         | `false`                      |

Les chemins relatifs de base de données sont résolus à partir du répertoire de travail du processus.
Le connecteur crée le répertoire parent et le fichier de base de données si nécessaire : le
processus doit donc disposer des droits d’écriture appropriés.

Le paquet nécessite Node.js 22 ou une version ultérieure et une plateforme prise en charge par sa
dépendance native `better-sqlite3`. Il n’est pas prévu pour React Native ni pour Expo ; dans ces
environnements, utilisez un stockage mobile natif de la plateforme, comme `expo-sqlite`.

Ne placez pas une base de données de soumissions dans un répertoire web public et ne l’ajoutez pas
au contrôle de version.
