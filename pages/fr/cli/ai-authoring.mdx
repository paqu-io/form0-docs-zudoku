:::warning

peuvent changer avant une version stable. Vérifiez les calculs et le JavaScript des événements.

:::

La création avec IA ajoute à form0-cli un mode conversationnel pour modifier les schémas. Elle
travaille avec des schémas form0 ordinaires : le fichier final ne contient ni conversation, ni
configuration de fournisseur, ni mutation.

Lancez-le directement avec un schéma ou entrez dans le mode AI depuis le shell interactif :

```bash
form0 ai [schema]
```

```ansi
form0> serve
form0(server)> ai
form0(server,ai)> Add a calculated total from quantity and unit price
```

Le mode AI ne lance pas le serveur d'aperçu. S'il est déjà actif, les brouillons validés sont envoyés
au navigateur avec l'indication **AI draft**, sans écriture sur disque.

## Fonctionnement de la création

1. Le modèle sélectionné reçoit le formulaire complet et le catalogue du core installé.
2. L'agent propose un lot cohérent de mutations sémantiques au lieu de remplacer le fichier.
3. form0-core applique le lot à une copie et valide le résultat complet.
4. Un brouillon valide peut être inspecté, révisé, écarté ou appliqué explicitement.
5. L'application revérifie la révision sur disque et écrit le schéma atomiquement.

Une proposition invalide ne devient jamais un brouillon. Quitter ou écarter restaure le schéma
validé dans le navigateur. Le résultat reste un schéma form0 ordinaire sans métadonnées AI ajoutées.
