---
title: Configuration du projet
description: Configuration locale du projet et préférences utilisateur utilisées par form0-cli.
---

Les réglages du projet se trouvent dans `form0.config.js`. Les valeurs propres à la machine et les
identifiants des connecteurs doivent rester dans `.env.local`. Ne publiez ni secrets ni bases de
données locales contenant de véritables soumissions.
