---
title: Configuration du projet
description: Comprenez la configuration propre au projet et à l’utilisateur utilisée par form0-cli.
---

<PageBadges />

Les réglages du projet se trouvent dans `form0.config.js`. Selon le type de projet, ce fichier peut
décrire l’emplacement des schémas, les serveurs de développement de l’application, les thèmes, le
stockage et les connecteurs.

Les valeurs propres à chaque machine et les identifiants des connecteurs vont dans `.env.local`. Les
préférences de l’utilisateur, comme le thème et la langue de la CLI, sont gérées séparément par la
CLI. Ne commitez ni secrets ni fichiers de base de données locaux contenant de véritables
soumissions.
