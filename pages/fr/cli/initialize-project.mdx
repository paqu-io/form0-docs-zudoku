---
title: Initialiser un projet
description: Créez un projet form0 standard, web ou mobile avec la CLI.
---

<PageBadges />

Exécutez `form0`, saisissez `init`, puis choisissez **Projet standard**, **Application web** ou
**Application mobile**. Vous pouvez aussi utiliser directement `form0 init [dir]`.

Une fois le projet créé, ouvrez son répertoire et suivez le README généré.
