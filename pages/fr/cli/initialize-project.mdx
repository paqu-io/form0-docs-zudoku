---
title: Initialiser un projet
description: Créez un projet form0 standard, web ou mobile avec la CLI.
---

<PageBadges />

Exécutez `form0`, saisissez `init`, puis choisissez le type de projet qui correspond à votre application :

- **Projet standard de schéma form0** pour les schémas, la validation locale, les tests et l’aperçu.
- **Application web** pour le starter maintenu React et Vite.
- **Application mobile** pour le starter maintenu React Native et Expo.

Vous pouvez aussi initialiser directement un répertoire avec `form0 init [dir]`. Une fois le projet
créé, placez-vous dans son répertoire et suivez le README généré.
