<PageBadges />

La CLI nécessite Node.js 22.19.0 ou une version ultérieure.

Installez le CLI globalement pour rendre la commande `form0` disponible:

```bash
npm install -g form0-cli
```

Vous pouvez plutôt l'exécuter sans installation globale:

```bash
npx form0-cli
```

Utilisez la même commande npm pour mettre à jour une installation globale.
les versions dans des environnements automatisés et examinez les versions de GitHub avant la mise à niveau.
