---
title: Installer et mettre à jour
description: Installez form0-cli globalement ou exécutez-le temporairement avec npx.
---

Installez la CLI avec `npm install -g form0-cli`, ou exécutez-la sans installation globale avec
`npx form0-cli`. Utilisez la même commande npm pour la mettre à jour.

Les versions antérieures à 1.0 peuvent comporter des changements incompatibles. Épinglez la
version dans les environnements automatisés et consultez GitHub Releases avant une mise à niveau.
