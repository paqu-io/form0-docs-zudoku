---
title: Installer et mettre à jour
description: Installez form0-cli globalement ou exécutez-le temporairement avec npx.
---

<PageBadges />

La CLI nécessite Node.js 22.19.0 ou une version ultérieure.

Installez la CLI globalement pour rendre la commande `form0` disponible :

```bash
npm install -g form0-cli
```

Vous pouvez aussi l’exécuter sans installation globale :

```bash
npx form0-cli
```

Pour mettre à jour une installation globale, utilisez la même commande npm. Les versions antérieures
à la 1.0 peuvent introduire des changements incompatibles : figez les versions dans les
environnements automatisés et consultez les GitHub Releases avant toute mise à jour.
