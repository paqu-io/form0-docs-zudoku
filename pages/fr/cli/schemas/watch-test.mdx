---
title: Regarder et tester
description: Revalider schemas à mesure qu'ils changent et exécuter le script de test form0 d'un projet.
---

<PageBadges />

Utilisez `form0 watch [schema]` pendant le développement de schema. Ajoutez `--auto-validate` ou `--auto-run` pour répéter
ces opérations après les modifications enregistrées; `--values` fournit les valeurs initiales pour les exécutions automatiques.

Utilisez `form0 test [dir]` pour exécuter le `test.js` du projet. Gardez les tests déterministes et
Comportement schema important pour le projet.
