---
title: Exécuter avec des valeurs
description: Évaluez un schéma avec des valeurs initiales JSON ou YAML.
---

<PageBadges />

Utilisez `form0 run <schema> --values <input>`. L’entrée peut être une valeur JSON en ligne ou un
fichier JSON, YAML ou YML. La commande affiche l’état évalué du moteur et signale les champs
d’entrée inconnus.
