:::warning

La création avec IA est en préversion. Les commandes, les fournisseurs disponibles, les prompts et
le protocole de mutation peuvent changer avant une version stable. Relisez les calculs et le
JavaScript d’événements générés.

:::

La création avec IA ajoute à form0-cli un mode conversationnel de création de schémas. Elle
travaille sur des schémas form0 ordinaires : le fichier final ne contient ni historique de
conversation, ni configuration de fournisseur, ni données de mutation.

Lancez-la directement avec un schéma, ou entrez dans le mode IA depuis le shell interactif :

```bash
form0 ai [schema]
```

```ansi
form0> serve
form0(server)> ai
form0(server,ai)> Add a calculated total from quantity and unit price
```

Le mode IA ne lance pas le serveur d’aperçu. Si un serveur est déjà en cours d’exécution, les
brouillons validés sont diffusés au navigateur avec l’étiquette de source **AI draft**, sans être
écrits sur le disque.

## Fonctionnement de la création

1. Le modèle sélectionné reçoit le formulaire courant complet et le catalogue de création du form0-core installé.
2. L’agent propose un lot cohérent de mutations sémantiques au lieu de remplacer le fichier du schéma.
3. form0-core applique le lot à une copie et valide le résultat complet.
4. Un brouillon valide peut être inspecté, révisé, abandonné ou appliqué explicitement.
5. L’application revérifie la révision sur disque et écrit le schéma de manière atomique.

Une proposition invalide ne devient jamais un brouillon. Quitter ou abandonner rétablit le schéma
enregistré dans le navigateur. Le résultat reste un schéma form0 ordinaire, sans métadonnées d’IA
ajoutées automatiquement.
