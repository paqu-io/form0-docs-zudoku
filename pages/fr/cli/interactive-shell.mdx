<PageBadges />

Exécutez `form0` sans arguments pour démarrer le shell interactif. Une session peut garder un schema chargé
pendant que vous validez, prévisualisez, exécutez, regardez, modifiez ou servez.

Utilisez `help` pour lister les commandes disponibles dans le mode courant, `status` pour inspecter la session, et
`exit` pour quitter le CLI . Commandes telles que `load` , `schema edit` et `serve` Mettre à jour l'invite
Affiche l'état de la session active.
