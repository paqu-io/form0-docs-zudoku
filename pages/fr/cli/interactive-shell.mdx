Exécutez `form0` sans argument pour lancer le shell interactif. Une session peut garder un schéma
chargé pendant que vous le validez, le prévisualisez, l’exécutez, le surveillez, le modifiez ou le
servez.

Utilisez `help` pour lister les commandes disponibles dans le mode courant, `status` pour inspecter
la session et `exit` pour quitter la CLI. Des commandes comme `load`, `schema edit` et `serve`
mettent à jour l’invite pour afficher l’état actif de la session.

## Syntaxe des commandes selon le mode

| Invite              | Comportement de la saisie                                                                                                                    |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `form0>`            | Saisissez les commandes du shell sans préfixe.                                                                                               |
| `form0(server)>`    | Saisissez les commandes compatibles avec le serveur affichées par `help`, comme `validate`, `preview`, `serve status`, `serve stop` ou `ai`. |
| `form0(schema)>`    | Saisissez les commandes de l’éditeur de schéma sans préfixe.                                                                                 |
| `form0(ai)>`        | Le texte sans préfixe est envoyé au modèle ; les actions de la CLI commencent toujours par `/`.                                              |
| `form0(server,ai)>` | Utilisez les commandes à barre oblique du mode IA, notamment `/preview`, `/validate`, `/serve status` et `/serve stop`.                      |

Ainsi, les requêtes en langage naturel restent sans ambiguïté en mode IA, tandis que le reste du
shell conserve sa syntaxe concise.

L’installation d’un connecteur est une commande de terminal, et non une action du shell interactif :

```bash
form0 connector install <name-or-path>
form0 connector --help
```

Dans le shell, utilisez `connector help` pour charger, configurer, tester et vérifier l’état des
connecteurs.
