---
title: Serveurs de développement d’applications
description: Lancez une application web ou Expo configurée en parallèle du serveur d’aperçu form0.
---

<PageBadges />

Utilisez `form0 serve --app` lorsque le `form0.config.js` du projet définit un serveur de
développement pour l’application. Les templates web et mobile maintenus incluent une configuration
adaptée.

Les projets Expo peuvent utiliser `--public-url` lorsqu’un appareil doit joindre le serveur de
développement via un tunnel ou une URL de développement publique et stable.

Pour une application Expo, l’aperçu sur le port 3030 indique que l’application s’ouvre sur le
téléphone à partir du QR code d’Expo. Dans le shell interactif, `serve --app` n’affiche pas l’invite
`form0(server)>` tant que vous n’appuyez pas sur Entrée, afin qu’Expo imprime son QR code sur des
lignes propres. Les commandes saisies avant s’exécutent quand même.
