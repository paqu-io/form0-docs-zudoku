Les applications de démarrage associent les paquets form0 au routage, à la configuration, aux
styles et aux conventions de développement local. Utilisez-les pour personnaliser une application
fonctionnelle plutôt que pour intégrer un binding dans un projet existant.

| Application         | Recommandée pour                                                          | Code source                                                              |
| ------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| React + Vite        | Applications web, formulaires personnalisés et hébergement statique       | [GitHub](https://github.com/paqu-io/form0-web-tmpl-react-vite)           |
| React Native + Expo | Applications iOS et Android, fonctions de l’appareil et usages hors ligne | [GitHub](https://github.com/paqu-io/form0-mobile-tmpl-react-native-expo) |

## Parcours de création recommandé

Utilisez [form0-cli](/fr/cli/overview). La CLI guide le choix du projet et du gestionnaire de paquets,
puis produit une application normale qui vous appartient.

```bash
npm install --global form0-cli
form0 init mon-application-form0
```

Le bouton GitHub **Use this template** reste disponible pour créer directement un dépôt depuis la
source. La CLI demeure le parcours d’intégration canonique.

Ces guides expliquent l’application autour de form0. Consultez les [Bindings](/fr/bindings/overview)
pour les API et le [Core](/fr/core/overview) pour le comportement des schémas.

Continuez avec [Créer et exécuter React et Vite](/fr/starter-apps/react-vite/create-run).
