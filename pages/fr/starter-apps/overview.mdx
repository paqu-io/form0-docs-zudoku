Les applications starter sont des bases d’application maintenues qui associent les paquets form0 au
routage, à la configuration, aux styles et aux conventions de développement local. Elles sont utiles
lorsque vous voulez partir d’une application fonctionnelle à personnaliser plutôt qu’ajouter un
binding à un projet existant.

| Starter             | Usage idéal                                                                                | Code source                                                              |
| ------------------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| React + Vite        | Applications navigateur, formulaires web personnalisés et hébergement statique             | [GitHub](https://github.com/paqu-io/form0-web-tmpl-react-vite)           |
| React Native + Expo | Applications iOS et Android, fonctionnalités de l’appareil et parcours orientés hors ligne | [GitHub](https://github.com/paqu-io/form0-mobile-tmpl-react-native-expo) |

## Parcours de création recommandé

Utilisez [form0-cli](/fr/cli/overview) pour créer un starter. La CLI vous guide dans le choix du
projet et du gestionnaire de paquets, et produit un dépôt d’application classique qui vous
appartient.

```bash
npm install --global form0-cli
form0 init my-form-app
```

Le bouton **Use this template** de GitHub reste disponible lorsque vous voulez explicitement créer
un dépôt à partir du starter source. La CLI reste le parcours d’intégration de référence.

Les guides des starters décrivent l’application qui entoure form0. Pour les API des paquets,
consultez la [documentation des bindings React et React Native](/fr/bindings/overview). Pour le
comportement des schémas, consultez la [documentation du noyau](/fr/core/overview).

Poursuivez avec le guide de votre starter :

- [Créer et exécuter le starter React et Vite](/fr/starter-apps/react-vite/create-run)
- [Créer et exécuter le starter React Native et Expo](/fr/starter-apps/react-native-expo/create-run)
