Les applications de démarrage sont des fondations d'application maintenues qui combinent des paquets form0 avec le routage,
conventions de configuration, de style et de développement local. Ils sont utiles lorsque vous
personnaliser plutôt que d'ajouter un binding à un projet existant.

| Démarrage         | Le meilleur pour                                                                   | Source                                                                   |
| ----------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| React+Vite        | Applications de navigateur, formulaires Web personnalisés et hébergement statique  | [GitHub](https://github.com/paqu-io/form0-web-tmpl-react-vite)           |
| React Native+Expo | Applications iOS et Android, capacités des appareils et flux de travail hors ligne | [GitHub](https://github.com/paqu-io/form0-mobile-tmpl-react-native-expo) |

## Chemin de création recommandé

Utilisez [form0-cli](/fr/cli/overview) pour créer un starter.
sélection et produit un dépôt d'application normal que vous possédez.

```bash
npm install --global form0-cli
form0 init my-form-app
```

** Utilisez ce bouton de modèle ** est également disponible lorsque vous souhaitez explicitement
Le CLI reste le chemin canonique d'intégration.

Les guides de démarrage expliquent l'application autour de form0. Pour les API de package,
[React et React Native binding documentation](/fr/bindings/overview). Pour le comportement schema,
[Documentation de base](/fr/core/overview).
