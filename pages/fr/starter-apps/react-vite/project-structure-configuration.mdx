Le starter est une application Vite normale. Les valeurs form0 se trouvent dans `form0.config.js` et
le code applicatif reste sous `src`.

```text
.
├── form0.config.js
├── src/
│   ├── components/        # wrappers et primitives d’interface
│   ├── field-renderers/   # rendus propres à l’application
│   ├── forms/             # schémas, registre et chargeur
│   ├── pages/             # pages et routes
│   ├── styles/            # styles form0 supplémentaires
│   └── themes/            # thèmes Vanilla Extract facultatifs
└── vite.config.js         # plugins, alias et proxy local
```

## Zones de configuration

`form0.config.js` contrôle la mise en page, le mode et le stockage du moteur, le thème,
l’interaction, le répertoire des schémas, le serveur de développement, les rendus de champs et le
format de sortie. Les props peuvent remplacer les valeurs pertinentes pour un formulaire précis.

> [!CAUTION]
> Conservez `engine.store` à `snapshot`. La configuration incluse documente une limite connue des
> messages de validation avec le mode `selector`.

## Proxy de développement

Vite transmet `/api` à `http://localhost:3030` par défaut. Définissez `FORM0_DEV_API_URL` dans
l’environnement du processus ou un fichier `.env` Vite local pour changer cette adresse. La valeur
est consommée par la configuration Vite et n’est pas exposée au navigateur.

Ne placez jamais d’identifiants dans les variables client. Les identifiants de base de données
appartiennent à l’environnement CLI ou serveur décrit dans [Connecteurs](/fr/connectors/overview).
