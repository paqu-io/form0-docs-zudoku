## Ressources nécessaires

- Node.js 22 ou plus récent
- Un gestionnaire de paquets pris en charge; la source starter commit un fichier de verrouillage npm
- Un navigateur moderne

## Créer l'application

Installez le CLI, puis initialisez un projet web:

```bash
npm install --global form0-cli
form0 init my-form-app
```

Choisissez l'application Web \*\* ** et ** React + Vite \*\* lorsque vous y êtes invité.
dépendances si le flux sélectionné ne l'a pas déjà fait, et lancez l'application:

```bash
cd my-form-app
npm install
npm run dev
```

Ouvrez le URL imprimé par Vite, normalement `http://localhost:5173`. La page d'accueil
exemples de formulaires et leur page et superposition de présentations.

## Exécutez avec form0-cli

À partir du répertoire du projet, `form0 serve --app` démarre le serveur d'applications configuré
le serveur de développement CLI. Utilisez ce mode lorsque vous souhaitez que le gestionnaire par défaut de starter
atteindre des connecteurs configurés localement.

```bash
form0 serve --app
```

Voir [Serveurs de développement d'applications](/fr/cli/local-development/app-development-servers) et
[Soumissions et connecteurs](/fr/starter-apps/react-vite/submissions-connectors) pour la frontière
entre l'application du navigateur, le serveur CLI et le connecteur de base de données.
