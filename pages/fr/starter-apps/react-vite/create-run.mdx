## Prérequis

- Node.js 22 ou une version ultérieure
- Un gestionnaire de paquets pris en charge ; le starter source inclut un fichier de verrouillage npm
- Un navigateur récent

## Créer l’application

Installez la CLI, puis initialisez un projet web :

```bash
npm install --global form0-cli
form0 init my-form-app
```

Choisissez **Application web** et **React + Vite** lorsque la CLI vous le demande. Placez-vous dans
le répertoire généré, installez ses dépendances si le parcours choisi ne l’a pas déjà fait, puis
démarrez l’application :

```bash
cd my-form-app
npm install
npm run dev
```

Ouvrez l’URL affichée par Vite, généralement `http://localhost:5173`. La page d’accueil liste les
formulaires d’exemple inclus et leurs présentations en page et en overlay.

## Exécuter avec form0-cli

Depuis le répertoire du projet, `form0 serve --app` démarre le serveur d’application configuré en
même temps que le serveur de développement de la CLI. Utilisez ce mode lorsque vous voulez que le
gestionnaire de soumission par défaut du starter atteigne les connecteurs configurés localement.

```bash
form0 serve --app
```

Consultez
[Serveurs de développement d’applications](/fr/cli/local-development/app-development-servers) et
[Soumissions et connecteurs](/fr/starter-apps/react-vite/submissions-connectors) pour comprendre la
séparation entre l’application navigateur, le serveur de la CLI et le connecteur de base de données.
