## Une route indique que le formulaire est introuvable

Vérifiez que l’identifiant de l’URL correspond exactement à une entrée de `src/forms/registry.js`.
Vérifiez aussi que son import dynamique pointe vers un fichier de schéma existant.

## Un schéma ne se charge pas

Ouvrez la console du navigateur pour voir l’erreur d’import, puis validez le schéma avec form0-cli.
Les erreurs de syntaxe JSON et les chemins d’import relatifs incorrects sont les causes les plus
fréquentes.

```bash
form0
```

Chargez le schéma et exécutez `validate`. Voir [Valider et prévisualiser](/fr/cli/schemas/validate-preview).

## Un renderer personnalisé n’est pas utilisé

Vérifiez les trois noms : le type de champ du schéma, son association dans `form0.config.js` et
l’identifiant du resolver dans `src/field-renderers/resolver.js`. Le resolver journalise un
avertissement pour les identifiants inconnus.

## Les soumissions n’atteignent pas le serveur de la CLI

Exécutez `form0 serve --app` depuis le répertoire du projet. Si le serveur de la CLI utilise une
autre adresse, définissez `FORM0_DEV_API_URL` avant de démarrer Vite ou dans le fichier `.env` local
concerné. Vérifiez que `devServer.apiBaseUrl` correspond toujours au chemin du proxy Vite.

## L’évaluation dans le worker échoue

Définissez temporairement `engine.mode` sur `main-thread` pour distinguer le chargement du worker du
comportement du schéma. Vérifiez ensuite la console du navigateur, les chemins des ressources et le
type de contenu servi par le déploiement. Voir
[Workers et performances](/fr/bindings/react/workers-performance).

## Les liens directs renvoient une 404 après le déploiement

Configurez l’hébergement statique pour qu’il se replie sur `index.html` pour les chemins inconnus de
l’application. Il s’agit d’un problème de configuration de l’hébergement, et non de définition des
routes React.

Pour les erreurs d’affichage au niveau du paquet, poursuivez avec
[Dépannage React](/fr/bindings/react/troubleshooting). Pour les erreurs de base de données, consultez
[Dépannage des connecteurs](/fr/connectors/troubleshooting).
