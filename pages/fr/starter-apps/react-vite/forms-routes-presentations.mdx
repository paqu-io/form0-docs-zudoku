Les fichiers de schéma se trouvent dans `src/forms`. Le registre de `src/forms/registry.js` associe à
chaque formulaire une route de l’application, des métadonnées d’affichage, un import dynamique du
schéma et des valeurs initiales facultatives.

```js
const forms = [
  {
    id: "contact",
    title: "Contact us",
    description: "Send a message to the team.",
    loadSchema: () => import("./contact/schema.json"),
  },
]
```

Créez le fichier de schéma correspondant, puis ajoutez l’entrée au registre. Les imports dynamiques
placent les fichiers de schéma dans des chunks de build distincts.

## Routes

Le starter fournit :

- `/` pour la liste des formulaires et les exemples d’overlay ;
- `/:formId` pour la présentation standard par défaut ;
- `/:formId/:variant` pour les présentations en page `standard` ou `simplified`.

`FormPage` valide l’identifiant du formulaire et la présentation avant de charger le schéma. `Home`
gère les exemples modal et spotlight.

## Présentations

Les quatre clés de présentation incluses sont :

| Clé          | Emplacement                  |
| ------------ | ---------------------------- |
| `standard`   | Page de formulaire complète  |
| `simplified` | Page pas à pas               |
| `modal`      | Overlay en boîte de dialogue |
| `spotlight`  | Overlay en panneau latéral   |

Les valeurs de mise en page par défaut de chaque présentation se trouvent dans `form0.config.js`. Le
composant d’encapsulation de l’application transmet à `FormRenderer` le thème, l’emplacement, le
mode d’interaction et le dimensionnement résolus.

Consultez [Modifier votre premier schéma](/fr/getting-started/schema-edit) pour la rédaction de
schémas et [Modes, emplacement et navigation](/fr/bindings/react/modes-placement-navigation) pour le
comportement sous-jacent du binding React.
