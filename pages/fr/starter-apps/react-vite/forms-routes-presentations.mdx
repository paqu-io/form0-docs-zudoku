Les fichiers de schéma vivent sous `src/forms`. Le registre dans `src/forms/registry.js` donne à chaque formulaire un
route de l'application, affichage des métadonnées, une importation dynamique schema et des valeurs initiales facultatives.

```js
const forms = [
  {
    id: "contact",
    title: "Contact us",
    description: "Send a message to the team.",
    loadSchema: () => import("./contact/schema.json"),
  },
]
```

Créez le fichier schema correspondant, puis ajoutez l'entrée de registre. Les importations dynamiques conservent les fichiers schema dans
construire des chunks séparés.

## Routes

Le starter fournit:

- `/` pour la liste de formulaires et les exemples de superposition;
- `/:formId` pour la présentation standard par défaut; et
- `/:formId/:variant` pour les présentations de pages `standard` ou `simplified`.

`FormPage` valide l'identifiant de formulaire et la présentation avant de charger schema . `Home` Possède le
modal et spotlight exemples.

## Exposés

Les quatre clés de présentation incluses sont:

| Clé          | Placement                |
| ------------ | ------------------------ |
| `standard`   | Formulaire complet       |
| `simplified` | Page étape par étape     |
| `modal`      | Incrustation de dialogue |
| `spotlight`  | Superposition du tiroir  |

Les valeurs par défaut de mise en page pour chaque présentation en direct dans `form0.config.js`.
