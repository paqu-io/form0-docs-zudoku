Le starter sépare les contrats d’affichage du paquet de la présentation propre à l’application.
Importez `form0-react/index.css` une seule fois, puis ajoutez par-dessus les choix propres à
l’application.

## Renderers de champ

Les renderers de l’application se trouvent dans `src/field-renderers`. Pour en ajouter un :

1. Créez le composant React.
2. Ajoutez-le à `src/field-renderers/resolver.js` sous un identifiant stable.
3. Associez le type de champ form0 à cet identifiant dans `form0.config.js`.

```js
fieldRenderers: {
  DateField: "date-field-shadcn",
}
```

Le renderer de date inclus montre comment combiner les propriétés de champ form0 avec les
composants de base de shadcn/ui. Consultez le
[contrat des renderers personnalisés](/fr/bindings/react/custom-renderers) avant de créer d’autres
surcharges.

## Thèmes

Définissez `theme.mode` sur `light`, `dark` ou `system`. Pour remplacer le thème du paquet, créez un
thème Vanilla Extract dans `src/themes` et définissez `theme.customTheme` avec son chemin d’import.

Le thème personnalisé doit implémenter l’intégralité du contrat de thème de `form0-react`. Partez de
`src/themes/custom-example.css.js` et consultez le contrat dans
[Thèmes et styles](/fr/bindings/react/themes-styling).

## CSS de l’application

Utilisez ces couches pour des responsabilités distinctes :

- `src/index.css` pour Tailwind, les jetons shadcn et les styles globaux de l’application ;
- `src/App.css` pour la mise en page de l’application ;
- `src/styles/form0-overrides.css` pour les classes de formulaire propres à l’application ;
- les thèmes Vanilla Extract pour les jetons des renderers du paquet.

Privilégiez l’enregistrement de renderers et les contrats de thème plutôt que la modification du code
des paquets form0 installés.
