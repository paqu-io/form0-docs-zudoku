## Inclus SQLite magasin

Le starter enregistre les enregistrements soumis structurés avec `expo-sqlite`.
le bloc `storage` dans `form0.config.js`:

```js
storage: {
  enabled: true,
  databaseName: "form0.db",
  tableName: "form0_submissions",
  debug: false,
}
```

La base de données se trouve dans le bac à sable de l'application spécifique à la plate-forme.
enregistrer les métadonnées et l'enregistrement structuré complet sous JSON. Les contrôles de débogage inclus peuvent lister
ou effacer les enregistrements lorsque `debug` est activé.

## La persistance n'est pas la synchronisation

Ce magasin fournit uniquement la persistance sur le périphérique. Il ne télécharge pas les enregistrements, ne réessaye pas les demandes, ne résout pas
conflits, chiffrent les exportations ou définissent des politiques de rétention et de suppression.
Traiter les sauvegardes de bases de données et les fichiers exportés comme des fichiers sensibles
données utilisateur.

Les paquets Node.js `form0-connector-pg` et `form0-connector-sqlite` ne s'exécutent pas dans React Native.
Envoyer à distance submissions via une application authentifiée API; n'intégrez pas les informations d'identification de la base de données
dans une application mobile.
