## Stockage SQLite inclus

Le starter enregistre les enregistrements structurés soumis avec `expo-sqlite`. Configurez-le ou
désactivez-le via le bloc `storage` de `form0.config.js` :

```js
storage: {
  enabled: true,
  databaseName: "form0.db",
  tableName: "form0_submissions",
  debug: false,
}
```

La base de données se trouve dans le sandbox de l’application propre à chaque plateforme. Chaque
soumission est insérée avec les métadonnées de l’enregistrement et l’enregistrement structuré complet
au format JSON. Les contrôles de débogage inclus permettent de lister ou d’effacer les
enregistrements lorsque `debug` est activé.

## Photos et vidéos

`PhotoField` et `VideoField` prennent des photos et des vidéos avec l’appareil photo ou les
choisissent dans la galerie au moyen de `src/lib/media-picker.js`, qui utilise `expo-image-picker` ;
`Form0Form` le passe à `FormRenderer` en tant que `mediaPicker`. Les fichiers du sélecteur lui-même
sont temporaires : les fichiers choisis sont donc copiés dans le dossier de documents de
l’application, sous `form0-media/`. Les enregistrements conservent l’`url` locale de chaque fichier
avec `upload_status: "local"`, et rien n’est envoyé. Retirer un élément d’un enregistrement ne
supprime pas son fichier.

## La persistance n’est pas la synchronisation

Ce stockage assure uniquement la persistance sur l’appareil. Il n’envoie pas les enregistrements, ne
relance pas les requêtes, ne résout pas les conflits, ne chiffre pas les exports et ne définit pas de
politique de conservation ni de suppression. Les applications doivent concevoir ces comportements en
fonction de leurs données et de leur modèle de menace. Traitez les sauvegardes de la base de données
et les fichiers exportés comme des données utilisateur sensibles.

Les paquets Node.js `form0-connector-pg` et `form0-connector-sqlite` ne s’exécutent pas dans React
Native. Envoyez les soumissions distantes via une API authentifiée de l’application ; n’intégrez pas
d’identifiants de base de données dans une application mobile.

Pour le contrat de soumission et de snapshot du renderer, consultez
[Valeurs, snapshots et soumission](/fr/bindings/react-native/values-snapshots-submission). Pour les
limites générales côté mobile, consultez
[Intégration mobile](/fr/bindings/react-native/mobile-integration).
