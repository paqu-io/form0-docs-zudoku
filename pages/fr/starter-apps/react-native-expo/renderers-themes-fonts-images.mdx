## Thème et polices

La racine de l’application charge `form0Fonts` avec `expo-font` avant l’affichage et enveloppe son
interface dans `ThemeProvider`. Configurez le mode de couleur de base et les surcharges de thème
facultatives dans `form0.config.js`. Les écrans du starter qui entourent le formulaire utilisent les
mêmes jetons de thème que lui.

## Surcharges de renderers

Associez les types de champs du schéma à des identifiants de renderer dans `form0.config.js`, puis
associez ces identifiants à des composants dans `src/field-renderers/resolver.js`. Garder les
composants hors du fichier de configuration préserve une configuration sérialisable et facile à
exploiter par les outils.

Pour les propriétés des renderers et le fonctionnement de l’enregistrement, consultez la
[documentation des renderers personnalisés](/fr/bindings/react-native/custom-renderers).

## Images d’appui

React Native exige que les références aux images intégrées au bundle soient détectables de façon
statique. Ajoutez les fichiers dans `assets/supporting-images`, puis régénérez la table de
correspondance :

```bash
npm run generate-images
```

Commitez à la fois la ressource et `src/supporting-images/index.js`. Les scripts de démarrage
régénèrent le fichier, et la CI vérifie que le registre commité est à jour. Les chemins d’image
HTTP et HTTPS distants n’ont pas besoin d’entrée dans le registre.

Consultez [Thèmes, polices et images](/fr/bindings/react-native/themes-assets) pour les API du
binding.
