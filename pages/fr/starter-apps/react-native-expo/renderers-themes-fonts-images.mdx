## Thème et polices

La racine de l'application charge `form0Fonts` avec `expo-font` avant le rendu et enveloppe son interface utilisateur dans
`ThemeProvider` . Configurez le mode de couleur de base et les remplacements facultatifs de thème dans `form0.config.js` .
Les écrans starter environnants utilisent les mêmes jetons de thème que le formulaire.

## Rendu overrides

Map schema types de champ à renderer identifiants dans `form0.config.js`, puis mapper ces identifiants à
composants dans `src/field-renderers/resolver.js`. Garder les composants hors du fichier de configuration
préserve une limite de configuration sérialisable et conviviale pour les outils.

Pour les props renderer et le comportement d'enregistrement,
[documentation personnalisée renderer](/fr/bindings/react-native/custom-renderers).

## Images de soutien

React Native nécessite que les références d'image groupées soient détectables statiquement.
`assets/supporting-images`, puis régénérez la table de correspondance:

```bash
npm run generate-images
```

Commit la ressource et `src/supporting-images/index.js`. Les scripts de démarrage régénèrent le fichier,
et CI vérifie que le registre engagé est à jour. Les chemins d'image distants HTTP et HTTPS ne sont pas
besoin d'entrées de registre.

Voir [Thèmes, polices et images](/fr/bindings/react-native/themes-assets) pour les API de niveau binding.
