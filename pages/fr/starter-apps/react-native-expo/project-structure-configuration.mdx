Le starter est une application Expo classique. L’identité de l’application et les paramètres natifs
se trouvent dans `app.json` ; les conventions form0 de l’application se trouvent dans
`form0.config.js`.

```text
.
├── app.json
├── form0.config.js
├── assets/
├── scripts/
└── src/
    ├── components/
    ├── field-renderers/
    ├── forms/
    ├── lib/
    ├── pages/
    └── supporting-images/
```

## Configuration Expo

Utilisez `app.json` pour le nom de l’application, le slug, la version, l’orientation, les icônes,
l’écran de démarrage, les options de plateforme et les autres paramètres Expo. Vérifiez ces valeurs
d’exemple avant de distribuer une application.

## Configuration form0

`form0.config.js` contrôle :

- la mise en page du formulaire et le placement des libellés ;
- le mode de thème et les surcharges du thème ;
- le comportement initial en édition ou en consultation ;
- le décalage de défilement lié au clavier ;
- les identifiants des renderers ;
- le choix des clés de champ dans la sortie ;
- le stockage local SQLite ;
- l’intégration avec le serveur de développement Expo utilisée par `form0 serve --app`.

Conservez dans `.env.local` les URL publiques de développement propres à chaque machine. Ne placez
pas de secrets dans la configuration publique d’Expo ni dans des valeurs intégrées à l’application
cliente.

La [référence de configuration du projet de la CLI](/fr/cli/project-configuration) documente les
paramètres form0 partagés. Poursuivez avec
[Formulaires, écrans et navigation](./forms-screens-navigation).
