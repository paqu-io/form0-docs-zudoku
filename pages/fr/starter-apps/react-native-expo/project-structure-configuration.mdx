Le starter est une application Expo normale. Identité de l'application et paramètres natifs
`app.json`; Les conventions d'application form0 résident dans `form0.config.js`.

```text
.
├── app.json
├── form0.config.js
├── assets/
├── scripts/
└── src/
    ├── components/
    ├── field-renderers/
    ├── forms/
    ├── lib/
    ├── pages/
    └── supporting-images/
```

## Configuration Expo

Utilisez `app.json` pour le nom de l'application, le slug, la version, l'orientation, les icônes, l'écran de démarrage, les options de plate-forme,
et d'autres paramètres Expo. Passez en revue ces valeurs d'espace réservé avant de distribuer une application.

## Configuration form0

Commandes `form0.config.js`:

- mise en page et placement des étiquettes;
- mode de thème et remplacements de thème;
- comportement initial d'édition ou de visualisation;
- décalage de défilement du clavier;
- les identifiants renderer;
- sélection de la clé de champ de sortie;
- un stockage local SQLite; et
- Intégration du serveur de développement Expo utilisé par `form0 serve --app`.

Conservez les URL de développement public spécifiques à la machine dans `.env.local`. Ne placez pas de secrets dans Expo public
configuration ou en valeurs regroupées dans l'application cliente.
