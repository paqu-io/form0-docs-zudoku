## Enregistrer les formulaires

Les schémas se trouvent dans `src/forms`. Ajoutez chaque formulaire à `src/forms/registry.js` avec un
ID stable, des métadonnées d’affichage et une fonction `loadSchema`. Les imports statiques sont
utiles pour le premier écran ; les imports dynamiques permettent de différer le chargement des
autres formulaires.

`useFormSchema` résout l’entrée du registre sélectionnée et expose son état de chargement, son
schéma et son état d’erreur. Validez les schémas avec [form0-cli](/fr/cli/schemas/validate-preview)
avant de les livrer.

## Comprendre l’enchaînement des écrans

Le starter utilise volontairement un petit enchaînement fondé sur l’état :

```text
App → Home → FormPage → Form0Form
```

`Home` liste les formulaires enregistrés. `FormPage` charge le schéma et gère les actions de
soumission et de débogage du stockage. `Form0Form` traduit la configuration de l’application en
propriétés du `FormRenderer` React Native.

C’est un point de départ facile à comprendre, pas un framework de routage. Remplacez l’état
`activeFormId` par le routeur ou la bibliothèque de navigation de votre application lorsque vous
avez besoin de liens profonds, d’onglets, de piles authentifiées ou de restaurer l’état de
navigation.

Le renderer gère le défilement, l’évitement du clavier et les écrans drilldown dans la zone d’écran
qui lui est allouée. Évitez de l’envelopper dans une autre vue de défilement verticale. Consultez
[Modes et navigation](/fr/bindings/react-native/modes-navigation) pour le contrat du renderer.
