## Enregistrer les formulaires

Les schémas vivent sous `src/forms` . Ajouter chaque formulaire `src/forms/registry.js` avec un ID stable, afficher
Métadonnées et A `loadSchema` Les importations statiques sont utiles pour le premier écran; dynamique
Les importations peuvent différer le chargement d'autres formulaires.

`useFormSchema` résout l'entrée de Registre sélectionnée et expose son chargement, schema et son erreur
Validez schemas avec [form0-cli](/fr/cli/schemas/validate-preview) avant de les expédier.

## Comprendre le flux d'écran

Le starter utilise délibérément un petit flux basé sur l'état:

```text
App → Home → FormPage → Form0Form
```

`Home` répertorie les formulaires enregistrés. `FormPage` charge le schema et possède submission et storage-debug
`Form0Form` mappe la configuration de l'application dans le React Native `FormRenderer`.

Ceci est un point de départ compréhensible, pas un routage framework. Remplacer l'état `activeFormId`
avec le routeur ou la bibliothèque de navigation utilisés par votre application lorsque vous avez besoin de liens profonds, d'onglets,
piles authentifiées, ou état de navigation restauré.

Le renderer possède des écrans de défilement, d'évitement de clavier et de drill-down à l'intérieur de son écran alloué
zone. Évitez de l'envelopper dans une autre vue de défilement vertical. Voir
[Modes et navigation](/fr/bindings/react-native/modes-navigation) pour le contrat renderer.
