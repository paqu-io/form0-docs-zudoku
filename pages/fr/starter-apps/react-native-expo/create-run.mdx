Le starter React Native et Expo est le moyen le plus rapide d’obtenir une application mobile form0.
Il inclut des exemples de schémas, des renderers natifs, des polices, des images d’appui et une
persistance locale avec SQLite.

## Créer l’application

Installez [form0-cli](/fr/cli/install-update), puis initialisez un projet :

```bash
npm install --global form0-cli
form0 init my-mobile-form
```

Choisissez **Application mobile** et **React Native + Expo**. Placez-vous dans le répertoire généré
et installez ses dépendances si le gestionnaire de paquets choisi ne l’a pas déjà fait.

```bash
cd my-mobile-form
npm install
npm start
```

Le bouton **Use this template** de GitHub est une autre option lorsque vous voulez explicitement une
copie du dépôt. La CLI reste le parcours de création recommandé.

## Choisir une cible de développement

Utilisez un development build Expo pour le travail orienté production et chaque fois que
l’application inclut du code natif personnalisé. Expo Go reste utile pour apprendre et évaluer
lorsqu’une version compatible du SDK est disponible pour la plateforme cible. Vous pouvez aussi
utiliser un émulateur Android, le simulateur iOS ou la cible web :

```bash
npm run android
npm run ios
npm run web
```

Le modèle nécessite Node.js 22.13 ou une version ultérieure. Les builds natifs prennent en charge
Android 7 ou une version ultérieure et iOS 16.4 ou une version ultérieure ; les builds iOS locaux
nécessitent Xcode 26.4 ou une version ultérieure. La configuration des émulateurs et des appareils
natifs suit le
[guide de l’environnement de développement Expo](https://docs.expo.dev/get-started/set-up-your-environment/).

Poursuivez avec [Structure et configuration du projet](./project-structure-configuration).
