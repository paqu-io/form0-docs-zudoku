## Thèmes de couleur

`colorMode` accepte `light` ou `dark`. Fournissez un `customTheme` partiel pour surcharger des
jetons ; le binding le fusionne en profondeur avec le thème intégré sélectionné. Une application
peut déterminer la préférence de l’appareil avec `useColorScheme` de React Native et transmettre le
mode obtenu.

```jsx
<FormRenderer schema={schema} colorMode="dark" customTheme={{ color: { primary: "#7c3aed" } }} />
```

`lightTheme`, `darkTheme`, `mergeThemes` et `getThemeByName` sont exportés pour composer des thèmes
au niveau de l’application. `ThemeProvider` et `useTheme` permettent d’harmoniser l’interface native
qui entoure le formulaire avec celui-ci.

## Polices fournies

Le paquet exporte ses fichiers de police Figtree via `form0Fonts`. Avec Expo, chargez-les au
démarrage de l’application, avant d’afficher le formulaire :

```jsx
import { useFonts } from "expo-font"
import { form0Fonts, FormRenderer } from "form0-react-native"

const [fontsLoaded] = useFonts(form0Fonts)
if (!fontsLoaded) return null

return <FormRenderer schema={schema} />
```

## Images d’appui

Par défaut, les chemins HTTP et HTTPS distants sont résolus en `{ uri }`. React Native exige que les
images locales intégrées au bundle soient détectables de façon statique : fournissez donc un
`imageResolver` qui associe les chemins du schéma à des sources d’image importées ou chargées avec
require :

```jsx
const images = {
  "safety/helmet.png": require("./assets/safety/helmet.png"),
}

<FormRenderer schema={schema} imageResolver={(path) => images[path] ?? null} />
```

Le starter maintenu Expo génère cette table de correspondance lorsque les images d’appui changent.
