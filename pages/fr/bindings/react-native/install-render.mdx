Pour une nouvelle application mobile, utilisez le [CLI quickstart](/getting-started/quickstart) . L ' entretien
React Native et Expo starter inclut le binding, le chargement de police, l'exemple schemas, le support
images, et la persistance locale SQLite.

Pour ajouter form0 à une application existante:

```bash
npm install form0-react-native form0-core lucide-react-native
```

Installez des dépendances natives avec des versions compatibles avec votre application. Dans Expo:

```bash
npx expo install react-native-svg react-native-safe-area-context expo-font
```

Le paquet nécessite Node.js 22 ou plus récent pour l'installation et l'outillage, React 18 ou 19, et React
Natif 0.72 ou plus récent. `react-native-safe-area-context` est facultatif mais laisse l'en-tête intégré
respecter la zone de sécurité de l'appareil. Lorsqu'il est installé, enveloppez la racine de l'application dans son
`SafeAreaProvider`.

## Rendre un schema

```jsx
import { FormRenderer } from "form0-react-native"
import schema from "./contact.form0.json"

export function ContactForm() {
  return (
    <FormRenderer
      schema={schema}
      onSubmit={(record, meta) => {
        console.log(record)
        console.log(meta.rawValues)
      }}
    />
  )
}
```

`schema` doit contenir un objet de formulaire `form0-core` valide.
[Modifier votre premier schema](/fr/getting-started/schema-edit) ou
[Objet de formulaire](/fr/core/schema/form).

Chargez les polices empaquetées avant d'afficher le formulaire pour la typographie prévue. Voir
[Thèmes, polices et images](/fr/bindings/react-native/themes-assets).
