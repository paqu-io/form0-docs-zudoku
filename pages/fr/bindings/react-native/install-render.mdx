Pour une nouvelle application mobile, utilisez le
[démarrage rapide de la CLI](/fr/getting-started/quickstart). Le starter maintenu React Native et
Expo inclut le binding, le chargement des polices, des exemples de schémas, des images d’appui et
une persistance locale avec SQLite.

Pour ajouter form0 à une application existante :

```bash
npm install form0-react-native form0-core lucide-react-native
```

Installez les dépendances peer natives dans des versions compatibles avec votre application. Avec
Expo :

```bash
npx expo install react-native-svg react-native-safe-area-context expo-font
```

Le paquet nécessite Node.js 22 ou une version ultérieure pour l’installation et l’outillage, React
18 ou 19, et React Native 0.72 ou une version ultérieure. `react-native-safe-area-context` est
facultatif, mais permet à l’en-tête intégré de respecter la zone de sécurité de l’appareil. S’il est
installé, enveloppez la racine de l’application dans son `SafeAreaProvider`.

## Afficher un schéma

```jsx
import { FormRenderer } from "form0-react-native"
import schema from "./contact.form0.json"

export function ContactForm() {
  return (
    <FormRenderer
      schema={schema}
      onSubmit={(record, meta) => {
        console.log(record)
        console.log(meta.rawValues)
      }}
    />
  )
}
```

`schema` doit contenir un objet formulaire `form0-core` valide. Commencez par
[Modifier votre premier schéma](/fr/getting-started/schema-edit) ou consultez
la page [Objet formulaire](/fr/core/schema/form).

Chargez les polices fournies avec le paquet avant d’afficher le formulaire pour obtenir la
typographie prévue. Voir [Thèmes, polices et images](/fr/bindings/react-native/themes-assets).
