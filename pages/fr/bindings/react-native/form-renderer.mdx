`FormRenderer` valide et prépare un schema, crée le moteur de formulaire, rend les champs natifs et
et produit des enregistrements structurés ou snapshots restaurable.

```jsx
<FormRenderer
  schema={schema}
  initialValues={{ name: "Ada" }}
  mode="edit"
  colorMode="light"
  labelPosition="top"
  onSubmit={saveRecord}
/>
```

## Propriétés essentielles

| Biens              | Objet                                                                       |
| ------------------ | --------------------------------------------------------------------------- |
| `schema`           | Un form0 schema contenant `form.elements`.                                  |
| `initialValues`    | Valeurs initiales des champs non répétables.                                |
| `initialSnapshot`  | Restaurer les valeurs brutes, l'état répétable et les horodatages ensemble. |
| `overrideValues`   | Appliquer des valeurs faisant autorité sur les valeurs initiales.           |
| `onSubmit`         | Recevez un enregistrement structuré et des métadonnées validés.             |
| `onSave`           | Recevez un snapshot sans exiger que le formulaire soit valide.              |
| `onSnapshotChange` | Observer les graines et le changement d'utilisateur snapshots.              |
| `mode`             | Démarrez en mode `edit` ou `readonly`.                                      |

## Intégration hôte

- `onRequestClose` active l'action d'annulation racine et reçoit `{ reason: "cancel" }` après toute
  Confirmation de rejet requise.
- `headerAccessory` affiche le contenu de l'application immédiatement en dessous de l'en-tête intégré.
- `showHeader` masque l'en-tête intégré lorsque l'hôte possède la navigation et les actions environnantes.
- `primaryActionMode`, `primaryActionLabel`, et `showPrimaryActionsInViewMode` personnaliser le
  action primaire intégrée.
- `onSchemaReady` reçoit le schema préparé après que les clés stables ont été assurées.
- `engineOptions` fournit les assistants de base, la configuration de sécurité, les avertissements, la gestion des opérations et
  Mise à jour Observation.
