## Exécution du moteur

Le `engineMode="main-thread"` par défaut évalue le moteur de formulaire sur le thread de l'interface utilisateur.
`engineMode="worker"` pour déplacer l'évaluation du moteur dans le module packagé worker lorsque Web Workers
sont disponibles:

```jsx
<FormRenderer schema={schema} engineMode="worker" />
```

`new Worker(new URL("./worker.js", import.meta.url), { type: "module" })`; sinon utilisez la valeur par défaut
mode fil principal.

Si le navigateur n'a pas de support Worker, le binding revient à l'exécution du fil principal.

## React mode de stockage

`engineStoreMode="snapshot"` clone le moteur snapshot dans l'état React et est l'état par défaut.
`engineStoreMode="selector"` utilise des abonnements sur le terrain pour réduire les grands rendus.

Traiter le mode sélecteur comme une optimisation: vérifier les erreurs de champ, les résumés de navigation, répétable
sections, et submission comportement dans l'application cible avant de l'adopter.
