`FormRenderer` valide et prépare un schéma, crée le moteur du formulaire, affiche les champs et les
sections, et produit des enregistrements structurés lors de la soumission.

```jsx
<FormRenderer
  schema={schema}
  initialValues={{ name: "Ada" }}
  mode="edit"
  theme="standard"
  colorMode="system"
  labelPosition="top"
  onSubmit={saveRecord}
/>
```

## Propriétés essentielles

| Propriété          | Rôle                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------- |
| `schema`           | Un schéma form0 contenant `form.elements`.                                               |
| `initialValues`    | Valeurs initiales des champs non répétables.                                             |
| `initialSnapshot`  | Restaure ensemble les valeurs brutes, l’état des sections répétables et les horodatages. |
| `overrideValues`   | Applique des valeurs prioritaires sur les valeurs initiales.                             |
| `onSubmit`         | Reçoit l’enregistrement structuré et les métadonnées de soumission.                      |
| `onSnapshotChange` | Observe les snapshots d’initialisation et de modification par l’utilisateur.             |
| `mode`             | Démarre en mode `edit` ou `readonly`.                                                    |

## Interface et état gérés par l’application

- `headerAccessory` affiche un nœud React, ou une fonction recevant `{ mode }`, entre le résumé et le corps du formulaire.
- `recordMetadataFields` affiche des métadonnées d’enregistrement en lecture seule. Un descripteur avec `displayValue` n’entre jamais dans les valeurs du moteur, les snapshots ni les valeurs soumises.
- `externalDirty` inclut les modifications gérées par l’application dans la confirmation d’abandon de l’overlay.
- `submitBlockedReason` désactive et bloque la soumission tant qu’une exigence externe n’est pas satisfaite.
- `onSchemaReady` reçoit le schéma préparé une fois les clés stables garanties.

## Propriétés de l’élément form

Les autres propriétés standard d’un formulaire, comme `id`, `aria-*` et les gestionnaires
d’événements, sont transmises au `<form>` affiché. N’utilisez pas ce mécanisme pour configurer le
moteur.

Poursuivez avec [Valeurs, snapshots et soumission](/fr/bindings/react/values-snapshots-submission)
ou [Modes, emplacement et navigation](/fr/bindings/react/modes-placement-navigation).
