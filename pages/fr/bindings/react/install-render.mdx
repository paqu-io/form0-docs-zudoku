Pour une nouvelle application web, utilisez le
[démarrage rapide de la CLI](/fr/getting-started/quickstart). Le starter maintenu React et Vite
inclut le binding, la configuration et des exemples de schémas.

Pour ajouter form0 à une application existante :

```bash
npm install form0-react form0-core
```

L’application host doit aussi fournir des dépendances peer compatibles :

- Node.js 22 ou une version ultérieure pour l’installation et les outils de build
- React 18 ou 19
- React DOM 18 ou 19
- `@vanilla-extract/css` 1.17.4 ou une version ultérieure

## Afficher un schéma

```jsx
import { FormRenderer } from "form0-react"
import "form0-react/index.css"
import schema from "./contact.form0.json"

export function ContactForm() {
  return (
    <FormRenderer
      schema={schema}
      onSubmit={(record, meta) => {
        console.log(record)
        console.log(meta.rawValues)
      }}
    />
  )
}
```

`schema` doit contenir un objet formulaire `form0-core` valide. Commencez par
[Modifier votre premier schéma](/fr/getting-started/schema-edit) ou consultez l’[Objet
formulaire](/fr/core/schema/form).

`onSubmit` reçoit un enregistrement form0 structuré. Le second argument expose les valeurs brutes,
l’état des sections répétables, les horodatages et le résumé de validation. Voir
[Valeurs, snapshots et soumission](/fr/bindings/react/values-snapshots-submission).

> [!NOTE]
> Par défaut, `FormRenderer` exécute le moteur sur le thread principal. Les applications Vite peuvent
> opter pour le module worker fourni avec le paquet avec `engineMode="worker"`.
