# Support

## Documentation

Read the [form0 documentation](https://docs.form0.dev) and start with the
[quickstart](https://docs.form0.dev/getting-started/quickstart). The recommended entry point for a
new form0 project is [form0-cli](https://github.com/paqu-io/form0-cli).

## Documentation problems

Search the
[form0 documentation issues](https://github.com/paqu-io/form0-docs-zudoku/issues) before opening a
new issue. Use this repository for:

- inaccurate, incomplete, or unclear documentation;
- translation problems;
- broken documentation links or examples; and
- problems with documentation navigation, search, accessibility, or rendering.

Include the affected page URL, what you expected, what you found, and any relevant package or
runtime version. A proposed correction is welcome, but not required.

## Product and package problems

When the documentation is accurate but the implementation behaves differently, report the problem
to the repository that owns the behavior:

- [form0-cli](https://github.com/paqu-io/form0-cli/issues) for commands and development tooling;
- [form0-core](https://github.com/paqu-io/form0-core/issues) for schema evaluation and validation;
- [form0-react](https://github.com/paqu-io/form0-react/issues) for React bindings;
- [form0-react-native](https://github.com/paqu-io/form0-react-native/issues) for React Native
  bindings; or
- the relevant connector or starter repository for repository-specific behavior.

If you are unsure where a problem belongs, open it where you observed it. Maintainers can redirect
or move it.

For private or general support, email [support@paqu.io](mailto:support@paqu.io).

## Security

Do not report suspected vulnerabilities in a public issue. Follow this repository's
[security policy](./SECURITY.md) and use its private vulnerability-reporting link.
